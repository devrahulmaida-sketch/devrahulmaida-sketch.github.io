1. सरल करने के बाद मानक रूप

एक चर का द्विघात समीकरण ax² + bx + c = 0 है, जहाँ गुणांक वास्तविक और a ≠ 0 है। पहले कोष्ठक खोलें, सभी पद एक ओर लाएँ और समान पद जोड़ें। सरल बहुपद की घात ही समीकरण का प्रकार तय करती है। स्रोत उदाहरण 2(ii) में x(x + 1) + 8 = (x + 2)(x − 2) से x + 12 = 0 मिलता है: यह रैखिक है, भले मूल रूप में x² हो। उदाहरण 2(iv) में (x + 2)³ = x³ − 4 से 6x² + 12x + 12 = 0 मिलता है: यह द्विघात है, भले मूल रूप में घन हों।

2. मूल समीकरण को सत्य बनाता है

5. विविक्तकर: पहले मूलों की प्रकृति

ax² + bx + c = 0, a ≠ 0 के लिए D = b² − 4ac निकालें। b और c के दिए चिह्न रखें। D > 0 पर दो भिन्न वास्तविक मूल; D = 0 पर दो समान वास्तविक मूल; D < 0 पर कोई वास्तविक मूल नहीं। 2x² − 4x + 3 = 0 में D = (−4)² − 4(2)(3) = −8 है, इसलिए वास्तविक मूल नहीं हैं। हर संख्या-पद्धति में मूल नहीं हैं, ऐसा न कहें। अध्याय वास्तविक मूलों पर काम करता है।

6. द्विघात सूत्र और प्राचल-जाँच

Selected explanations

1. Standard form comes after simplification

A quadratic equation in one variable is ax² + bx + c = 0, with real coefficients and a ≠ 0. First expand brackets, move every term to one side and collect like terms. The degree of that simplified polynomial decides the type. In the source Example 2(ii), x(x + 1) + 8 = (x + 2)(x − 2) becomes x + 12 = 0, so it is linear, despite the original x² terms. Example 2(iv), (x + 2)³ = x³ − 4, becomes 6x² + 12x + 12 = 0, so it is quadratic, despite the original cubes.

Source basis: printed pp 39-41. Our explanation; counterexamples labelled in the text are ours.

2. A root makes the equation true

A real number α is a root when aα² + bα + c = 0. It is also a zero of the polynomial ax² + bx + c. For 2x² − 3x + 1 = 0, x = 1 gives 2 − 3 + 1 = 0, so 1 is a root. A quadratic has at most two distinct real roots. A repeated root is one real value counted twice, not two different numbers. After solving, substitution in the original equation checks signs and fractions.

Source basis: printed pp 42. Our explanation; counterexamples labelled in the text are ours.

3. Factorisation and the zero-product rule

Write the polynomial as a product of linear factors. A product is zero only when at least one factor is zero. For 2x² − 5x + 3, split −5x into −2x − 3x: 2x(x − 1) − 3(x − 1) = (2x − 3)(x − 1). Thus the equation has roots 3/2 and 1. Do not divide the equation by a factor containing x: that can discard a root when that factor is zero. Expand the factors again to check that the original polynomial is recovered.

Source basis: printed pp 42-44. Our explanation; counterexamples labelled in the text are ours.

4. Repeated factors give equal roots

For 100x² − 20x + 1 = 0, the left side is (10x − 1)². Both linear factors give x = 1/10. The two equal roots are 1/10, 1/10; there is one distinct real solution. In 2x² − x + 1/8 = 0, the left side is 2(x − 1/4)², so both roots are 1/4. A non-zero constant factor does not change where a product is zero.

Source basis: printed pp 43-44. Our explanation; counterexamples labelled in the text are ours.

5. Discriminant: decide the nature first

For ax² + bx + c = 0 with a ≠ 0, compute D = b² − 4ac, using the sign of b and c as written. D > 0 gives two distinct real roots; D = 0 gives two equal real roots; D < 0 gives no real roots. For 2x² − 4x + 3 = 0, D = (−4)² − 4(2)(3) = −8, so there are no real roots. Say no real roots, not no roots in every number system. The chapter works with real roots.

Source basis: printed pp 44-47. Our explanation; counterexamples labelled in the text are ours.

6. Quadratic formula and parameter checks

When D ≥ 0, x = (−b ± √D)/(2a). The whole numerator is divided by 2a, and ± asks for both signs. At D = 0 both branches give −b/(2a). To find a parameter for equal roots, set D = 0 and also check a ≠ 0. For kx(x − 2) + 6 = 0, a = k, b = −2k, c = 6. D = 4k(k − 6), but k = 0 leaves 6 = 0, not a quadratic. Therefore only k = 6 is valid, with repeated root 1.

Source basis: printed pp 44-47. Our explanation; counterexamples labelled in the text are ours.

7. Algebraic roots versus a usable answer

Define the variable and unit before modeling a word problem. In the hall example, breadth x metres and length 2x + 1 metres give x(2x + 1) = 300. Factorising gives (x − 12)(2x + 25) = 0, so x = 12 or −12.5. A breadth cannot be negative: breadth 12m and length 25m are valid, and 12 × 25 = 300. Other contexts may require a positive integer count or a non-zero denominator. Do not reject a negative root without a stated context restriction. The word-problem aids below apply these context checks.

Source basis: printed pp 38-40,44-47. Our explanation; counterexamples labelled in the text are ours.

Example 2: expand before classifying

Parts (i) and (iii), step by step. Parts (ii) and (iv) are summarised in concept note 1 above.

NCERT jemh104, Reprint 2026-27, Example 2(i, iii), printed pp 40-41. Source PDF

(i) Expand the square

Use (x − 2)² = x² − 4x + 4. Subtract 2x − 3 from both sides: the constant −3 becomes +3 on the left. Collect like terms.

(x − 2)² + 1 = 2x − 3 x² − 4x + 4 + 1 = 2x − 3 x² − 4x + 5 − 2x + 3 = 0 x² − 6x + 8 = 0

In standard form, a = 1, b = −6 and c = 8. Since a ≠ 0, this is a quadratic equation.

(iii) Distribute, then collect

Multiply x by each term inside the bracket. Subtract x² + 1 from both sides. The coefficient of x² becomes 2 − 1 = 1, not zero.

x(2x + 3) = x² + 1 2x² + 3x = x² + 1 2x² + 3x − x² − 1 = 0 x² + 3x − 1 = 0

In standard form, a = 1, b = 3 and c = −1. Since a ≠ 0, this is also a quadratic equation.

Example 9: zero discriminant with fractions

NCERT jemh104, Reprint 2026-27, Example 9, printed p 46. Source PDF

3x² − 2x + 1/3 = 0

Read the coefficients with their signs: a = 3, b = −2 and c = 1/3. In b², square the whole value −2; do not write −4.

3x² − 2x + 1/3 = 0 D = (−2)² − 4 × 3 × (1/3) D = 4 − 4 = 0

The discriminant is zero, so the equation has two equal real roots. Keep the whole denominator 2a = 6.

x = −b/(2a) = −(−2)/(2 × 3) x = 2/6 = 1/3

The roots are 1/3 and 1/3, one distinct real value. Our substitution and factor checks:

At x = 1/3: 3(1/3)² − 2(1/3) + 1/3 = 1/3 − 2/3 + 1/3 = 0 3x² − 2x + 1/3 = 3(x − 1/3)²

3(x − 1/3)² = 0 gives the same repeated root. Do not report ±1/3: the negative value does not satisfy the original equation.

Example 8: a pole on a circular park

The park has diameter 13 m. Gates A and B are opposite ends of that diameter. Can a pole P on the boundary have distances from the gates differing by 7 m?

NCERT jemh104, Reprint 2026-27, Example 8, printed pp 45–46. Our explanation, translation and drawing. Source PDF

1. Turn the geometry into an equation

Choose the orientation AP ≥ BP. Let BP = x metres, so AP = x + 7 metres and x > 0. Because AB is a diameter and P is another boundary point, the angle APB is 90° (angle in a semicircle). Use Pythagoras, not AP + BP = AB.

(x + 7)² + x² = 13² 2x² + 14x − 120 = 0 x² + 7x − 60 = 0

2. Solve, then check the distance

The discriminant is positive, but real algebraic roots alone do not finish a distance problem. Reject −12 because a distance must be positive. With x = 5, BP = 5 m and AP = 12 m.

D = 7² − 4(1)(−60) = 289 x = (−7 ± √289)/2 x = (−7 ± 17)/2 x = 5 or −12

3. Check both original conditions

12² + 5² = 144 + 25 = 169 = 13², and 12 − 5 = 7 m. Both conditions hold. The arrangement is possible.

Our extra observation: the question gives an absolute difference, not which gate is farther away. Swapping A and B gives another valid orientation. Reflecting P across AB also keeps the same distances.

Why the formula works

Our supplementary explanation, not a printed derivation in this reprint. The source prints the formula and real-root condition on pp 44 and 47. NCERT jemh104, Reprint 2026-27

Make a perfect square

Let a, b, c be real and a ≠ 0. Start with ax² + bx + c = 0. Multiply both sides by 4a, then move 4ac and add b² to both sides. These operations are reversible because a ≠ 0.

ax² + bx + c = 0 4a²x² + 4abx + 4ac = 0 4a²x² + 4abx + b² = b² − 4ac (2ax + b)² = D, where D = b² − 4ac

Read the square carefully

The left side is a square, so a real solution requires D ≥ 0. Taking square roots gives both signs. Divide the whole numerator by 2a. This works even when a < 0: no inequality is being divided here.

For D ≥ 0: 2ax + b = ±√D 2ax = −b ± √D x = (−b ± √D)/(2a)

A short completing-square example

Our example: x² − 6x + 5 = 0. Half the x coefficient is −3; add its square, 9, to both sides. Do not add it to one side only.

x² − 6x = −5 x² − 6x + 9 = 4 (x − 3)² = 4 x − 3 = ±2 x = 1 or 5

The two values 1 and 5 satisfy the original equation. D = 0 makes the two formula branches equal; D < 0 gives no real roots.
