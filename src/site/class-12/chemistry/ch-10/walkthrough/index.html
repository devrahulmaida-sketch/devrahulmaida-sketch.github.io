Class 12 Chemistry - Chapter 10 - Biomolecules

Biomolecules Ka Visual Walkthrough

7 interactive scenes - sugar sort game (reducing vs non-reducing), glucose proof bench (5 reactions), alpha/beta anomer lab, glycosidic junction (sucrose/maltose/lactose/starch/cellulose), amino acid + peptide bond maker, protein structure levels, DNA base pairing + vitamin match, aur quiz.

1. Kaunsa Sugar? - Reducing Ya Nahi? ⭐⭐

Hydrolysis basis: MONOsaccharide (1 unit - glucose, fructose), DI (2 units - sucrose, maltose, lactose), POLY (bahut - starch, cellulose). REDUCING sugar = free carbonyl/anomeric C (Tollens/Fehling POSITIVE): glucose, fructose, maltose, lactose. SUCROSE = NON-reducing (dono anomeric C glycosidic bond me busy). Sugar dekho, class batao!

2. Glucose Proof Bench - Open Chain Ke Saboot ⭐⭐

Glucose ka open-chain structure 5 reactions se PROVE hota: HI/red P (heat) → n-hexane (straight 6-C chain); Br2 water → gluconic acid (-CHO oxidize, ALDEHYDE proof); HNO3 → saccharic acid (-CHO + -CH2OH dono oxidize); acetic anhydride → pentaacetate (5 -OH); HCN → cyanohydrin (carbonyl present). Reagent chuno, result dekho!

3. Anomer Lab - Alpha Ya Beta? ⭐⭐

Glucose actually RING me rehta: C1 ka -CHO C5 ke -OH se react karke 6-membered PYRANOSE ring. Naya chiral centre (ANOMERIC carbon C1) → do anomers: alpha-glucose (C1 OH NEECHE) aur beta-glucose (C1 OH UPAR). Open chain ⇌ cyclic equilibrium me, isliye glucose Tollens positive deta. Fructose = ketohexose, 5-membered FURANOSE ring.

4. Glycosidic Junction - Kaunsa Link, Kaunsa Sugar? ⭐⭐

Glycosidic linkage: do monosaccharides anomeric C pe -O- bond se jude (condensation, H2O nikalta). SUCROSE = glucose+fructose (C1-C2, dono anomeric busy = NON-reducing, hydrolysis se invert sugar). MALTOSE = 2 glucose (alpha 1→4, reducing). LACTOSE = galactose+glucose (beta 1→4, milk sugar, reducing). STARCH = alpha-glucose polymer (amylose + iodine = BLUE test), CELLULOSE = beta-glucose (humans digest NAHI), GLYCOGEN = animal starch.

5. Amino Acid + Peptide Bond Maker ⭐⭐

Amino acid = alpha-C pe -NH2 + -COOH + H + side chain (R). ~20 standard; ESSENTIAL body nahi banati (diet se: valine, leucine, lysine). ZWITTERION: -NH2 proton le leta (-NH3+) aur -COOH de deta (-COO-) = same molecule me + aur - charge (dipolar) → high melting, water-soluble, amphoteric. PEPTIDE BOND: ek ka -COOH dusre ke -NH2 se -CO-NH- (amide linkage), H2O nikalta. Polypeptide/protein aise hi banta.

6. Protein Structure - 4 Levels + Denaturation ⭐

PRIMARY = amino acids ka sequence (peptide bonds). SECONDARY = folding - alpha-helix (spring) ya beta-pleated sheet, H-bonds se. TERTIARY = 3D shape (side chains interact - disulphide bonds). QUATERNARY = multiple chains (haemoglobin). DENATURATION: heat/acid/agitation se 2°/3° TOOT jati (1° intact) → activity khatam, usually irreversible. Example: anda ubalna (egg white coagulate), dahi jamna. Enzymes = protein catalysts, highly specific (lock-and-key).

7. DNA Base Pairing + Vitamin Match ⭐⭐

Nucleotide = pentose sugar + phosphate + nitrogenous base. DNA: deoxyribose + A,T,G,C (double helix, antiparallel strands). RNA: ribose + A,U,G,C (T ki jagah U - KEY difference!). Complementary pairing: A=T (2 H-bonds), G≡C (3 H-bonds). Vitamins: water-soluble B,C (store NAHI, excess urine me); fat-soluble A,D,E,K (store, excess toxic). Deficiency: C→scurvy, D→rickets, A→night blindness, B1→beri-beri, K→bleeding.
