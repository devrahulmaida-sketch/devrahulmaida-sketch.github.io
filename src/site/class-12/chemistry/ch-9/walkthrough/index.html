Class 12 Chemistry - Chapter 9 - Amines

Amines Ka Visual Walkthrough

6 interactive scenes - classification game (N pe groups gino), banao machine (Hoffmann, Gabriel, nitro reduction), basic strength lab (pKb), 1/2/3-degree test bench, diazonium magic + aniline bench, aur quiz.

1. Kaunsa Class? - N Pe Groups Gino! ⭐⭐

Amines = NH3 ke derivatives (H alkyl/aryl se replace). 1°/2°/3° = NITROGEN pe kitne alkyl/aryl groups jude - 1° (ek, R-NH2), 2° (do, R2NH), 3° (teen, R3N). DHYAN: yeh alcohol wala carbon-logic NAHI hai - yahan N pe gino, carbon pe nahi! Simple (same groups) vs mixed (alag). Molecule dekho, class batao.

2. Banao Machine - Nitro / Ammonolysis / Hoffmann / Gabriel ⭐⭐

Nitro reduction: R-NO2 + Sn/HCl (ya H2/Ni) → R-NH2. Ammonolysis: R-X + NH3 → lekin MIXTURE (1°+2°+3°+quaternary, excess NH3 se 1° favour). HOFFMANN BROMAMIDE: amide + Br2/KOH → 1° amine, CHAIN EK C SE GHATTI. GABRIEL PHTHALIMIDE → PURE 1° amine (no mixture, par aromatic NAHI ban sakta).

3. Basic Strength Lab - pKb Ka Khel ⭐⭐

N ka lone pair H+ accept karta = base. pKb KAM = base ZYADA (ulta!). Gas phase: 3° > 2° > 1° > NH3 (pure +I effect). AQUEOUS me solvation bhi: methylamines 2° > 1° > 3° > NH3; ethyl: 2° > 3° > 1°. Aniline SABSE KAM (lone pair ring ke saath resonance me busy). Electron-donating group basicity badhata, -NO2 ghatata.

4. Test Bench - 1° 2° 3° Pehchano ⭐⭐

CARBYLAMINE: CHCl3 + alc KOH (heat) → isocyanide ki GANDI SMELL - SIRF 1° amine deta (aliphatic + aromatic dono). HINSBERG (C6H5SO2Cl): 1° → product KOH me SOLUBLE, 2° → insoluble, 3° → reaction NAHI. HNO2 (NaNO2+HCl): 1° aliphatic → N2 BUBBLES, 1° aromatic (273-278K) → diazonium, 2° → yellow OILY nitrosamine, 3° → kuch nahi.

5. Diazonium Magic - N2+ Ki Jagah Kuch Bhi ⭐⭐

Aniline + NaNO2 + 2HCl (273-278 K, COLD) → benzenediazonium chloride. -N2+ = BEST leaving group (N2 gas nikal jata) - uski jagah Cl/Br/CN/I/F/OH/H kuch bhi! SANDMEYER: CuCl→Cl, CuBr→Br, CuCN→CN. KI→I, HBF4+heat→F (Balz-Schiemann), H3PO2→H (benzene), H2O warm→OH (phenol). COUPLING: + phenol (alkaline, cold) → p-hydroxyazobenzene (ORANGE DYE).

6. Aniline Bench - Br2 Water aur Protection ⭐⭐

-NH2 = STRONGLY ACTIVATING, o/p-directing. Aniline + Br2 water → 2,4,6-TRIBROMOANILINE (WHITE PPT) - teeno positions ek saath! CONTROLLED substitution chahiye to pehle ACETYLATION (CH3COCl → acetanilide, -NH2 kam reactive = PROTECT), phir substitution (nitration → p-nitroaniline major), phir hydrolysis se -NH2 wapas.

7. Rapid Quiz - Amines Pakka? ⭐⭐

5 sawaal. Yaad rakho: N pe groups gino, Hoffmann = ek C kam, Gabriel = pure 1°, aqueous methylamines 2°>1°>3°, carbylamine sirf 1°, Sandmeyer CuCN → cyanobenzene.

Formula Recap - Screenshot Le Lo! ⭐

Classification ⭐⭐

1°/2°/3° = NITROGEN pe alkyl/aryl groups (carbon pe NAHI) | 1°: R-NH2 | 2°: R2NH | 3°: R3N | Simple (same groups) vs mixed | IUPAC: alkane+amine (ethanamine), 2°/3° me N-substituent (N-methylethanamine) | Aromatic = aniline (C6H5NH2)

Preparation ⭐⭐

Nitro: R-NO2 + Sn/HCl ya H2/Ni → R-NH2 | Ammonolysis: R-X + NH3 → MIXTURE (1°+2°+3°+quaternary; excess NH3 = 1° favour) | Nitrile R-CN + LiAlH4 → R-CH2-NH2 (chain +1 C) | HOFFMANN BROMAMIDE: RCONH2 + Br2/KOH → R-NH2 (EK C KAM) | GABRIEL PHTHALIMIDE = PURE 1° (aromatic NAHI)

Basic Strength ⭐⭐

N lone pair H+ accept = base | pKb KAM = base ZYADA | Aliphatic > aromatic (aniline lone pair resonance me busy) | GAS: 3° > 2° > 1° > NH3 (+I effect) | AQUEOUS methyl: 2° > 1° > 3° > NH3 (inductive+solvation+steric) | EDG basicity badhata, -NO2 ghatata

Distinguish Tests ⭐⭐

CARBYLAMINE (CHCl3+alc KOH): sirf 1° amine → isocyanide GANDI SMELL | HINSBERG (C6H5SO2Cl): 1° → KOH-soluble, 2° → insoluble, 3° → no reaction | HNO2: 1° aliphatic → N2 BUBBLES (alcohol), 1° aromatic (cold) → DIAZONIUM, 2° → yellow OILY nitrosamine, 3° → kuch nahi

Diazonium Salts ⭐⭐

Aniline + NaNO2+2HCl (273-278 K) → C6H5N2+Cl- | -N2+ = BEST leaving group | SANDMEYER: CuCl→C6H5Cl, CuBr→C6H5Br, CuCN→C6H5CN | KI→iodobenzene | HBF4+heat→fluorobenzene (Balz-Schiemann) | H3PO2→benzene | H2O warm→phenol | COUPLING + phenol → p-hydroxyazobenzene (orange AZO DYE)

Aniline Reactions ⭐⭐

-NH2 = strongly ACTIVATING, o/p-directing | Br2 water → 2,4,6-TRIBROMOANILINE (WHITE PPT) | ACETYLATION (CH3COCl) → acetanilide = -NH2 PROTECT (kam activating) | phir nitration → p-nitroaniline MAJOR | phir hydrolysis → -NH2 wapas | Controlled substitution = protect → react → deprotect
