1. Rutherford Scattering - Nucleus Ki Khoj ⭐

Gold foil: zyadatar alpha seedhe nikle, kuch deflect hue, bahut kam wapas aaye. Matlab atom mostly khaali hai aur ek chhota, dense, positive nucleus uska zyada mass rakhta hai. Impact parameter b chhota (nucleus ke paas) → bada deflection; b bada → lagbhag seedha. Limit: classical orbiting electron radiate karke nucleus me gir jaata - stable atom explain nahi hota.

1.0

2. Bohr Orbits - Radius aur Speed ⭐

Bohr: electron allowed (stationary) orbit me radiate nahi karta, aur angular momentum quantized: mvr = nh/(2π), n = 1, 2, 3... Hydrogen-like (one electron, charge Ze): r_n = a₀n²/Z, a₀ = 0.529 Å, v_n ≈ 2.19×10⁶ (Z/n) m/s. n badhe → orbit bada (n² se), speed kam. n = 1 sabse chhota orbit hai, n = 0 nahi hota. n = 2

3. Energy Levels aur Photon ⭐⭐

E_n = −13.6 Z²/n² eV (minus = bound). Transition n_i → n_f me photon energy = level DIFFERENCE: Eγ = 13.6 Z² (1/n_f² − 1/n_i²) eV, λ = hc/Eγ ≈ 1240/Eγ nm. n_i > n_f emission, n_i < n_f absorption. Ionization: n se n = ∞ (E = 0) tak 13.6Z²/n² eV. Photon energy kisi ek level ki energy nahi hoti!

4. Hydrogen Line Spectrum - Atom Ka Barcode ⭐

Levels discrete hain, isliye sirf selected wavelengths nikalte hain (line spectrum, continuum nahi). Rydberg: 1/λ = R Z² (1/n_f² − 1/n_i²), R ≈ 1.097×10⁷ m⁻¹. Lyman n_f = 1 (UV), Balmer n_f = 2 (visible + near UV), Paschen n_f = 3 (IR). n_i badhne pe lines series limit ke paas bheed me aati hain.

5. Rapid Quiz - Atoms Pakka? ⭐⭐

5 sawaal. Yaad rakho: Rutherford = tiny dense nucleus, r_n = 0.529 n²/Z Å, E_n = −13.6 Z²/n² eV, photon = level difference, Lyman UV / Balmer visible / Paschen IR.
