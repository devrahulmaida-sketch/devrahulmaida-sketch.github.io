1. Huygens Principle - Wavefronts aur Refraction ⭐⭐

Wavefront = same phase ke points ka surface, rays uske PERPENDICULAR. Huygens: har wavefront point secondary wavelets ka source, unka envelope next wavefront! Isi geometry se reflection (i = r) AUR refraction (n₁ sin i = n₂ sin r) dono milte hain. Medium change → speed v = c/n → wavelength badalti hai (λ₂ = λ₁/n₂), par FREQUENCY same rehti hai. Dekho wavefronts boundary pe kaise MUD jaate hain!

2. Superposition - Bright ya Dark? ⭐⭐

Do waves milte hain to displacements ADD hote hain. Path difference Δ = mλ → same phase → BRIGHT (constructive); Δ = (m+½)λ → opposite phase → DARK (destructive). Phase difference = 2πΔ/λ. PAR stable pattern sirf COHERENT sources se - same frequency + STABLE phase difference. Do independent bulbs KABHI stable fringes nahi dete (phase random!). Aur haan - energy gayab nahi hoti, bright fringes me REDISTRIBUTE hoti hai.

0.500λ

3. Young Ka Double Slit - β = λD/d ⭐⭐

Ek hi source se do slits → COHERENT sources phase-locked! Screen pe equally spaced fringes, fringe width β = λD/d. Bright y = mβ pe, dark y = (m+½)β pe, CENTRAL fringe hamesha BRIGHT. λ ya D badhao → fringes WIDER; slit separation d badhao → NARROWER. (CBSE: derivation nahi aati, final formula yaad rakho!) Color bhi λ ke saath badalta hai - sliders ghumao!

4. Single Slit Diffraction ⭐⭐

Slit ke ANDAR ke alag-alag points aaps me interfere karte hain - isliye light seedhi nahi jaati, PHAIL jaati hai! First minimum a sinθ = ±λ pe. CENTRAL maximum sabse CHAUDA (width ≈ 2Dλ/a, screen pe) aur sabse bright; side maxima ~half width aur bahut weak. TRAP: slit jitni NARROW (a chhota), spread utna ZYADA - intuition se bilkul ulta! Clear diffraction tab jab slit width λ ke aaspaas ho.

5. Rapid Quiz - Wave Optics Pakka? ⭐⭐

5 sawaal. Yaad rakho: β = λD/d (d ↑ → β ↓!), bright Δ = mλ aur dark Δ = (m+½)λ, independent bulbs se stable fringes NAHI, first minimum a sinθ = λ, narrower slit = WIDER spread, aur refraction me frequency SAME rehti hai!

Formula Recap - Screenshot Le Lo! ⭐

Wavefront + Huygens ⭐

Wavefront = same phase points ka surface; rays hamesha ⊥ wavefronts | Huygens: har point secondary wavelet deta hai, envelope = next wavefront | Geometry se i = r aur n₁ sin i = n₂ sin r | Medium me v = c/n, λₙ = λ/n, frequency SAME

Superposition + Coherence ⭐⭐

Bright: Δ = mλ | Dark: Δ = (m+½)λ | Phase difference = 2πΔ/λ | Coherent = same frequency + STABLE phase diff | Independent bulbs → koi stable fringes NAHI | Energy redistribute hoti hai, gayab nahi hoti

YDSE ⭐⭐

Fringe width β = λD/d | Bright y = mβ, dark y = (m+½)β | Central fringe hamesha BRIGHT | λ↑ ya D↑ → wider fringes; d↑ → narrower | Dono slits EK hi source se - tabhi phase locked

Diffraction ⭐⭐

Single slit first minima: a sinθ = ±λ | Central width ≈ 2λ/a (angular), ≈ 2Dλ/a (screen) | Central max ~2× chauda + brightest | a chhota → spread ZYADA | λ ~ a ho tab clear dikhta hai

YDSE vs Diffraction ⭐

YDSE: do coherent sources, equally spaced fringes β = λD/d | Single slit: aperture ke hi parts interfere, central band ~2× side bands | Ray optics jab λ ≪ feature size; wave optics jab phase aur spread matter kare

Traps ⭐

β ∝ 1/d hai, d ke proportional NAHI | Central fringe BRIGHT hoti hai | Dark ke liye (m+½)λ, mλ nahi | Do alag bulbs se fringes nahi banti | Narrower slit = WIDER spread | Refraction me frequency SAME, λ badalta hai
