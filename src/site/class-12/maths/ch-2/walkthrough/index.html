Inverse Trig Ka Visual Walkthrough

5 animated scenes - branch explorer, principal value machine, fold-trap lab, all-6 branch chart, aur quiz.

1. Branch Explorer - Answer Ka Ghar ⭐⭐

Inverse trig = VALUE se ANGLE wapas. Par har value ke infinite angles hote hain (sin periodic!) - isliye domain RESTRICT karke function ko one-one banate hain. Jo angle PRINCIPAL BRANCH se aata hai, wahi answer! Function chuno, x slider ghumao - curve pe point aur uska branch-ke-andar answer dekho. sin⁻¹x ≠ 1/sin x yaad rakho!

0.50

2. Principal Value Machine - Standard Values ⭐

Board exam ka bread-and-butter: standard values ke principal values. Method: pehle angle socho jiska sin/cos/tan ye value ho → phir BRANCH check karo → wahi answer (radians me!). Buttons dabao - teeno functions ka answer ek saath gauges pe dekho. Negative inputs pe dhyan: cos⁻¹ alag behave karta hai (π − cos⁻¹x)!

3. Fold Trap Lab - sin⁻¹(sin θ) ≠ θ! ⭐⭐

Sabse zyada marks katne wala trap: sin⁻¹(sin θ) = θ SIRF jab θ khud branch [−π/2, π/2] me ho. Bahar ho toh answer FOLD ho jaata hai - magenta curve dekho, wo zigzag hai! θ slider ko 90° se aage ghumao aur fold ko LIVE dekho. Highlighted band = principal branch. cos⁻¹(cos θ) ka bhi yahi scene hai, branch [0, π] ke saath.

120°

4. All-6 Branch Chart - Poora Parivaar ⭐⭐

6 functions, 6 branches - ek hi jagah yaad karo. sin⁻¹, cos⁻¹, tan⁻¹ toh pakke, par cot⁻¹ (domain R, branch (0,π)), sec⁻¹ aur cosec⁻¹ (|x| ≥ 1, beech ka gap!) bhi aate hain. Har button pe curve, domain, branch aur SHAPE dekho: sin⁻¹ increasing ↑, cos⁻¹ decreasing ↓, tan⁻¹ S-shape. Excluded points pe bracket OPEN!

5. Rapid Quiz - Inverse Trig Pakka? ⭐⭐

5 sawaal. Yaad rakho: branches (sin⁻¹ [−π/2,π/2], cos⁻¹ [0,π], tan⁻¹ (−π/2,π/2), cot⁻¹ (0,π) domain R, sec⁻¹ [0,π]−{π/2}, cosec⁻¹ [−π/2,π/2]−{0}); evaluation = angle socho → branch check; negative: sin⁻¹(−x)=−sin⁻¹x, cos⁻¹(−x)=π−cos⁻¹x; sin⁻¹(sin θ)=θ sirf branch ke andar; elementary properties DELETED!

Formula Recap - Screenshot Le Lo! ⭐

Concept ⭐

Inverse = value se angle | Domain restrict karke one-one banate (tabhi inverse FUNCTION!) | sin⁻¹x ≠ 1/sin x | Principal value = branch ke andar wala answer | Answer radians me

Branches ⭐⭐

sin⁻¹: [−π/2, π/2], domain [−1,1] | cos⁻¹: [0, π], domain [−1,1] | tan⁻¹: (−π/2, π/2), domain R

Branches 2 ⭐

cot⁻¹: (0, π), domain R (0, π EXCLUDED!) | sec⁻¹: [0, π] − {π/2}, domain |x| ≥ 1 | cosec⁻¹: [−π/2, π/2] − {0}, domain |x| ≥ 1

Evaluation ⭐

Angle socho → BRANCH check karo → wahi principal value | Negative input: sin⁻¹(−x) = −sin⁻¹x, tan⁻¹(−x) = −tan⁻¹x, cos⁻¹(−x) = π − cos⁻¹x | Standard values (1/2, √2/2, √3/2, 0, ±1) ratti honi chahiye!

Fold Trap ⭐⭐

sin⁻¹(sin θ) = θ SIRF θ ∈ [−π/2, π/2] | Bahar ho → equivalent branch angle (fold!) | cos⁻¹(cos θ) = θ sirf θ ∈ [0, π] | Ye trap har saal marks kaat-ta hai!

Syllabus + Shapes ⭐

Elementary properties (identities) DELETED - mat padho! | Focus: domain/range + principal values | Shapes: sin⁻¹ ↑ increasing, cos⁻¹ ↓ decreasing, tan⁻¹ S-shape (asymptotes ±π/2)
