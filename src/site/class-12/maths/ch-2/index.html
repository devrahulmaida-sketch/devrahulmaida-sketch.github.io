Notes language:

1. Inverse ke liye fixed branch chahiye

Angle ka sine ek number hai; number ka inverse sine ek angle hai. Jaise sin(π/6)=1/2 aur sin⁻¹(1/2)=π/6. Is page par saare angles radians mein hain.

Saare real angles par sine one-one nahi: π/6 aur 5π/6 ka sine same hai. Sine ka domain [−π/2,π/2] rakho; [−1,1] tak bijection milta hai aur inverse define hota hai. Baaki inverse trigonometric functions bhi fixed branches lete hain.

sin⁻¹x ka matlab arcsin x hai, 1/sin x nahi. 1/sin x, cosec x hai. Inverse ek principal angle deta hai, trigonometric equation ke saare solutions nahi.

2. Domain aur principal range

Domain allowed inputs hain; range possible outputs hain. Neeche table mein outputs angles hain. Square bracket endpoint ko include, round bracket exclude karta hai. R real numbers ka set hai.

Table NCERT ki principal-branch convention leta hai. Khaaskar cot⁻¹x ki range (0,π) hai, negative input par bhi. sec⁻¹ aur cosec⁻¹ ke liye |x|≥1 chahiye. Original function mein zero se division rokne ke liye midpoint exclude hota hai.

3. Value ke saath branch check karo

Inverse value ke liye aisa angle lo jiska trig value sahi ho, phir principal range check karo. cos⁻¹(−1/2) ke liye 2π/3 lo: cosine −1/2 hai aur 0≤2π/3≤π.

cot⁻¹(−1) mein 3π/4 lo, −π/4 nahi: range (0,π) hai. sec⁻¹(−2) mein 2π/3 lo kyunki cos(2π/3)=−1/2. cosec⁻¹(−2) mein −π/6 lo kyunki sin(−π/6)=−1/2.

Pehle input check karo. sin⁻¹(2) ka real value nahi: 2, [−1,1] se bahar hai. Yahan sirf real inverse functions padhe ja rahe hain.

4. Cancellation bina condition mat karo

sin(sin⁻¹x)=x, x in [−1,1] par sahi hai. Par sin⁻¹(sin θ)=θ tabhi jab θ in [−π/2,π/2] ho. Bahar ho to same sine wala branch ke andar ka angle chuno.

Example: sin⁻¹(sin(5π/6))=sin⁻¹(1/2)=π/6, 5π/6 nahi. Isi tarah cos⁻¹(cos(7π/6))=cos⁻¹(−√3/2)=5π/6, 7π/6 nahi.

Graph ka idea: original function ko bijective branch par restrict karo, phir y=x mein reflection lo. [−1,1] par sin⁻¹ increasing, cos⁻¹ decreasing hain; R par tan⁻¹ increasing hai. tan⁻¹ kabhi ±π/2 tak nahi pahunchta.

5. Ek useful identity aur coverage

−1≤x≤1 par sin⁻¹x+cos⁻¹x=π/2. Proof: α=sin⁻¹x lo, to α in [−π/2,π/2]. β=π/2−α in [0,π] hai aur cos β=sin α=x. Isliye β=cos⁻¹x.

Expressions mein domain pehle check karo. sin⁻¹x+cos⁻¹(2x) mein x aur 2x dono [−1,1] mein hone chahiye. Conditions ka intersection −1/2≤x≤1/2 hai. Alag arguments par upar ki identity mat lagao.

1. प्रतिलोम के लिए निश्चित शाखा चाहिए

कोण का ज्या मान एक संख्या है; संख्या का प्रतिलोम ज्या एक कोण है। जैसे sin(π/6)=1/2 और sin⁻¹(1/2)=π/6। इस पृष्ठ पर सभी कोण रेडियन में हैं।

सभी वास्तविक कोणों पर ज्या एकैकी नहीं: π/6 और 5π/6 का ज्या मान समान है। प्रांत [−π/2,π/2] तक सीमित करें तो [−1,1] पर एकैकी आच्छादक फलन मिलता है और प्रतिलोम परिभाषित होता है। अन्य प्रतिलोम त्रिकोणमितीय फलन भी निश्चित शाखाएं लेते हैं।

sin⁻¹x का अर्थ arcsin x है, 1/sin x नहीं। 1/sin x, cosec x है। प्रतिलोम एक मुख्य कोण देता है, त्रिकोणमितीय समीकरण के सभी हल नहीं।

2. प्रांत और मुख्य परिसर

प्रांत अनुमत इनपुट हैं; परिसर संभव आउटपुट हैं। नीचे सारणी में आउटपुट कोण हैं। वर्ग कोष्ठक सिरा शामिल करता है; गोल कोष्ठक नहीं करता। R वास्तविक संख्याओं का समुच्चय है।

सारणी NCERT की मुख्य शाखा परंपरा लेती है। विशेषकर cot⁻¹x का परिसर (0,π) है, ऋणात्मक इनपुट पर भी। sec⁻¹ और cosec⁻¹ के लिए |x|≥1 चाहिए। मूल फलन में शून्य से भाग रोकने के लिए मध्य बिंदु हटाया जाता है।

3. मान के साथ शाखा जांचें

प्रतिलोम मान के लिए ऐसा कोण चुनें जिसका त्रिकोणमितीय मान सही हो, फिर मुख्य परिसर जांचें। cos⁻¹(−1/2) के लिए 2π/3 लें: कोज्या −1/2 है और 0≤2π/3≤π।

cot⁻¹(−1) में 3π/4 लें, −π/4 नहीं: परिसर (0,π) है। sec⁻¹(−2) में 2π/3 लें क्योंकि cos(2π/3)=−1/2। cosec⁻¹(−2) में −π/6 लें क्योंकि sin(−π/6)=−1/2।

पहले इनपुट जांचें। sin⁻¹(2) का वास्तविक मान नहीं: 2, [−1,1] से बाहर है। यहां केवल वास्तविक प्रतिलोम फलन पढ़े जा रहे हैं।

4. बिना शर्त प्रतिलोम नहीं काट सकते

sin(sin⁻¹x)=x, x in [−1,1] पर सही है। पर sin⁻¹(sin θ)=θ तभी जब θ in [−π/2,π/2] हो। बाहर होने पर उसी ज्या मान वाला शाखा के अंदर का कोण चुनें।

उदाहरण: sin⁻¹(sin(5π/6))=sin⁻¹(1/2)=π/6, 5π/6 नहीं। इसी तरह cos⁻¹(cos(7π/6))=cos⁻¹(−√3/2)=5π/6, 7π/6 नहीं।

आलेख का विचार: मूल फलन को एकैकी आच्छादक शाखा तक सीमित करके y=x में परावर्तित करें। [−1,1] पर sin⁻¹ वर्धमान और cos⁻¹ ह्रासमान हैं; R पर tan⁻¹ वर्धमान है। tan⁻¹ कभी ±π/2 तक नहीं पहुंचता।

5. उपयोगी सर्वसमिका और कवरेज

−1≤x≤1 पर sin⁻¹x+cos⁻¹x=π/2। प्रमाण: α=sin⁻¹x लें, तो α in [−π/2,π/2]। β=π/2−α in [0,π] है और cos β=sin α=x। इसलिए β=cos⁻¹x।

व्यंजक में पहले प्रांत जांचें। sin⁻¹x+cos⁻¹(2x) में x और 2x दोनों [−1,1] में होने चाहिए। शर्तों का प्रतिच्छेद −1/2≤x≤1/2 है। अलग तर्कों पर ऊपर की सर्वसमिका न लगाएं।

ये चुनी बुनियादें और दस मौलिक प्रश्न हैं, पूरी पाठ्यपुस्तक/Exemplar प्रश्नावली, पिछले वर्षों के प्रश्न या पूरी JEE तैयारी नहीं। विस्तृत आलेख, लंबी सर्वसमिकाएं, प्रतिलोम त्रिकोणमितीय समीकरण और उन्नत रूपांतरण अभी शामिल नहीं हैं। परीक्षा अंक या पाठ्यक्रम बहिष्करण की भविष्यवाणी नहीं है; परीक्षा का दायरा वर्तमान आधिकारिक पाठ्यक्रम से जांचें।

1. An inverse needs a chosen branch

The sine of an angle is a number. The inverse sine of a number is an angle. For example, sin(π/6)=1/2 and sin⁻¹(1/2)=π/6. All angles on this page are in radians.

Sine on all real numbers is not one-one: π/6 and 5π/6 have the same sine. Restrict sine to [−π/2,π/2]; it becomes a bijection onto [−1,1], so its inverse is well defined. Other inverse trigonometric functions also use fixed branches.

sin⁻¹x means arcsin x, not 1/sin x. The latter is cosec x. An inverse gives one principal angle, not all solutions of a trigonometric equation.

2. Domain and principal range

Domain means allowed inputs. Range means possible outputs. In the table below, the outputs are angles. Square brackets include endpoints; round brackets exclude them. R is the set of real numbers.

The six rows use the NCERT principal-branch convention. In particular cot⁻¹x lies in (0,π), even for negative x. For sec⁻¹ and cosec⁻¹, the input must satisfy |x|≥1. The excluded midpoint prevents division by zero in the original function.

3. Evaluate, then check the branch

To find an inverse value, choose an angle with the required trigonometric value and check it lies in the principal range. For cos⁻¹(−1/2), use 2π/3: its cosine is −1/2 and 0≤2π/3≤π.

For cot⁻¹(−1), choose 3π/4, not −π/4, because the required range is (0,π). For sec⁻¹(−2), choose 2π/3, since cos(2π/3)=−1/2. For cosec⁻¹(−2), choose −π/6, since sin(−π/6)=−1/2.

Before evaluating, check the input. sin⁻¹(2) has no real value because 2 is outside [−1,1]. This page works only with real inverse functions.

4. Inverse cancellation has conditions

sin(sin⁻¹x)=x holds for x in [−1,1]. But sin⁻¹(sin θ)=θ only when θ is in [−π/2,π/2]. Outside that interval, find the angle in the branch with the same sine.

Example: sin⁻¹(sin(5π/6))=sin⁻¹(1/2)=π/6, not 5π/6. Likewise cos⁻¹(cos(7π/6))=cos⁻¹(−√3/2)=5π/6, not 7π/6.

Graph meaning: after restricting the original function to a bijective branch, reflect its graph in y=x to get its inverse. sin⁻¹ is increasing on [−1,1], cos⁻¹ is decreasing there, and tan⁻¹ is increasing on R. tan⁻¹ never reaches ±π/2.

5. A useful identity and honest scope

For −1≤x≤1, sin⁻¹x+cos⁻¹x=π/2. Reason: put α=sin⁻¹x, so α lies in [−π/2,π/2]. Then β=π/2−α lies in [0,π], and cos β=sin α=x. Therefore β=cos⁻¹x.

Domain checks still matter in expressions. For sin⁻¹x+cos⁻¹(2x), both x and 2x must lie in [−1,1]. Intersect the conditions to get −1/2≤x≤1/2. Do not apply the preceding identity to unequal arguments.

Q7 sin⁻¹(sin(5π/6)) nikalo.

Q8 cos⁻¹(cos(7π/6)) nikalo.
Answer dekho

Q10 sin⁻¹(1/2)+cos⁻¹(1/2) nikalo.
Answer dekho

Rule: Common input [−1,1] mein hai.

Steps: sin⁻¹(1/2)=π/6; cos⁻¹(1/2)=π/3.

Answer/check: π/2. Complementary-angle identity bhi check ho gayi.

Q7 sin⁻¹(sin(5π/6)) निकालें।
उत्तर देखें

नियम: प्रतिलोम ज्या की शाखा से बाहर काटें नहीं।

चरण: sin(5π/6)=1/2; sin⁻¹(1/2)=π/6।

उत्तर/जांच: π/6, 5π/6 नहीं। उत्तर [−π/2,π/2] में है।

Q8 cos⁻¹(cos(7π/6)) निकालें।
उत्तर देखें

नियम: समान कोज्या मान वाला [0,π] का कोण चुनें।

चरण: cos(7π/6)=−√3/2=cos(5π/6)।

उत्तर/जांच: 5π/6। यह [0,π] में है, 7π/6 नहीं।

Q9 sin⁻¹x+cos⁻¹(2x) का वास्तविक प्रांत निकालें।
उत्तर देखें

नियम: दोनों प्रतिलोम फलनों के इनपुट अनुमत हों।

चरण: −1≤x≤1 और −1≤2x≤1। [−1,1] और [−1/2,1/2] का प्रतिच्छेद लें।

उत्तर/जांच: [−1/2,1/2], दोनों सिरे शामिल। जांच: वहां 2x=±1 अनुमत है।

Q10 sin⁻¹(1/2)+cos⁻¹(1/2) निकालें।
उत्तर देखें

नियम: समान इनपुट [−1,1] में है।

चरण: sin⁻¹(1/2)=π/6; cos⁻¹(1/2)=π/3।

उत्तर/जांच: π/2। पूरक-कोण सर्वसमिका की जांच भी हो गई।

Q1 Find sin⁻¹(1/2).
Show answer

Rule: Choose an angle in [−π/2,π/2].

Steps: sin(π/6)=1/2.

Answer/check: π/6. Although 5π/6 has the same sine, it is outside this branch.

Q2 Find cos⁻¹(−1/2).
Show answer

Rule: The output lies in [0,π].

Steps: cos(2π/3)=−1/2.

Answer/check: 2π/3. The angle −2π/3 gives the same cosine but is outside the branch.

Q3 Find tan⁻¹(−1).
Show answer

Rule: The output lies in (−π/2,π/2).

Steps: tan(−π/4)=−1.

Answer/check: −π/4. The endpoints ±π/2 are excluded.

Q4 Using the NCERT branch, find cot⁻¹(−1).
Show answer

Rule: Use (0,π), not the inverse-tangent branch.

Steps: cot(3π/4)=cos(3π/4)/sin(3π/4)=−1.

Answer/check: 3π/4, not −π/4. Both have cotangent −1, but only one is in (0,π).

Q5 Find sec⁻¹(−2).
Show answer

Rule: The input must have |x|≥1; the output is in [0,π] excluding π/2.

Steps: cos(2π/3)=−1/2, so sec(2π/3)=−2.

Answer/check: 2π/3. It is in the branch and is not π/2.

Q6 Find cosec⁻¹(−2).
Show answer

Rule: Use [−π/2,π/2] excluding 0.

Steps: sin(−π/6)=−1/2, so cosec(−π/6)=−2.

Answer/check: −π/6. It is in the branch and not zero.

Q7 Find sin⁻¹(sin(5π/6)).
Show answer

Rule: Do not cancel outside the inverse-sine branch.

Steps: sin(5π/6)=1/2; sin⁻¹(1/2)=π/6.

Answer/check: π/6, not 5π/6. The answer lies in [−π/2,π/2].

Q8 Find cos⁻¹(cos(7π/6)).
Show answer

Rule: Choose the angle in [0,π] with the same cosine.

Steps: cos(7π/6)=−√3/2=cos(5π/6).

Answer/check: 5π/6. It is inside [0,π], whereas 7π/6 is not.

Q9 Find the real domain of sin⁻¹x+cos⁻¹(2x).
Show answer

Rule: Both inverse-function inputs must be allowed.

Steps: −1≤x≤1 and −1≤2x≤1. Intersect [−1,1] with [−1/2,1/2].

Answer/check: [−1/2,1/2], with both endpoints included. Check: 2x=±1 there is allowed.

Q10 Find sin⁻¹(1/2)+cos⁻¹(1/2).
Show answer

Rule: The common input lies in [−1,1].

Steps: sin⁻¹(1/2)=π/6; cos⁻¹(1/2)=π/3.

Answer/check: π/2. This also checks the complementary-angle identity.
