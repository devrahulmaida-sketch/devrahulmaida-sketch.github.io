4. Definite Integral - Area, King Aur Even/Odd ⭐⭐

Definite mein F(b) − F(a), +C nahi! Canvas pe AREA dekho. KING property: ∫₀ᵃf(x)dx = ∫₀ᵃf(a−x)dx - area mirror pe bhi SAME. EVEN function pe symmetric area DOUBLE, ODD pe ZERO!

Formula Recap - Screenshot Le Lo!

Basics ⭐

∫ = differentiation ka ulta | ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1) | ∫1/x dx = ln|x| + C | +C HAMESHA (indefinite)

Substitution ⭐⭐

Signal: function + uska derivative dikhe → andar wala = t | f′/f → ln|f| | ∫2x·sin(x²)dx: t = x² → −cos(x²) + C

By Parts ⭐⭐

∫uv = u∫v − ∫(u′∫v) | u choose: ILATE (Inverse, Log, Algebraic, Trig, Exp) | ∫ln x dx = x ln x − x + C

Special Forms ⭐

∫1/(x²+a²) = (1/a)tan⁻¹(x/a) | ∫1/√(a²−x²) = sin⁻¹(x/a) | Quadratic neeche → complete the square

Definite ⭐⭐

∫ₐᵇ = F(b) − F(a), +C NAHI | KING: ∫₀ᵃf(x)dx = ∫₀ᵃf(a−x)dx | EVEN: 2×∫₀ᵃ | ODD: 0 (symmetric limits)
