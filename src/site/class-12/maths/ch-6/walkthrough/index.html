1. Rate of Change - Speedometer Wala Derivative ⭐

Balloon phool raha hai: radius badhe to area kitni SPEED se badhta hai? Relation likho (A = πr²), dono taraf TIME ke respect me differentiate karo: dA/dt = 2πr·dr/dt. dr/dt NEGATIVE = leak (ghat raha!). Units zaroor likho!

2. Increasing / Decreasing - Sign Chart Machine ⭐⭐

f′(x) > 0 → increasing (graph UP), f′(x) < 0 → decreasing (graph DOWN). Critical points (f′=0) se number line todo, har zone me sign check karo. Slider se point chalao - tangent ka slope aur sign LIVE dekho. Yehi 4-marker ka framework!

3. Maxima & Minima - Peaks aur Valleys ⭐⭐

f(x) = x³ − 3x ka landscape. Critical points jahan f′=0: c = −1 aur c = 1. FIRST derivative test: sign + se − → MAX, − se + → MIN. SECOND derivative test: f″(c) < 0 → max (neeche-muh katora), f″(c) > 0 → min (upar-muh). Point chalao ya critical pe jump karo!

Formula Recap - Screenshot Le Lo! ⭐

Rate of Change ⭐

Relation likho → dono taraf d/dt | dA/dt = 2πr·dr/dt (circle), dV/dt = 4πr²·dr/dt (sphere) | Negative rate = quantity GHAT rahi | UNITS likhna mat bhoolo!

Increasing / Decreasing ⭐⭐

f′(x) > 0 → strictly increasing, f′(x) < 0 → strictly decreasing | Critical points (f′=0) se intervals todo → har zone me sign | Sign chart = 4-marker framework

First Derivative Test ⭐⭐

c critical point (f′=0 ya undefined) | f′: + → − at c => local MAX | f′: − → + at c => local MIN | sign same => na max na min

Second Derivative Test ⭐⭐

f″(c) < 0 → local MAX (neeche-muh katora) | f″(c) > 0 → local MIN (upar-muh) | f″(c) = 0 → test FAIL, first test lagao

Absolute Max/Min ⭐⭐

Closed [a,b]: critical points AUR endpoints a, b dono check | Sabse bada value = absolute max, sabse chhota = absolute min | Endpoints bhoolna = marks katna!

Word Problems + Deleted ⭐

Fixed perimeter max area = SQUARE | x+y=k max product: x=y=k/2 | Constraint se variable hatao pehle! | DELETED: tangents-normals equations, approximations (differentials)
