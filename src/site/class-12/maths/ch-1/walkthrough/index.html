Relations & Functions Ka Visual Walkthrough

5 animated scenes - relation explorer, equivalence class lab, function machine (one-one/onto!), counting calculator, aur quiz.

1. Relation Explorer - Grid Pe Khelo ⭐⭐

Relation R = A × A ka koi bhi SUBSET - pairs ka collection. Cells click karke apna relation banao aur LIVE checker dekho: Reflexive (diagonal sab on?), Symmetric (har pair ka mirror?), Transitive (chain complete?). Teeno ek saath = EQUIVALENCE! Diagonal (yellow cells) pe dhyan do - reflexive ka matlab poori diagonal.

2. Equivalence Class Lab - A Ki Partition ⭐⭐

Equivalence relation set ko CLASSES me baant deta hai - jaise school me sections! Equivalence class [a] = a se related SAB elements. Golden rule: do classes ya toh BARABAR hain ya DISJOINT - partial overlap impossible. Mod 2 (even/odd) aur mod 3 dono try karo - alag partitions dikhenge, dono valid!

3. Function Machine - One-One? Onto? ⭐⭐

Function = har input ka EXACTLY ek output (2 arrows ek input se = FUNCTION NAHI!). One-one (injective): alag inputs ka alag output - koi target pe 2 arrows nahi. Onto (surjective): range = codomain - har B element pe koi arrow. Dono ek saath = BIJECTIVE (inverse exist karta hai!). 5 presets dabao aur arrows gin-ke check karo.

4. Counting Calculator - Kitne Functions? ⭐⭐

Exam favourite: |A| = a (domain), |B| = b (codomain) ho toh - TOTAL functions = b^a (har input ke b choices). ONE-ONE = P(b,a) - pehle input ke b, agle ke b−1... (b < a toh ZERO - pigeonhole!). BIJECTIONS sirf jab |A| = |B|: tab n! Onto ka formula inclusion-exclusion se - slider ghumao aur pattern dekho!

5. Rapid Quiz - Relations Pakke? ⭐⭐

5 sawaal. Yaad rakho: relation = A×B ka subset, 2^(n²) total; R = reflexive (sab (a,a)), S = symmetric (ulta bhi), T = transitive (chain); equivalence = R+S+T → classes barabar ya disjoint; function = har input ka 1 output; one-one = alag output, onto = range = codomain, bijective = dono; counting: total |B|^|A|, one-one P(|B|,|A|), bijection n!

Formula Recap - Screenshot Le Lo! ⭐

Relation Basics ⭐

Relation = A × B ka SUBSET | Domain = first elements, Range = second elements | n elements pe total relations = 2^(n²) | Empty relation bhi valid!

Types ⭐⭐

Reflexive: (a,a) SABKE liye (poori diagonal!) | Symmetric: (a,b) ∈ R ⟹ (b,a) ∈ R | Transitive: (a,b),(b,c) ∈ R ⟹ (a,c) ∈ R | Chain ka dhyaan - transitive sabse zyada galti hoti hai!

Equivalence ⭐⭐

R + S + T TEENO chahiye | Equivalence class [a] = a se related sab | Classes: BARABAR ya DISJOINT (partition!) | Union of classes = poora set

Functions ⭐⭐

Function: har input ka EXACTLY 1 output | One-one: alag input → alag output | Onto: range = codomain | Bijective = one-one + onto → inverse exist karta hai!

Counting ⭐⭐

Total functions: |B|^|A| | One-one: P(|B|,|A|) (|B| < |A| → 0!) | Bijections (|A|=|B|=n): n! | Onto: inclusion-exclusion se

Traps ⭐

Empty relation: symmetric + transitive HAI, reflexive NAHI | Diagonal relation: equivalence HAI! | (a,a) na ho toh reflexive fail | One-one check = koi target pe 2 arrows nahi
