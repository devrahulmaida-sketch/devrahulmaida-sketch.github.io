Formula Recap - Screenshot Le Lo! ⭐

Order & Degree ⭐

Order = sabse HIGH derivative ki order | Degree = highest derivative ki POWER (fractions/radicals clear karke, polynomial form me!) | sin(dy/dx) = x → degree defined NAHI

Solutions ⭐⭐

General solution: arbitrary constants | Order n → EXACTLY n constants! | Particular: initial condition se constants fix | Verify: differentiate karke DE me DAALO

Variable Separable ⭐⭐

dy/dx = f(x)g(y) → dy/g(y) = f(x)dx → dono side ∫ | dy/dx = y → y = Aeˣ | dy/dx = x/y → y² − x² = C | DEFAULT pehla attempt!

Homogeneous ⭐

Pehchan: har term same degree / F(y/x) form | Substitute y = vx → dy/dx = v + x·dv/dx → separable ban jaata hai! | v = y/x wapas daalna mat bhoolo

Linear DE (IF) ⭐⭐

dy/dx + P(x)y = Q(x) → IF = e^(∫P dx) → y·IF = ∫(Q·IF)dx + C | dx/dy type: x·IF = ∫(Q·IF)dy + C | Pehle dy/dx ka coefficient 1 karo!

Exam Tips ⭐

Verify-solution 2-marker = free marks | IF formula direct 5-marker | Particular solution me C nikalna second half | y·dy/dx dikhe → NOT linear!
