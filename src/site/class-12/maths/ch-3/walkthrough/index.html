1. Order Explorer - Row Pehle, Column Baad ⭐

Matrix = numbers ka rectangular GRID (Excel sheet jaisa!). Order m × n = m rows, n columns. Element aᵢⱼ = i-th ROW, j-th COLUMN - "row pehle, column baad me"! m aur n badlo - grid aur TYPE dono dekho (row matrix, column matrix, square!). Highlighted cell ka ADDRESS padhna seekho!

2. Operations Lab - Add + Scalar ⭐

Addition/subtraction SIRF same-order matrices me - corresponding elements jodo (A + B = B + A, commutative!). Scalar multiplication kA = HAR element ko k se (sirf ek pe nahi!). k slider ghumao - poore matrix pe effect dekho. Dono operations element-by-element!

3. Multiplication Machine - Row × Column ⭐⭐

A(m×n) × B(n×p) possible SIRF jab A ke columns = B ki rows → result m×p. Element (i,j) = A ki row i · B ka column j (dot product - matching pairs multiply karke ADD!). TRAPS: AB ≠ BA generally! Aur AB = O ho sakta hai bina A ya B zero ke! Cell buttons se har element ka hisaab dekho!

4. Transpose + Symmetric Lab ⭐⭐

Transpose A′: rows ko COLUMNS bana do (m×n → n×m). Golden rule: (AB)′ = B′A′ - ORDER ULAT jaata hai! Symmetric: A′ = A (diagonal ke across mirror). Skew-symmetric: A′ = −A (diagonal ZAROOR 0!). POWER MOVE: har square matrix = ½(A+A′) [symmetric] + ½(A−A′) [skew] - direct 3-marker!

5. Rapid Quiz - Matrices Pakke? ⭐⭐

5 sawaal. Yaad rakho: order = rows × columns, aᵢⱼ = row i col j; add = same order only, kA = har element; multiply = row × column dot, AB ≠ BA, AB = O trap; transpose rules (AB)′ = B′A′; symmetric A′=A, skew A′=−A (diagonal 0!); ½(A+A′) + ½(A−A′) decomposition; (AB)⁻¹ = B⁻¹A⁻¹!

Formula Recap - Screenshot Le Lo! ⭐

Matrix Basics ⭐

Matrix = numbers ka grid | Order m × n = m rows, n cols | aᵢⱼ = row i, col j (row PEHLE!) | Equal: same order + same elements | Total elements = m×n

Types ⭐

Row: 1×n | Column: m×1 | Square: m=n | Zero O: sab 0 | Diagonal: sirf aᵢᵢ non-zero | Scalar: diagonal sab EQUAL | Identity I: diagonal 1 (AI = IA = A!) | Upper/Lower triangular

Operations ⭐⭐

Add/Subtract: SIRF same order, element-wise | A+B = B+A ✓ | kA = HAR element × k | Multiply: A(m×n)×B(n×p) = m×p (cols A = rows B!) | (i,j) = row i · col j

Multiplication Traps ⭐⭐

AB ≠ BA generally (commutative NAHI!) | AB = O possible bina A=O ya B=O! | Associative: (AB)C = A(BC) ✓ | Distributive: A(B+C) = AB+AC ✓ | Kabhi AB possible, BA possible hi nahi!

Transpose + Symmetric ⭐⭐

(A′)′ = A | (A+B)′ = A′+B′ | (kA)′ = kA′ | (AB)′ = B′A′ (order FLIP!) | Symmetric: A′ = A | Skew: A′ = −A (diagonal 0!) | A = ½(A+A′) + ½(A−A′)

Invertible + DELETED ⭐

A invertible ⟺ ∃B: AB = BA = I (B = A⁻¹, UNIQUE) | (AB)⁻¹ = B⁻¹A⁻¹ (order FLIP!) | Inverse nikalna = adjoint method (Ch 4!) | DELETED: elementary row/column operations - ab nahi padhne!
