2. Line Builder - Lambda Dial Ghumao ⭐⭐

Line fix karne ke liye: ek POINT + ek DIRECTION. Vector form: r⃗ = a⃗ + λb⃗. Cartesian: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c. λ = line pe ghoomne ka DIAL - λ=0 pe point a⃗, badhao to direction me chalo! Two-point mode me direction = Q − P khud niklega.

3. Do Lines Ka Angle - Dot Product Wapas ⭐

Lines ka angle = unke DIRECTION VECTORS ka angle: cos θ = (a₁a₂+b₁b₂+c₁c₂)/(√...·√...) - Ch 10 ka dot product! PERPENDICULAR: dot = 0. PARALLEL: DRs proportional. Angle hamesha ACUTE (modulus). Famous pairs try karo - (1,2,3)·(4,−5,2) = 0 dekho!

4. Shortest Distance - Skew Lines Ka Gap ⭐⭐

Skew lines: na parallel, na intersect - alag planes me. SD = |(a⃗₂−a⃗₁)·(b⃗₁×b⃗₂)| / |b⃗₁×b⃗₂| - "points ka difference, cross pe project, cross se divide"! SD = 0 → lines INTERSECT. Parallel lines: d = |b⃗×(a⃗₂−a⃗₁)|/|b⃗|. 5-marker ka fixed recipe - step-by-step dekho!

DCs & DRs ⭐⭐

l = cos α, m = cos β, n = cos γ | l²+m²+n² = 1 (golden!) | DRs (a,b,c) = DCs ke proportional | DRs→DCs: a/√(a²+b²+c²) etc | Two points DRs = (x₂−x₁, y₂−y₁, z₂−z₁)

Line Ki Equations ⭐⭐

Vector: r⃗ = a⃗ + λb⃗ (point + λ×direction) | Cartesian: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c | Two points: r⃗ = a⃗ + λ(b⃗−a⃗) | Denominator 0 = wo coordinate CONSTANT

Angle Between Lines ⭐

cos θ = (a₁a₂+b₁b₂+c₁c₂)/(√(a₁²+b₁²+c₁²)·√(a₂²+b₂²+c₂²)) | PERPENDICULAR: dot = 0 | PARALLEL: DRs proportional | Angle hamesha ACUTE (modulus!)

Shortest Distance (Skew) ⭐⭐

SD = |(a⃗₂−a⃗₁)·(b⃗₁×b⃗₂)| / |b⃗₁×b⃗₂| | SD = 0 → lines INTERSECT/coplanar | Recipe: a₂−a₁ → cross → dot → divide

Parallel Lines Ka SD ⭐

d = |b⃗×(a⃗₂−a⃗₁)| / |b⃗| | Dono lines ka SAME direction b⃗ use karo | Cartesian aaye to pehle vector form me convert karo
