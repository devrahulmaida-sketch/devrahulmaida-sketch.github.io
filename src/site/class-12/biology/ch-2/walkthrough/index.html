Human Reproduction Ka Visual Walkthrough

8 interactive scenes - male system, female system, gametogenesis, menstrual cycle graph, fertilization to implantation, placenta, parturition + lactation, aur quiz.

1. Male Reproductive System - Factory + Delivery 🧬

Testis me sperm banta hai, duct system se travel karta hai, accessory glands fluid add karti hain. Button se part chuno.

2. Female Reproductive System - Ovary Se Uterus Tak 🥚

Ovary -> fallopian tube -> uterus -> cervix -> vagina. Fertilization tube me, implantation uterus me - yeh confusion exam me pakka aata hai!

3. Gametogenesis - Sperm Aur Egg Kaise Bante Hain ⭐

Spermatogenesis: 1 cell se 4 sperms. Oogenesis: 1 cell se sirf 1 ovum (polar bodies degenerate).

4. Menstrual Cycle - 28 Din Ka Hormonal Dance ⭐⭐

Estrogen, progesterone aur LH ke graph ke saath 4 phases + pregnancy me hCG ka role. Phase chuno.

5. Fertilization Se Implantation Tak 🧫

Zygote -> cleavage -> morula (solid) -> blastocyst (hollow) -> implantation (~7 din). Stage by stage dekho.

6. Placenta Aur Pregnancy 🤰

Placenta exchange karta hai (khoon mix nahi hota) aur hormones banata hai. Gestation ~9 months, 3 trimesters.

7. Parturition Aur Lactation 🍼

Oxytocin ka positive feedback loop delivery chalata hai. Lactation: prolactin + colostrum + let-down.

8. Quiz - Human Reproduction Pakka? ⭐

5 sawaal - fertilization site, spermatogenesis, ovulation trigger, hCG, colostrum. Score 5/5 lao!

Formula / Fact Recap - Ek Nazar Mein

Male systemTestes scrotum me (2-2.5°C thande). Sertoli cells = nutrition, Leydig cells = testosterone. Flow: seminiferous tubules -> rete testis -> vasa efferentia -> epididymis -> vas deferens -> ejaculatory duct -> urethra. Glands: prostate, seminal vesicles, Cowper's. Semen = sperms + seminal plasma.
Female systemOvary (ova + estrogen + progesterone). Tube: infundibulum -> ampulla -> isthmus; fertilization = ampullary-isthmic junction. Uterus: perimetrium, myometrium, endometrium (implantation). Mammary: alveoli -> lactiferous duct -> nipple.
GametogenesisSpermatogenesis: 1 primary spermatocyte -> 4 sperms (head with acrosome, middle piece mitochondria, tail). Oogenesis: starts before birth, primary oocyte stuck in meiosis I, meiosis II after fertilization, 1 ovum + polar bodies.
Menstrual cycleMenstrual 1-5, follicular 6-13 (FSH, estrogen up), ovulation Day 14 (LH surge, Graafian follicle), luteal 15-28 (corpus luteum, progesterone). hCG keeps corpus luteum alive in pregnancy.
Fertilization + implantationSperm + secondary oocyte at ampullary-isthmic junction -> zygote (acrosome dissolves zona pellucida). Cleavage -> morula (solid) -> blastocyst (hollow: trophoblast + inner cell mass) -> implantation in endometrium ~7 days.
Placenta, birth, milkPlacenta: exchange, blood does NOT mix; hormones hCG, hPL, estrogen, progesterone (relaxin from ovary). Parturition: oxytocin positive feedback. Lactation: prolactin makes milk, colostrum has IgA, suckling -> oxytocin -> let-down.
