Formula / Fact Recap - Ek Nazar Mein

Pathogens + diseasesHealth = physical + mental + social. Typhoid: Salmonella typhi (Widal). Pneumonia: S. pneumoniae / H. influenzae. Cold: rhinovirus. Ringworm: fungi. Non-infectious (cancer) person to person nahi.
MalariaPlasmodium; infected female Anopheles -> sporozoites -> liver -> RBC -> burst + haemozoin -> fever. Gametocytes -> sexual cycle in mosquito. Mosquito = primary host. Amoebiasis, ascariasis, filariasis.
Innate vs acquiredInnate: skin/mucus, acid/saliva/tears, phagocytes, interferons. Acquired: specific, memory; primary slow/low, secondary fast/high. B = antibodies (humoral); T = cell-mediated. Antibody H2L2; IgA, IgE, IgG.
Vaccines + allergyActive = own antibodies + memory (vaccine, slow, long). Passive = ready antibodies (colostrum, antiserum, quick, short). Allergy: IgE + mast cell histamine. Autoimmunity: self attack.
AIDSHIV retrovirus: RNA -> DNA by reverse transcriptase -> integrates -> kills helper CD4 T cells. Spreads: sex, blood/needles, mother-to-child. NOT handshake/food. ELISA; ART suppresses, no cure.
Cancer + drugsBenign local; malignant invasive + metastasis. Carcinogens: tobacco, radiation. Biopsy, imaging; surgery/radiation/chemo/immuno. Opioids, cannabinoids, cocaine; needle sharing = HIV/HepB. Prevention + counselling.
