Formula / Fact Recap - Ek Nazar Mein

PopulationPopulation = one species, defined area, same time. Attributes: birth rate, death rate, density, sex ratio, age structure. N(t+1) = N + B + I - D - E. Density: coverage, biomass, tracks.
Age pyramidsBroad base = growing; roughly stable shape = stable; narrow base = declining. Groups: pre-reproductive, reproductive, post-reproductive.
GrowthExponential dN/dt = rN (J-shaped, unlimited). Logistic dN/dt = rN(1 - N/K) (S-shaped, limited). K = carrying capacity, not a universal fixed number.
Life historyTrade-off: many small vs few cared offspring. Salmon = single breeding; most birds/mammals = repeated. Breeding season depends on weather, food, predation.
InteractionsMutualism +/+ (lichen, pollination). Commensalism +/0 (orchid). Predation +/-, parasitism +/-. Competition -/-. Amensalism -/0.
Predation + competitionPredators regulate prey. Gause: same niche, limiting resources = exclusion. Resource partitioning helps coexistence. Brood parasitism: koel/cuckoo.
