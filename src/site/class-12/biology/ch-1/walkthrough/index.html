Class 12 Biology - Chapter 1 - Sexual Reproduction in Flowering Plants

Sexual Reproduction in Flowering Plants Ka Visual Walkthrough

8 interactive scenes - flower ka map, pollen grain, embryo sac (7 cells, 8 nuclei), pollination types, pollen tube + double fertilization, embryo development, seed-fruit-apomixis, aur quiz.

1. Flower Ka Map - Stamen aur Pistil 🌸

Flower me male part STAMEN (filament + anther) aur female part PISTIL (stigma + style + ovary). Neeche button se part chuno aur dekho kaunsa kya banata hai.

2. Microsporogenesis - Pollen Grain Kaise Bana? 🌼

Anther ke pollen sac me MMC meiosis se 4 microspores (tetrad) banata hai. Pollen grain ki do walls: exine (sporopollenin) aur intine.

3. Megasporogenesis - Embryo Sac Ka Banna 🥚

Ovule ke nucellus me MMC meiosis se 4 megaspores, 3 degenerate. 1 functional megaspore 3 baar mitosis karke 8 nuclei, 7 cells ka embryo sac banata hai. Stage by stage dekho.

4. Pollination - Pollen Ka Safar 🐝

Autogamy, geitonogamy, xenogamy, cleistogamy aur pollination agents. Geitonogamy ka trick: functionally cross, genetically self!

5. Pollen Tube aur Double Fertilization ⭐⭐

Pollen stigma pe germinate hota hai, tube style se micropyle tak jaata hai, 2 male gametes deta hai. Ek egg se (zygote 2n), doosra polar nuclei se (PEN 3n) - triple fusion!

6. Endosperm aur Embryo Development 🌱

PEN se endosperm (3n) banta hai jo embryo ko khana deta hai. Zygote -> proembryo -> globular -> heart-shaped -> mature embryo. Stage chuno.

7. Post-Fertilization - Seed, Fruit aur Apomixis 🍎

Ovule -> seed, ovary -> fruit. Apomixis (seed bina fertilization) vs parthenocarpy (fruit bina fertilization) - confusion mat karna!

8. Quiz - Reproduction Pakka? ⭐

5 sawaal - pollen exine, embryo sac, geitonogamy, false fruit, parthenocarpy. Score 5/5 lao!

Formula / Fact Recap - Ek Nazar Mein

Flower + pollenStamen = filament + anther (pollen factory). Pistil = stigma + style + ovary (ovules). MMC (2n) meiosis -> microspore tetrad (4 x n). Pollen: exine (sporopollenin, hardest) + intine (cellulose + pectin); vegetative + generative cell. Parthenium pollen = allergy.
Embryo sacOvule nucellus me MMC meiosis -> 4 megaspores, 3 degenerate, 1 functional. 3 mitosis -> 8 nuclei -> 7 cells: 3 antipodals + 2 synergids (filiform apparatus) + 1 egg + central cell (2 polar nuclei). 7-celled, 8-nucleate.
PollinationAutogamy (same flower), geitonogamy (same plant: functionally cross, genetically self), xenogamy (alag plants). Cleistogamous: flower khulta nahi (Commelina, Viola). Agents: wind, water, insects, birds, bats. Outbreeding: dichogamy, herkogamy, self-incompatibility, unisexual.
Double fertilizationPollen tube: stigma -> style -> micropyle -> synergid. 2 male gametes: male 1 + egg = zygote (2n, syngamy); male 2 + 2 polar nuclei = PEN (3n, triple fusion). Angiosperm special.
Embryo + endospermPEN -> endosperm (nuclear, cellular, helobial). Embryo: zygote -> proembryo -> globular -> heart-shaped -> mature (axis + cotyledons + plumule + radicle). Albuminous (maize, wheat) vs ex-albuminous (pea, bean).
Seed, fruit, apomixisOvule -> seed, ovary -> fruit, ovary wall -> pericarp, integuments -> seed coat, nucellus -> perisperm. False fruit: apple, strawberry (thalamus). Apomixis = seed w/o fertilization (clone). Parthenocarpy = fruit w/o fertilization. Polyembryony: citrus, onion.
