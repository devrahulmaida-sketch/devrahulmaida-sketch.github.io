Light and shadows: follow the path

A bright object may make light or reflect it. A shadow tells a different story: some light has been blocked. Read these original paper models by following the arrows.

From a source to a shadow

1. Bright does not always mean luminous

A luminous object emits its own light. A switched-on lamp is luminous. A book and the Moon do not produce their own visible light in these examples; they are non-luminous. The Moon looks bright because it reflects sunlight.

To see a non-luminous object, light from a source must reach it and some reflected light must enter the eye. The direction is source → object → eye, not eye → object. Brightness alone does not tell us where the light began.

Our arrows show selected paths and the direction of light travel. They are not solid rods, and they do not show every ray. Never look at the Sun or shine a light into anyone’s eyes. No observation activity is needed here.

Ask where the light starts
ObjectOwn visible light?Reason
Lamp onYesEmits light
BookNoReflects light
MoonNoReflects sunlight

Worked example

A student calls the Moon luminous because it looks bright. Is that enough?

Three steps

  1. Ask whether it makes its own visible light.
  2. Moonlight is reflected sunlight, not visible light made by the Moon.
  3. The Moon is non-luminous in this classification; brightness is not the test.

2. A shadow marks blocked light

In a uniform medium, such as the air in our ideal model, light travels in straight lines. An opaque object blocks the light that would otherwise reach part of a screen. That less-lit region on the screen is a shadow, not light emitted by the object.

Trace two boundary rays from the point source past the top and bottom edges of the object to the screen. Between their endpoints is the model shadow. The grey fill marks a region deprived of this source’s direct light; it is not another beam.

A source, a blocking object and a receiving surface are needed to show this shadow on a screen. A wall or the ground can be the receiving surface. Transparent materials transmit much light; translucent materials transmit some and scatter it. Even transparent objects can make faint shadows, so do not claim they never do.

What reaches the screen?
MaterialLight through itShadow caution
OpaqueNo trans­mitted lightDark shadow
Trans­lucentSome, scatteredLighter shadow
Trans­parentMuch passesFaint shadow possible

Worked example

A dark patch appears behind an opaque strip on a screen. What path explains it?

Three steps

  1. Start at the light source and trace straight paths through the uniform air.
  2. The strip blocks paths that would reach part of the screen.
  3. That region receives no direct light from the model source, so it is the shadow.

3. Keep the source and screen fixed

Compare the same opaque object with the same point source and fixed screen. Move only the object along the source-screen line. Closer to the source, its edge rays spread across a larger part of the screen; closer to the screen, the shadow is smaller. The object itself has not grown.

The two panels use the same scale, object height and source-to-screen distance. Only the object position changes. This is an ideal point-source model with parallel object and screen planes, not a measured lamp experiment. Real extended sources can produce softer edges.

Changing the surface colour of an otherwise identical opaque object does not make its shadow take that colour under the same white lighting. A shadow is not a coloured picture. Shape, size and sharpness depend on geometry and source size; a shadow alone may not identify the object.

Worked example

In panel A the same object is nearer the point source than in B. Which shadow is larger?

Three steps

  1. Check that the source, screen and object height are unchanged.
  2. Trace the edge rays to the screen in each panel.
  3. A spans a larger screen region. The shadow grows, not the object.

Trace, compare, explain

Q1. A lamp lights a book. Which way does light travel so you can see the book?

Show answer and reasoning

Three steps

  1. Start at the emitting lamp.
  2. Follow light to the book, then reflected light to the eye.
  3. Lamp → book → eye. The eye is the receiver.

Q2. An opaque strip is removed while the point source and screen stay. Does its shadow remain?

Show answer and reasoning

Three steps

  1. The strip was the blocker in this model.
  2. Removing it lets the previously blocked paths reach the screen.
  3. Its shadow disappears, provided no other blocker is introduced.

Q3. With the source and screen fixed, move the same object nearer the screen. What changes?

Show answer and reasoning

Three steps

  1. Keep object size and orientation the same.
  2. Its boundary rays now cover a smaller part of the screen.
  3. The shadow becomes smaller; the object size stays the same.

Q4. Two identical opaque cards differ only in surface colour. Must their shadows show those colours under the same white light?

Show answer and reasoning

Three steps

  1. The cards block light with the same outline and position.
  2. A shadow is reduced illumination, not a projected colour photograph.
  3. No. Surface colour alone does not make the shadow match the card.

प्रकाश और छाया: रास्ता पहचानें

चमकीली वस्तु अपना प्रकाश दे सकती है या दूसरे का प्रकाश परावर्तित कर सकती है। छाया बताती है कि कुछ प्रकाश रुका है। हमारे कागजी चित्रों में तीरों की दिशा देखें।

स्रोत से छाया तक

1. चमकना और प्रकाश देना अलग हैं

प्रकाशमान वस्तु अपना प्रकाश उत्सर्जित करती है। जलता हुआ विद्युत लैंप प्रकाशमान है। इन उदाहरणों में पुस्तक और चंद्रमा अपना दृश्य प्रकाश नहीं बनाते; वे अप्रकाशमान हैं। चंद्रमा सूर्य का प्रकाश परावर्तित करने से चमकता दिखता है।

अप्रकाशमान वस्तु देखने के लिए स्रोत का प्रकाश उस तक पहुँचे और कुछ परावर्तित प्रकाश आँख में आए। दिशा है स्रोत → वस्तु → आँख, आँख → वस्तु नहीं। केवल चमक से यह पता नहीं चलता कि प्रकाश कहाँ बना।

तीर प्रकाश के कुछ चुने रास्ते और चलने की दिशा दिखाते हैं। ये ठोस छड़ें नहीं और सभी किरणें भी नहीं हैं। सूर्य को कभी न देखें और किसी की आँख में प्रकाश न डालें। यहाँ देखने का कोई प्रयोग नहीं चाहिए।

प्रकाश कहाँ बना, पूछें
वस्तुअपना दृश्य प्रकाश?कारण
लैंप चालूहाँप्रकाश देता है
पुस्तकनहींपरावर्तन
चंद्रमानहींसूर्य का परावर्तन

हल किया उदाहरण

विद्यार्थी चंद्रमा को चमकीला देखकर प्रकाशमान कहता है। क्या इतना पर्याप्त है?

तीन चरण

  1. पूछें कि क्या वह अपना दृश्य प्रकाश बनाता है।
  2. चाँदनी सूर्य का परावर्तित प्रकाश है, चंद्रमा का बनाया दृश्य प्रकाश नहीं।
  3. इस वर्गीकरण में चंद्रमा अप्रकाशमान है; चमक कसौटी नहीं।

2. छाया में प्रकाश का रास्ता रुका है

एकसमान माध्यम में, जैसे हमारे आदर्श मॉडल की हवा में, प्रकाश सीधी रेखा में चलता है। अपारदर्शी वस्तु वह प्रकाश रोकती है जो पर्दे के एक भाग तक पहुँचता। पर्दे का कम रोशनी वाला भाग छाया है, वस्तु से निकला प्रकाश नहीं।

बिंदु स्रोत से वस्तु के ऊपरी और निचले किनारे को छूती दो सीमा किरणें पर्दे तक खींचें। उनके सिरों के बीच मॉडल की छाया है। धूसर भरा क्षेत्र इस स्रोत के सीधे प्रकाश से वंचित भाग है, कोई दूसरी किरण-पुंज नहीं।

पर्दे पर यह छाया दिखाने के लिए स्रोत, प्रकाश रोकने वाली वस्तु और प्रकाश ग्रहण करने वाला तल चाहिए। दीवार या जमीन भी यह तल हो सकती है। पारदर्शी पदार्थ से बहुत प्रकाश गुजरता है; पारभासी से कुछ गुजरता और बिखरता है। पारदर्शी वस्तु भी हल्की छाया बना सकती है, इसलिए कभी नहीं बनाती कहना गलत है।

हल किया उदाहरण

पर्दे पर अपारदर्शी पट्टी के पीछे गहरा भाग है। कौन-सा रास्ता इसे समझाता है?

तीन चरण

  1. प्रकाश स्रोत से एकसमान हवा में सीधी राहें बनाएँ।
  2. पट्टी कुछ राहें रोकती है जो पर्दे तक पहुँचतीं।
  3. उस क्षेत्र में मॉडल स्रोत का सीधा प्रकाश नहीं आता, इसलिए वह छाया है।

3. स्रोत और पर्दा स्थिर रखें

उसी अपारदर्शी वस्तु को उसी बिंदु स्रोत और स्थिर पर्दे के बीच तुलना करें। केवल वस्तु को स्रोत-पर्दे की दिशा में खिसकाएँ। स्रोत के पास उसके किनारों की किरणें पर्दे पर अधिक भाग घेरती हैं; पर्दे के पास छाया छोटी होती है। वस्तु खुद बड़ी नहीं हुई।

दोनों चित्रों में समान चित्र-पैमाना, वस्तु की ऊँचाई और स्रोत-पर्दा दूरी है। केवल वस्तु की जगह बदली है। यह बिंदु स्रोत का आदर्श मॉडल है, जिसमें वस्तु और पर्दे के तल समानांतर हैं; असली लैंप का माप नहीं। बड़े आकार के असली स्रोत से किनारे धुँधले हो सकते हैं।

बाकी सब समान रखते हुए अपारदर्शी वस्तु की सतह का रंग बदलने से समान सफेद रोशनी में छाया उस रंग की नहीं हो जाती। छाया रंगीन चित्र नहीं है। आकृति, आकार और स्पष्टता ज्यामिति तथा स्रोत के आकार पर निर्भर हैं; केवल छाया से वस्तु पहचानना हमेशा संभव नहीं।

A में वही वस्तु B से अधिक स्रोत के पास है। किसकी छाया बड़ी है?

तीन चरण

  1. जाँचें कि स्रोत, पर्दा और वस्तु की ऊँचाई नहीं बदले।
  2. हर चित्र में किनारों की किरणें पर्दे तक खींचें।
  3. A में अधिक पर्दा घिरा है। छाया बड़ी हुई, वस्तु नहीं।

Q1. लैंप से रोशन पुस्तक देखने में प्रकाश किस दिशा में चलता है?

उत्तर और कारण देखें

तीन चरण

  1. प्रकाश देने वाले लैंप से शुरू करें।
  2. प्रकाश पुस्तक तक, फिर परावर्तित होकर आँख तक आता है।

Q2. बिंदु स्रोत और पर्दा स्थिर हैं, अपारदर्शी पट्टी हटा दी। क्या उसकी छाया रहेगी?

उत्तर और कारण देखें

तीन चरण

  1. इस मॉडल में पट्टी अवरोध थी।
  2. हटाने पर पहले रुकी राहों से प्रकाश पर्दे तक आता है।
  3. कोई दूसरा अवरोध न हो तो उसकी छाया मिटती है।

Q3. स्रोत और पर्दा स्थिर रखकर वही वस्तु पर्दे के पास लाएँ। क्या बदलेगा?

उत्तर और कारण देखें

तीन चरण

  1. वस्तु का आकार और झुकाव वही रखें।
  2. किनारों की किरणें पर्दे का छोटा भाग घेरती हैं।
  3. छाया छोटी होगी; वस्तु का आकार नहीं बदलेगा।

Q4. दो एक जैसी अपारदर्शी पट्टियों का केवल रंग अलग है। समान सफेद प्रकाश में क्या छायाएँ वही रंग दिखाएँगी?

उत्तर और कारण देखें

तीन चरण

  1. पट्टियों की रूपरेखा और जगह समान हैं, इसलिए प्रकाश उसी तरह रुकता है।
  2. छाया कम रोशनी वाला भाग है, रंगीन तस्वीर नहीं।
  3. नहीं। केवल सतह का रंग छाया को वैसा रंग नहीं देता।

Light aur shadows: raasta follow karo

Bright object khud light bana sakta hai ya reflect kar sakta hai. Shadow ka matlab alag hai: kuch light block hui. In original paper models mein arrows follow karo.

Source se shadow tak

1. Bright ka matlab hamesha luminous nahi

Luminous object apni light emit karta hai. Switched-on lamp luminous hai. Book aur Moon in examples mein apni visible light nahi banate; ye non-luminous hain. Moon reflected sunlight ki wajah se bright dikhta hai.

Non-luminous object dekhne ke liye source ki light us tak pahunchni aur kuch reflected light eye mein aani chahiye. Direction source → object → eye hai, eye → object nahi. Sirf brightness light ka origin nahi batati.

Arrows selected paths aur light travel ki direction dikhate hain. Ye solid rods ya saari rays nahi hain. Sun ko kabhi mat dekho aur kisi ki eyes mein light mat shine karo. Yahan observation activity zaroori nahi.

Worked example

Student Moon ko bright dekhkar luminous bolta hai. Kya ye enough hai?

Teen steps

  1. Poochho kya Moon apni visible light banata hai.
  2. Moonlight reflected sunlight hai, Moon ki banayi visible light nahi.
  3. Is classification mein Moon non-luminous hai; brightness test nahi.

2. Shadow blocked light batati hai

Uniform medium mein, jaise hamare ideal model ki air, light straight lines mein travel karti hai. Opaque object woh light block karta hai jo screen ke ek part tak pahunchti. Screen ka less-lit region shadow hai, object ki emitted light nahi.

Point source se object ke top aur bottom edges ko just pass karti do boundary rays screen tak trace karo. Unke endpoints ke beech model shadow hai. Grey fill is source ki direct light se deprived region hai, koi doosri beam nahi.

Screen par ye shadow dikhane ke liye source, blocking object aur receiving surface chahiye. Wall ya ground bhi receiving surface ho sakte hain. Transparent material se much light pass hoti hai; translucent se kuch pass aur scatter hoti hai. Transparent object bhi faint shadow bana sakta hai, so never wala claim mat karo.

Worked example

Opaque strip ke peeche screen par dark patch hai. Kaunsa path explain karta hai?

Teen steps

  1. Light source se uniform air mein straight paths trace karo.
  2. Strip kuch paths block karti hai jo screen tak jaate.
  3. Us region ko model source ki direct light nahi milti, so woh shadow hai.

3. Source aur screen fixed rakho

Same opaque object ko same point source aur fixed screen ke saath compare karo. Sirf object ko source-screen line par move karo. Source ke closer, edge rays screen ka larger part cover karti hain; screen ke closer, shadow smaller hoti hai. Object khud grow nahi hua.

Dono panels mein same drawing scale, object height aur source-to-screen distance hai. Sirf object position badli. Ye ideal point-source model hai with parallel object aur screen planes, real lamp measurement nahi. Real extended sources softer edges bana sakte hain.

Otherwise same opaque object ka surface colour change karne se same white light mein shadow us colour ki nahi ho jaati. Shadow coloured picture nahi. Shape, size aur sharpness geometry aur source size par depend hain; shadow akeli object identify nahi kar sakti.

A mein same object B se source ke closer hai. Kaunsi shadow larger hai?

Teen steps

  1. Check karo source, screen aur object height unchanged hain.
  2. Dono panels mein edge rays screen tak trace karo.
  3. A screen ka larger region span karta hai. Shadow grow hoti hai, object nahi.

Trace, compare, explain karo

Q1. Lamp book ko light karta hai. Book dekhne ke liye light kis direction mein aati hai?

Answer aur reason kholo

Teen steps

  1. Emitting lamp se start karo.
  2. Light book tak, phir reflected light eye tak follow karo.
  3. Lamp → book → eye. Eye receiver hai.

Q2. Point source aur screen fixed hain. Opaque strip remove karo. Kya uski shadow rahegi?

Answer aur reason kholo

Teen steps

  1. Strip is model ka blocker tha.
  2. Remove karne par pehle blocked paths screen tak pahunchte hain.
  3. Koi doosra blocker introduce na ho to uski shadow disappear hoti hai.

Q3. Source aur screen fixed rakhkar same object screen ke nearer move karo. Kya badlega?

Answer aur reason kholo

Teen steps

  1. Object size aur orientation same rakho.
  2. Boundary rays screen ka smaller part cover karti hain.
  3. Shadow smaller hoti hai; object size same rehta hai.

Q4. Do identical opaque cards ka sirf surface colour alag hai. Same white light mein kya shadows wahi colours dikhayengi?

Answer aur reason kholo

Teen steps

  1. Cards same outline aur position se light block karte hain.
  2. Shadow reduced illumination hai, projected colour photo nahi.
  3. Nahi. Surface colour akela shadow ko card jaisa colour nahi deta.
