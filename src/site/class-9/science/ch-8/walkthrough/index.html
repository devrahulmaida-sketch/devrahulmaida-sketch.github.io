1. Path vs position

Round trip mein do alag answers ho sakte hain.

Distance

O→A 60 km, phir C at 25 km par return: total path 60+35=95 km. Source p 99.

Displacement

Start O, final C: displacement magnitude 25 km, not 95 km. Full return O par zero displacement,120 km distance. Source p 99.

2. Averages

Numerator pehle choose karo.

Speed

Total distance/total time. Pool trip 180 m in 60 s:3 m/s. Source pp 101-102.

Velocity

Displacement/total time. Pool swimmer start par lauti: displacement 0, average velocity 0. Constant-acceleration straight line mein hi (u+v)/2 rule use karo. Source pp 101-102.

3. Acceleration

Change in velocity ko time se divide karo.

Calculation

u=6 m/s, v=4 m/s, t=5 s gives a=(4−6)/5=−0.4 m/s². Original direction positive. Source p 103.

Sign trap

Negative a alone slowing down prove nahin karta. Velocity aur acceleration opposite direction mein hon to speed ghatti hai. Sign explanation meri vyakhya; source p 103 ke example se distinction.

4. Graph words

Height, slope aur area alag hain.

Slope

Distance-time slope speed; velocity-time slope acceleration. Horizontal distance-time means rest; horizontal velocity-time means constant velocity. Source pp 104-106.

Area

Velocity-time signed area displacement; speed-time area distance. Source positive-velocity examples pp 105-106; signed-area extension meri vyakhya. Original graphs is text box mein nahin.

5. Equations

Constant acceleration aur straight-line condition mat bhoolo.

Choose

v=u+at; s=ut+½at²; v²−u²=2 as. Units compatible, s signed displacement. Source pp 107-109.

Example

Source u 5 m/s→v 10 m/s in 5 s: a 1 m/s², s 37.5 m. Uniform acceleration assumed. Full graphical derivation covered nahin. Source p 109.

6. Circle

Constant speed ka matlab constant velocity nahin.

Direction

Circular motion mein direction changes continuously, isliye velocity changes aur acceleration nonzero hai. Source p 110.

One round

Distance 2πr; speed 2πr/T. Full round ke baad displacement 0, average velocity 0. Distance zero nahin. Source pp 110-111; round-trip link meri vyakhya.
