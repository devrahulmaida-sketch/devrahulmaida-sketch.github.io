1. Fundamental clue chuno

Same jagah rehna same group ka proof nahin.

Classification

Shared characteristics se groups bante hain. Defined nucleus, organisation aur nutrition broad clues hain; colour/habitat alone enough nahin. Source pp 80-82.

Hierarchy

Kingdom → Phylum/Division → Class → Order → Family → Genus → Species. Broad se narrow groups. Yeh archived textbook scheme hai. Source p 83.

2. Five kingdoms: old model

Cell type aur nutrition ko saath padho.

Monera vs Protista

Monera: defined nucleus ke bina prokaryotic. Protista: unicellular eukaryotic. Dono unicellular ho sakte hain, lekin cell structure alag hai. Source pp 83-84.

Other kingdoms

Fungi: heterotrophic eukaryotes, chitin wall. Plantae aur Animalia ko chapter cell wall/nutrition se contrast karta hai. Five-kingdom model historical hai, current final taxonomy nahin. Source pp 84-85.

3. Plant key

Conducting tissue aur seed enclosure ko alag sawal banao.

No seeds

Thallophyta: no differentiated root/stem/leaf body. Bryophyta: no specialised conducting tissue. Pteridophyta: differentiated body aur conducting tissue. Source pp 85-86.

Seeds

Gymnosperms: naked seeds. Angiosperms: seeds enclosed in fruit. Monocot one cotyledon, dicot two: source ka school model. Source pp 87-88.

4. Selected animal cues

Body-plan clues hain, full taxonomy nahin.

Body cavity

Platyhelminthes: no true coelom; Nematoda: pseudocoelom; Annelida: true body cavity aur segmentation. Historical chapter cues. Source pp 89-90.

Jointed legs

Arthropoda: jointed legs, open circulation. Echinodermata: marine animals aur water-driven tube system. Original chart/complete examples is walkthrough mein nahin. Source pp 90-91.

5. Vertebrate traps

Exception ko shortcut se erase mat karo.

Reptile heart

Source most reptiles mein three-chambered heart aur crocodiles mein four batata hai. All reptiles three kehna galat hai. Source p 93.

Mammals aur birds

Mammary glands milk deti hain. Platypus/echidna egg-laying mammals ke source examples hain. Feathers birds ka cue hain; all birds fly nahin. Source pp 93-94; flight caution meri vyakhya.

6. Scientific name

Capital aur small initial ko swap mat karo.

Two parts

Binomial mein generic aur specific name. Local language names se systematic naming ko alag samjho. Source p 96.

Writing rules

Genus initial capital, specific name initial small. Printed scientific name italics; handwritten words separately underlined. Source p 96.
