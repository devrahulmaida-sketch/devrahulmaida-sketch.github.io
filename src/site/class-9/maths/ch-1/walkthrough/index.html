1. Families ka map

Source pp 1-3; natural-number convention yahin specified hai.

N se Z

N: 1,2,3,...; W mein 0 add; Z mein negative integers bhi. Is source mein 0 natural nahin.

Q se R

Har integer m = m/1 rational. Q aur irrational numbers together R hain. p/q mein q ≠ 0 zaroori.

2. Infinite in between

Source p 4; r aur s distinct rationals hain.

Midpoint

r < s ke beech (r+s)/2 rational hai. Repeating this finds infinitely many rational numbers.

Example

1 = 6/6 aur 2 = 12/6. 7/6 se 11/6 tak ke five fractions inke beech. Common denominator order clear karta hai.

3. Decimal detective

Source pp 10-13; finite aur repeating notation alag rakho.

Rational

0.875 terminates; 0.333... recurring hai. Dono rational hain. Sirf endless decimal se irrational conclude mat karo.

Irrational

Non-terminating non-recurring decimal irrational hai. π irrational; 22/7 sirf approximation. √4 = 2 rational hai.

4. Repeating tail hatao

Source p 11; same infinite tails align hote hain.

Set up

x = 0.333...; 10 x = 3.333... . Teen dots yahan 3 ki endless repetition mean karte hain.

Subtract

10 x - x = 3, so 9 x = 3 aur x = 1/3. Meri vyakhya: finite 0.333 ko exact 1/3 mat likho.

5. Root aur conjugate

Source pp 22-23; equivalent value preserve karo.

Principal root

√4 = 2. x² = 4 ke two solutions ±2, lekin radical √4 ke two values nahin.

Rationalise

1/(2+√3) ko (2-√3)/(2-√3) se multiply: denominator 4-3 = 1; result 2-√3. Dono numerator aur denominator badalte hain.

6. Power with a condition

Source pp 25-26; positive bases aur rational exponents.

Read it

am/n = (a1/n)m for a > 0, n positive integer. Example 43/2 = (√4)3 = 8.

Common trap

ap × aq = ap+q, not apq. Power of a power mein exponents multiply: (ap)q = apq.
