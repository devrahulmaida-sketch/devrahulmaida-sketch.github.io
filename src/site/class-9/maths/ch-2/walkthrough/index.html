Polynomials

6 Text-box Walkthrough scenes + 5 fact questions. Hinglish captions. Animation ya video nahin.

1. Powers ka filter

Variable ki power aur constant radical ko alag dekho.

Allowed

x²+√2: √2 constant hai; variable x ki powers 2 aur 0. Polynomial. Source pp 29-32.

Not allowed

√x+3 aur x+1/x: variable powers 1/2 aur -1. One-variable polynomial nahin. Source p 29.

2. Terms versus degree

Ginti ke do alag sawaal.

Terms

x²+x+1 ke 3 terms: trinomial. Highest power 2: quadratic. Source pp 30-31.

Zero case

Nonzero constant 7 degree 0 hai. Zero polynomial ka degree undefined. Every real input zero polynomial ka zero hai. Source pp 31,50.

3. Value se zero

Input badlo, poora expression dobara evaluate karo.

Evaluate

p(x)=5 x-4 x²+3. p(-1)=5(-1)-4(-1)²+3=-6. Source Ex 2.2 Q 1, p 34; working meri vyakhya.

Test

a zero tabhi jab p(a)=0. ax+b, a≠0 ka unique zero -b/a. Nonzero constant has no zero. Source pp 33-34,50.

4. Remainder ka shortcut

Divisor ka zero pehle nikaalo.

Root of divisor

x+1=x-(-1), so a=-1. Remainder p(-1). x-1/2 ke liye a=1/2. Source pp 39-40.

Compute

For p(x)=(x+1)³: p(-1)=0; p(1/2)=27/8. Source Ex 2.3 Q 1(i,ii), p 40; working meri vyakhya.

5. Factor ka yes/no

Zero remainder hi factor banata hai.

Yes

x³+x²+x+1 at -1 gives 0. Therefore x+1 factor. Source Ex 2.4 Q 1(i), p 43; working meri vyakhya.

No

x⁴+x³+x²+x+1 at -1 gives 1. Therefore x+1 not factor. Source Ex 2.4 Q 1(ii), p 43; working meri vyakhya.

6. Split aur verify

Factorisation ko multiplication se check karo.

Split

12 x²-7 x+1 = 12 x²-3 x-4 x+1 = (3 x-1)(4 x-1). Source Ex 2.4 Q 4(i), p 44; working meri vyakhya.

Check

(3 x-1)(4 x-1)=12 x²-3 x-4 x+1=12 x²-7 x+1. Identity har real x par true. Source identity method pp 44-48; working meri vyakhya.
