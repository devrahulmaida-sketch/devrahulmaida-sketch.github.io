1. Source ka route

Same topic, different collection route.

Primary

Investigator khud apne objective ke liye collect kare: primary data (p 239). Our example: khud measured plant heights.

Secondary

Existing stored source se data le: secondary (p 239). Reliability/context check karo. Our example: existing school register se attendance.

2. Count aur boundary

Double-count rokna hai.

Frequency

Blood groups A 9+B 6+O 12+AB 3=30. O most common only among stated students (Ex 14.2 Q 1, p 245).

Classes

Ex 14.2 Q 2:0≤x<5 then 5≤x<10. Value 5 second class mein, dono mein nahin (p 245). Total frequency 40.

3. Graph ka meaning

Text explanation, not a drawn graph.

Bars

Bar graph categories ko separated equal-width bars se show karta hai (pp 247-249). Labels and scales matter.

Histogram

Adjacent continuous-class rectangles; area proportional to frequency. Unequal widths: f×reference width/class width. 7×10/20=3.5 (pp 250-252).

4. Mean ko weight do

Denominator total observations.

Raw

Goals sum 28 across 10 matches: mean 28/10=2.8, not necessarily an observed score (Ex 14.4 Q 1, p 269).

Frequency

Σ(fx)/Σf. Salary total ₹305000 for 60 workers: mean ₹15250/3≈₹5083.33. Historical exercise, not current wages (Ex 14.4 Q 5, p 269).

5. Median mein values

Sort before finding middle.

Odd n

Position(n+1)/2 ka VALUE median. Example n 9:5 th value (pp 266-267).

Even n

n 10 mein 5 th/6 th VALUES ka mean. Ex 14.4 Q 3: (x+x+2)/2=63, so x 62; middle 62, 64 (p 269).

6. Summary ka selection

One measure is not always best.

Mode

Most frequent observation. Goals list mein 3 four times, so mode 3; median 3 but mean 2.8 (p 269).

Audit

Extreme values mean ko affect kar sakti hain (p 268). Count, sorting, context, units and weighted denominator verify karo. No population/current-data claim.
