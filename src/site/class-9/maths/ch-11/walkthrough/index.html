2. Angle bisector

Same radius preserve karo.

Steps

B arc rays ko E,D par kaate. D,E se same radius>DE/2 ke arcs F par milao. Ray BF (p 189).

Reason

BE=BD, EF=DF, BF common. SSS then CPCT: angle EBF=DBF (p 189).

3. Perpendicular bisector

Dono properties chahiye.

Steps

A,B se equal radius>AB/2; dono taraf intersections P,Q. Line PQ meets AB at M (p 190).

Reason

SSS/SAS proof gives AM=BM and both adjacent angles 90°. Midpoint alone enough nahin (p 190).

4. 60° aur halving

Equilateral se shuru.

60°

A,D centres se same radius arcs E par milte hain. AD=AE=DE, so angle EAD=60° (p 191).

30°

60° ko p 189 method se bisect karo: equal halves 30°. This is written method for Ex 11.1 Q 3(i), no drawn answer (p 191).

5. Sum ya difference

D ki direction pehle decide karo.

Sum

BD=AB+AC same ray par. CD perpendicular bisector gives AD=AC, so AB+AC=BD (p 192).

Difference

AC>AB case: D opposite BX. Then AD=AB+BD=AC, so AC−AB=BD. Same-ray placement yahan galat case hoga (p 193).

6. Perimeter

Bisectors ka order.

Steps

XY=perimeter. X,Y par given base angles ko bisect karo; meeting point A. AX,AY perpendicular bisectors XY ko B,C par kaaten (p 194).

Reason

XB=AB and CY=AC, so BC+CA+AB=XY. Isosceles plus exterior-angle reasoning gives base angles (p 194).
