Existence

Uniqueness

4. Common point

At most one, exactly one nahin.

Contradiction

Source p 85: do distinct common points P,Q hon to unique-line axiom dono lines ko same bana dega.

Parallel case

Meri vyakhya: parallel distinct lines ka zero common point ho sakta hai. At most one includes zero.

5. Segment proof

Betweenness aur equality reason.

Midpoint length

Ex 5.1 Q 4,p 86: A-C-B, AC=CB. AB=AC+CB=2 AC, so AC=AB/2.

Subtract same length

Ex 5.1 Q 6,p 86: A-B-C-D, AC=BD. AB+BC=BC+CD; subtract BC, AB=CD.
