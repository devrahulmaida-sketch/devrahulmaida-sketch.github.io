5 animated scenes - calculus ke darwaze se tangent ki slope tak. Sliders ghumao, h ko zero karo, formulas feel karo.

1. Limit Kya Hai - KAREEB Jao, Touch Mat Karo

f(x) = (x² − 1)/(x − 1). x = 1 pe function UNDEFINED (0/0, hole hai graph me). Lekin slider se x ko 1 ke kareeb le jao - f(x) kis taraf ja raha hai?

LHL (left se) = RHL (right se) = 2 → limit EXIST karti hai, chahe f(1) defined na ho! lim(x→a) f(x) = L ka matlab: x → a to f(x) → L. Limit ≠ value: "kis taraf ja raha hai" vs "kahan khada hai".

2. Standard Limits - Zoom Karke Dekho

x → 0 pe sin x, x, aur tan x ek hi line ban jaate hain - isliye ratios 1 pe jaati hain. Zoom slider ghumao aur khud dekho.

lim(x→0) sin x / x = 1 lim(x→0) tan x / x = 1 lim(x→0) (eˣ − 1)/x = 1 lim(x→a) (xⁿ − aⁿ)/(x − a) = n·aⁿ⁻¹ (x radians me!) 0/0 aaye to factor/cancel ya standard limit pe lao - yehi 90% problems ka raasta.

3. Secant → Tangent - Derivative Ka Janm

Curve pe do points: P (fixed) aur Q = P + h. h slider ko zero ki taraf le jao - secant line ghoom ke TANGENT ban jaati hai. Slope kahan converge ho rahi hai, dekho.

f′(x) = lim(h→0) [f(x + h) − f(x)] / h - first principle (board exam me compulsory!). Geometric meaning: exact point pe tangent ki slope. x² ka derivative 2x - h → 0 karte hi secant slope 2x pe freeze.

4. Derivative Machine - Graph aur Uski Slope Ka Graph

Upar function, neeche uska derivative. Cursor ghumao: har point pe upar wale graph ki slope = neeche wale graph ki height. Max pe slope zero, steepest pe derivative max!

d/dx (xⁿ) = n·xⁿ⁻¹ (sin x)′ = cos x (cos x)′ = −sin x (eˣ)′ = eˣ (log x)′ = 1/x Product: (uv)′ = u′v + uv′. Quotient: (u/v)′ = (u′v − uv′)/v² - MINUS ka order yaad rakho!

5. Speedometer - Position → Velocity → Acceleration

Car ka position s(t) = t². Neeche uski velocity s′(t) aur acceleration s″(t) - har level upar wale ka derivative. Dekho: curve jab steep, velocity bara; acceleration constant (kyunki velocity straight line!).

s(t) position → s′(t) velocity → s″(t) acceleration - derivative ka derivative. Average speed = puri trip ka slope; derivative = speedometer ki ISS PAL ki reading. Class 12 calculus ka 70% base yehi hai!
