Complex Numbers Ka Visual Walkthrough

5 animated scenes - i ki rotation se ω triangle tak. Vector ghumao, roots plot karo, formulas feel karo.

1. i Kya Hai - Multiply = 90° Rotation

x² + 1 = 0 ka real solution nahi - isliye i = √−1 invent kiya (i² = −1). × i dabao aur dekho: har multiply vector ko 90° ghuma deta hai. Powers ka cycle: i, −1, −i, 1... repeat!

iⁿ trick: n ko 4 se divide karo, remainder dekho - i²⁰²³ = i³ = −i! Cycle of 4: i¹ = i, i² = −1, i³ = −i, i⁴ = 1.

2. Algebra Machine - Jod, Guna, Conjugate

z₁ = 3 + 2i (cyan), z₂ = 1 + 3i (pink). Add = vector jodna (parallelogram). Multiply = moduli guna, angles JUD jaate hain. Conjugate = x-axis ke across mirror - aur zz̄ hamesha REAL!

Multiply formula: (a + ib)(c + id) = (ac − bd) + i(ad + bc) - bas i² = −1 daal do. Division ka master key: numerator-denominator ko denominator ke conjugate se multiply karo - denominator real ban jaata hai (surds wali rationalize trick!).

3. Argand Plane - Modulus aur Argument

Har complex number = plane ka ek point. |z| = origin se doori (Pythagoras: √(a² + b²)), arg z = positive real axis se angle. Quadrant badlo - angle ka hisaab dekho (yahi pe sabse zyada galti hoti hai!).

arg z ka quadrant rule: pehle α = tan⁻¹|b/a| nikalo, phir QUADRANT dekho - Q1: α, Q2: 180° − α, Q3: −(180° − α), Q4: −α. Polar form: z = r(cos θ + i sin θ), r = |z|.

4. Discriminant - D Bataaega Roots Kis Type Ke

ax² + bx + c = 0 me D = b² − 4ac hi boss hai. D > 0: parabola x-axis ko 2 jagah kaate. D = 0: chhoo ke nikle (equal roots). D < 0: axis ke upar hi rahe - roots complex CONJUGATE pair me!

Real coefficients me complex roots HAMESHA conjugate pair me aate hain: 2 + 3i root hai to 2 − 3i pakka. Vieta: sum = −b/a, product = c/a. D < 0 ka matlab "no solution" NAHI - complex solution!

5. ω - Cube Roots of Unity Ka Triangle

x³ = 1 ke 3 roots: 1, ω, ω² jahan ω = (−1 + i√3)/2 - unit circle pe perfect triangle (120°-120°-120° pe)! × ω dabao: har multiply 120° rotation. Sum dekho: teeno vectors milke ZERO!

JEE favourite: 1 + ω + ω² = 0 aur ω³ = 1 - yeh 2 properties sawaalon ko 2 line me khatam karti hain. Bonus: (1 + i)² = 2i, (1 − i)² = −2i, 1/i = −i.
