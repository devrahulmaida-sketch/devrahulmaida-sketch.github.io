Long Notes — Full Explanation

Concept pakka karne ke liye — aaram se padho

Notes language:

1️⃣ i Ki Duniya — Imaginary Unit ⭐

  • Problem: x² + 1 = 0 ka koi real solution nahi (x² = −1!). Solution? Ek naya number invent karo: i = √−1 jiska i² = −1.
  • Powers of i ⭐ (cycle of 4): i¹ = i, i² = −1, i³ = −i, i⁴ = 1 — phir repeat! i^n nikalne ke liye n ko 4 se divide, remainder dekho (i^2023 = i^3 = −i!).
  • Complex number: z = a + ib form — a = real part Re(z), b = imaginary part Im(z). (b real number hai, "imaginary" sirf naam hai!)
  • Purely real: b = 0 (z = 5). Purely imaginary: a = 0 (z = 3i).
  • Equality: a + ib = c + id tabhi jab a = c AUR b = d — dono parts alag-alag match karne chahiye! ⭐
  • Complex numbers ka set C — R ⊂ C (har real number ek complex number hai with b = 0).

💡 Feel: i ek "upgrade" hai number system ka — jaise negative numbers ne subtraction ko hamesha possible kiya, i ne square roots ko hamesha possible kiya!

2️⃣ Complex Algebra — Jod, Ghata, Guna ⭐

  • Add/Subtract: real parts apas me, imaginary parts apas me — (a + ib) + (c + id) = (a + c) + i(b + d). Bas itna hi!
  • Multiply: normal expansion, bas i² = −1 substitute kar do: (a + ib)(c + id) = (ac − bd) + i(ad + bc). ⭐
  • Conjugate ⭐: z = a + ib ka conjugate z̄ = a − ib — sirf imaginary part ka sign flip. (z + z̄ = 2a real; z − z̄ = 2ib purely imaginary!)
  • zz̄ = a² + b² — hamesha REAL aur non-negative! Division ka master key yahi hai.
  • Division: (a + ib)/(c + id) = (a + ib)(c − id)/(c² + d²), sirf jab c + id ≠ 0 ho. Tab c² + d² positive hai.
  • Properties: z̄₁ + z̄₂ = conjugate of sum; conjugate of product = product of conjugates; z = z̄ ⟺ z real.

🎯 Division trick yaad rakho: "conjugate se multiply" — surds me rationalize karte the na (√2+1 ke saath √2−1), wahi game, bas i ke saath!

3️⃣ Modulus aur Argand Plane ⭐

  • Argand plane: complex number z = a + ib ko point (a, b) se dikhate hain — x-axis = real, y-axis = imaginary. Har complex number ek POINT (ya vector)!
  • Modulus ⭐: |z| = √(a² + b²) — origin se point ki DISTANCE. Hamesha non-negative real.
  • |z|² = zz̄ — modulus aur conjugate ka connection (proof: zz̄ = a² + b² hi to hai!).
  • Argument: z ≠ 0 ke liye positive real axis se direction angle θ lo. cos θ = a/|z| aur sin θ = b/|z| se quadrant chuno. tan θ = b/a sirf a ≠ 0 par use karo. a = 0 ho to b > 0 par π/2, b < 0 par −π/2 lo. Zero ka argument defined nahi hai.
  • Polar form: z = r(cos θ + i sin θ) jahan r = |z| — modulus-argument style me likhna.
  • Properties: |z₁z₂| = |z₁||z₂|; |z₁/z₂| = |z₁|/|z₂|; triangle inequality |z₁ + z₂| ≤ |z₁| + |z₂|. ⭐ Shart: z₂ ≠ 0.

💡 Feel: complex number = plane ka point. Modulus = origin se doori (Pythagoras!), argument = direction (angle). Real geometry, sirf "imaginary" naam!

4️⃣ Quadratic Equations — Ab Complex Roots Bhi ⭐

  • Standard form: ax² + bx + c = 0 (a ≠ 0). Quadratic formula ⭐: x = (−b ± √(b² − 4ac))/2a.
  • Quadratic ki shart: is section mein a, b, c real aur a ≠ 0 hain. Tab D = b² − 4ac real hai: D > 0 par alag real roots; D = 0 par repeated real root; D < 0 par non-real conjugate pair.
  • Complex roots hamesha conjugate pairs me aate hain ⭐: agar 2 + 3i ek root hai (real coefficients me), to 2 − 3i bhi root hai PAKKA.
  • Sum and product ⭐: roots ka sum = −b/a, product = c/a — Vieta's relations (bahut kaam ke!).
  • Equation banana: roots p, q hon → x² − (sum)x + product = 0 → x² − (p+q)x + pq = 0.
  • Example: x² + 2x + 5 = 0 → D = 4 − 20 = −16 → x = (−2 ± 4i)/2 = −1 ± 2i.

🎯 D < 0 ka matlab ab "no solution" NAHI — "complex solutions" hai! Complex numbers ke baad HAR quadratic solvable hai.

5️⃣ Square Roots of Complex Numbers aur Tricks

  • Square-root method: w = x + iy lo aur w² = a + ib rakho. Compare karo: x² − y² = a, 2xy = b. z ≠ 0 par do opposite roots; z = 0 par sirf w = 0.
  • Square roots, axis cases bhi: w = x + iy dhoondo jiska w² = z = a + ib ho. r = |z| lo. b ≠ 0 par x = √((r + a)/2) > 0 aur y = b/(2x) lo; dono roots w aur −w hain. b = 0 mein a > 0 ho to ±√a; a < 0 ho to ±i√(−a); z = 0 ka sirf ek root 0 hai. Har answer ko square karke check karo.
  • Cube roots of unity ⭐: x³ = 1 ke roots: 1, ω, ω² jahan ω = (−1 + i√3)/2. Properties: 1 + ω + ω² = 0, ω³ = 1. (JEE favourite!)
  • i ke powers simplify: (1 + i)² = 2i, (1 − i)² = −2i, (1 + i)(1 − i) = 2. ⭐
  • 1/i = −i (kyunki i × (−i) = −i² = 1) — division simplify karne me kaam aata hai.

💡 ω ka 1 + ω + ω² = 0 wala property questions ko 2 line me khatam kar deta hai — ratna nahi, SAMAJHNA: teen roots ek triangle banate hain Argand plane pe, sum zero!

1️⃣ i की दुनिया — काल्पनिक इकाई ⭐

  • समस्या: x² + 1 = 0 का कोई वास्तविक हल नहीं। समाधान? नई संख्या: i = √−1 जिसका i² = −1।
  • i की घातें ⭐ (4 का चक्र): i¹ = i, i² = −1, i³ = −i, i⁴ = 1 — फिर दोहराव! i^n के लिए n को 4 से भाग दो।
  • सम्मिश्र संख्या: z = a + ib — a = वास्तविक भाग, b = काल्पनिक भाग।
  • शुद्ध वास्तविक: b = 0। शुद्ध काल्पनिक: a = 0।
  • समानता: a + ib = c + id ⟺ a = c और b = d। ⭐

💡 i संख्या प्रणाली का "अपग्रेड" — जैसे ऋण संख्याओं ने घटाव संभव किया, i ने वर्गमूल संभव किया!

2️⃣ सम्मिश्र बीजगणित — जोड़, घटाव, गुणा ⭐

  • जोड़/घटाव: वास्तविक भाग आपस में, काल्पनिक आपस में — (a + c) + i(b + d)।
  • गुणा: सामान्य प्रसार, i² = −1 प्रतिस्थापित: (a + ib)(c + id) = (ac − bd) + i(ad + bc)। ⭐
  • संयुग्मी ⭐: z = a + ib का संयुग्मी z̄ = a − ib। (z + z̄ = 2a वास्तविक!)
  • zz̄ = a² + b² — सदैव वास्तविक और ऋणेतर!
  • भाग: (a + ib)/(c + id) = (a + ib)(c − id)/(c² + d²), केवल जब c + id ≠ 0 हो। तब हर c² + d² धनात्मक है।

🎯 भाग की युक्ति: "संयुग्मी से गुणा" — परिमेयकरण जैसा खेल!

3️⃣ मापांक और आर्गंड तल ⭐

  • आर्गंड तल: z = a + ib को बिंदु (a, b) से — x-अक्ष वास्तविक, y-अक्ष काल्पनिक।
  • मापांक ⭐: |z| = √(a² + b²) — मूलबिंदु से दूरी।
  • |z|² = zz̄ — मापांक-संयुग्मी संबंध।
  • कोणांक: z ≠ 0 के लिए धन वास्तविक अक्ष से दिशा का कोण θ लें। cos θ = a/|z| और sin θ = b/|z| से चतुर्थांश चुनें। tan θ = b/a केवल a ≠ 0 पर उपयोग करें। a = 0 में b > 0 पर π/2 और b < 0 पर −π/2 लें। शून्य का कोणांक परिभाषित नहीं है।
  • ध्रुवीय रूप: z = r(cos θ + i sin θ)।
  • गुण: |z₁z₂| = |z₁||z₂|; |z₁ + z₂| ≤ |z₁| + |z₂| (त्रिभुज असमिका)। ⭐

💡 सम्मिश्र संख्या = तल का बिंदु। मापांक = दूरी, कोणांक = दिशा।

4️⃣ द्विघात समीकरण — अब सम्मिश्र मूल भी ⭐

  • मानक रूप: ax² + bx + c = 0। द्विघात सूत्र ⭐: x = (−b ± √(b² − 4ac))/2a।
  • द्विघात की शर्त: यहां a, b, c वास्तविक और a ≠ 0 हैं। तब D = b² − 4ac वास्तविक है। D > 0 पर भिन्न वास्तविक मूल, D = 0 पर दो समान वास्तविक मूल और D < 0 पर अवास्तविक संयुग्मी युग्म मिलता है।
  • सम्मिश्र मूल सदैव संयुग्मी युग्म में ⭐: यदि 2 + 3i एक मूल है (वास्तविक गुणांकों में), तो 2 − 3i भी मूल है।
  • योग और गुणनफल ⭐: मूलों का योग = −b/a, गुणनफल = c/a।
  • समीकरण बनाना: मूल p, q → x² − (p+q)x + pq = 0।
  • उदाहरण: x² + 2x + 5 = 0 → D = −16 → x = −1 ± 2i।

🎯 D < 0 का अर्थ "कोई हल नहीं" नहीं — "सम्मिश्र हल" है!

5️⃣ सम्मिश्र वर्गमूल और युक्तियां

  • वर्गमूल की विधि: w = x + iy लें और w² = a + ib रखें। तुलना से x² − y² = a और 2xy = b हैं। z ≠ 0 पर दो विपरीत मूल हैं; z = 0 पर केवल w = 0 है।
  • वर्गमूल, अक्षों के मामले भी: w = x + iy ऐसा खोजें कि w² = z = a + ib हो। r = |z| लें। b ≠ 0 पर x = √((r + a)/2) > 0 और y = b/(2x) लें। दोनों मूल w और −w हैं। b = 0 में a > 0 हो तो ±√a; a < 0 हो तो ±i√(−a); z = 0 का केवल एक मूल 0 है। जांच के लिए उत्तर का वर्ग करें।
  • इकाई के घनमूल ⭐: x³ = 1 के मूल: 1, ω, ω² जहां ω = (−1 + i√3)/2। 1 + ω + ω² = 0, ω³ = 1।
  • सरलीकरण: (1 + i)² = 2i, (1 + i)(1 − i) = 2, 1/i = −i। ⭐

💡 1 + ω + ω² = 0 — तीनों मूल आर्गंड तल पर त्रिभुज बनाते हैं, योग शून्य!

1️⃣ The World of i — The Imaginary Unit ⭐

  • The problem: x² + 1 = 0 has no real solution (x² = −1!). The fix? Invent a new number: i = √−1 with i² = −1.
  • Powers of i ⭐ (cycle of 4): i¹ = i, i² = −1, i³ = −i, i⁴ = 1 — then it repeats! To find i^n, divide n by 4 and check the remainder (i^2023 = i³ = −i!).
  • Complex number: the form z = a + ib — a = the real part Re(z), b = the imaginary part Im(z). (b is a real number; "imaginary" is just a name!)
  • Purely real: b = 0 (z = 5). Purely imaginary: a = 0 (z = 3i).
  • Equality: a + ib = c + id only when a = c AND b = d — both parts must match separately! ⭐
  • The set of complex numbers is C — R ⊂ C (every real number is a complex number with b = 0).

💡 Feel: i is an upgrade to the number system — just as negatives made subtraction always possible, i makes square roots always possible!

2️⃣ Complex Algebra — Add, Subtract, Multiply ⭐

  • Add/Subtract: combine the real parts and the imaginary parts separately — (a + ib) + (c + id) = (a + c) + i(b + d). That is all!
  • Multiply: expand normally, then substitute i² = −1: (a + ib)(c + id) = (ac − bd) + i(ad + bc). ⭐
  • Conjugate ⭐: the conjugate of z = a + ib is z̄ = a − ib — flip only the imaginary part's sign. (z + z̄ = 2a is real; z − z̄ = 2ib is purely imaginary!)
  • zz̄ = a² + b² — always REAL and non-negative! This is the master key for division.
  • Division: (a + ib)/(c + id) = (a + ib)(c − id)/(c² + d²), only when c + id ≠ 0. The denominator c² + d² is then positive.
  • Properties: the conjugate of a sum = the sum of conjugates; the conjugate of a product = the product of conjugates; z = z̄ ⟺ z is real.

🎯 Remember the division trick: "multiply by the conjugate" — the same game as rationalizing surds (√2+1 with √2−1), just with i!

3️⃣ The Modulus and the Argand Plane ⭐

  • Argand plane: the complex number z = a + ib is shown as the point (a, b) — x-axis = real, y-axis = imaginary. Every complex number is a POINT (or vector)!
  • Modulus ⭐: |z| = √(a² + b²) — the DISTANCE from the origin. Always a non-negative real.
  • |z|² = zz̄ — the modulus-conjugate connection (zz̄ = a² + b² exactly!).
  • Argument: for z ≠ 0, θ is the direction from the positive real axis. Use cos θ = a/|z| and sin θ = b/|z| to choose the quadrant. tan θ = b/a is usable only if a ≠ 0. For a = 0, b > 0 gives π/2 and b < 0 gives −π/2. Zero has no defined argument.
  • Polar form: z = r(cos θ + i sin θ) where r = |z| — writing in modulus-argument style.
  • Properties: |z₁z₂| = |z₁||z₂|; |z₁/z₂| = |z₁|/|z₂|; the triangle inequality |z₁ + z₂| ≤ |z₁| + |z₂|. ⭐ Condition: z₂ ≠ 0.

💡 Feel: a complex number is a point on the plane. Modulus = distance from the origin (Pythagoras!), argument = direction (angle). Real geometry, just an "imaginary" name!

4️⃣ Quadratic Equations — Now with Complex Roots ⭐

  • Standard form: ax² + bx + c = 0 (a ≠ 0). The quadratic formula ⭐: x = (−b ± √(b² − 4ac))/2a.
  • Quadratic scope: in this section a, b, c are real and a ≠ 0. Then D = b² − 4ac is real: D > 0 gives distinct real roots; D = 0 gives a repeated real root; D < 0 gives a non-real conjugate pair.
  • Complex roots always come in conjugate pairs ⭐: if 2 + 3i is a root (with real coefficients), then 2 − 3i is a root for sure.
  • Sum and product ⭐: sum of roots = −b/a, product = c/a — Vieta's relations (hugely useful!).
  • Building an equation: if the roots are p, q → x² − (sum)x + product = 0 → x² − (p+q)x + pq = 0.
  • Example: x² + 2x + 5 = 0 → D = 4 − 20 = −16 → x = (−2 ± 4i)/2 = −1 ± 2i.

🎯 D < 0 no longer means "no solution" — it means "complex solutions"! With complex numbers, EVERY quadratic is solvable.

5️⃣ Square Roots of Complex Numbers and Tricks

  • Square-root method: write w = x + iy and require w² = a + ib. Comparing parts gives x² − y² = a and 2xy = b. For z ≠ 0 there are two opposite roots; at z = 0 only w = 0.
  • Square roots, including the axis cases: seek w = x + iy with w² = z = a + ib. Let r = |z|. For b ≠ 0, take x = √((r + a)/2) > 0 and y = b/(2x); both roots are w and −w. For b = 0 and a > 0 the roots are ±√a; for a < 0 they are ±i√(−a); for z = 0 the only root is 0. Check by squaring each answer.
  • Cube roots of unity ⭐: the roots of x³ = 1 are 1, ω, ω² where ω = (−1 + i√3)/2. Properties: 1 + ω + ω² = 0, ω³ = 1. (A JEE favourite!)
  • Handy simplifications: (1 + i)² = 2i, (1 − i)² = −2i, (1 + i)(1 − i) = 2. ⭐
  • 1/i = −i (since i × (−i) = −i² = 1) — useful for simplifying division.

💡 The property 1 + ω + ω² = 0 kills questions in two lines — do not just memorize it, SEE it: the three roots form a triangle on the Argand plane, so their sum is zero!

Practice language:
Q1 i^47 ka value?
Answer dekho

47 = 4×11 + 3 → i^47 = i³ = −i.

Q2 (2 + 3i)(1 − i) multiply karo.
Answer dekho

= 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i (i² = −1 substitute kiya!).

Q3 z = 3 + 4i. |z| aur z̄?
Answer dekho

|z| = √(9 + 16) = 5; z̄ = 3 − 4i.

Q4 (1 + i)/(1 − i) simplify karo.
Answer dekho

Conjugate se multiply: (1+i)²/((1)²+(1)²) = 2i/2 = i.

Q5 x² − 4x + 13 = 0 ke roots?
Answer dekho

D = 16 − 52 = −36 → x = (4 ± 6i)/2 = 2 ± 3i (conjugate pair!).

Q6 Ek quadratic ke roots 3 + 2i aur 3 − 2i hain. Equation?
Answer dekho

Sum = 6, product = 9 + 4 = 13 → x² − 6x + 13 = 0.

Q7 Real coefficients wali quadratic ka ek root 1 + i hai. Dusra?
Answer dekho

1 − i — complex roots hamesha conjugate pairs me aate hain.

Q8 1 + ω + ω² ka value? (ω = cube root of unity) Shart: ω ≠ 1, yani non-real cube root.
Answer dekho

0 — aur ω³ = 1. Dono properties JEE favourites hain. ω³ − 1 = (ω − 1)(ω² + ω + 1) = 0; ω − 1 nonzero hai, isliye 1 + ω + ω² = 0. ω = 1 hota to sum 3 hota.

Q9 z = 1 + i√3 ko polar form me likho.
Answer dekho

r = √(1+3) = 2, tan θ = √3 → θ = π/3 (Q1) → z = 2(cos π/3 + i sin π/3).

Q10 1/i ko a + ib form me?
Answer dekho

1/i = 1/i × (−i)/(−i) = −i/1 = −i (ya 0 − 1i).

Q1 i^47 का मान निकालें।
उत्तर देखें

नियम: i² = −1 और i⁴ = 1 हैं। पूर्णांक घातों में चार के बाद वही चक्र दोहरता है।

चरण: 47 = 4 × 11 + 3, इसलिए i^47 = (i⁴)^11 × i³ = 1 × (−i)।

उत्तर: −i। जांच: i से गुणा करने पर i^48 = 1 मिलता है।

Q2 (2 + 3i)(1 − i) का गुणा करें।
उत्तर देखें

नियम: सामान्य बीजगणित की तरह प्रसार करें, फिर i² की जगह −1 रखें।

चरण: 2 − 2i + 3i − 3i² = 2 + i + 3।

उत्तर: 5 + i। जांच: वास्तविक भाग 2 × 1 − 3 × (−1) = 5 और काल्पनिक भाग 2 × (−1) + 3 × 1 = 1 है।

Q3 z = 3 + 4i का मापांक |z| और संयुग्मी z̄ निकालें।
उत्तर देखें

अर्थ: मापांक मूलबिंदु से दूरी है। संयुग्मी में काल्पनिक भाग का चिह्न बदलता है।

चरण: |z| = √(3² + 4²) = √25 = 5; z̄ = 3 − 4i।

उत्तर: 5 और 3 − 4i। जांच: z z̄ = 9 + 16 = 25 = |z|²।

Q4 (1 + i)/(1 − i) को सरल करें।
उत्तर देखें

शर्त: हर 1 − i अशून्य है। अंश और हर दोनों को हर के संयुग्मी 1 + i से गुणा करें।

चरण: (1 + i)²/[(1 − i)(1 + i)] = (1 + 2i + i²)/(1 − i²) = 2i/2।

उत्तर: i। जांच: i(1 − i) = i − i² = 1 + i, अर्थात मूल अंश।

Q5 x² − 4x + 13 = 0 को हल करें।
उत्तर देखें

नियम: ax² + bx + c = 0 में x = (−b ± √D)/(2a), जहां D = b² − 4ac और a ≠ 0 है।

चरण: D = 16 − 52 = −36, इसलिए x = (4 ± 6i)/2।

उत्तर: x = 2 ± 3i। जांच: मूलों का योग 4 और गुणनफल 4 + 9 = 13 है।

Q6 3 + 2i और 3 − 2i मूलों वाला एक द्विघात समीकरण बनाएं।
उत्तर देखें

नियम: मूलों का योग S और गुणनफल P हो तो एक समीकरण x² − Sx + P = 0 है।

चरण: S = 6; P = (3 + 2i)(3 − 2i) = 9 + 4 = 13।

उत्तर: x² − 6x + 13 = 0। जांच: (x − 3)² + 4 = 0 से x = 3 ± 2i मिलता है। पूरे समीकरण का कोई अशून्य गुणज भी समतुल्य है।

Q7 वास्तविक गुणांकों वाले द्विघात समीकरण का एक मूल 1 + i है। दूसरा मूल निकालें।
उत्तर देखें

शर्त: गुणांक वास्तविक और अग्र गुणांक अशून्य है। तब अवास्तविक मूल संयुग्मी युग्म में आते हैं।

चरण: 1 + i के काल्पनिक भाग का चिह्न बदलें।

उत्तर: 1 − i। जांच: दोनों का योग 2 और गुणनफल 2 है। इनसे वास्तविक गुणांकों वाला समीकरण x² − 2x + 2 = 0 बनता है।

Q8 ω³ = 1 और ω ≠ 1 हो तो 1 + ω + ω² निकालें।
उत्तर देखें

अर्थ: ω इकाई का अवास्तविक घनमूल है। ω ≠ 1 की शर्त जरूरी है।

चरण: ω³ − 1 = (ω − 1)(ω² + ω + 1) = 0। अशून्य संख्या ω − 1 से भाग दें।

उत्तर: 0। जांच: ω = (−1 + i√3)/2 और ω² = (−1 − i√3)/2 का योग −1 है। यदि ω = 1 होता तो पूछा गया योग 3 होता।

Q9 z = 1 + i√3 को ध्रुवीय रूप में लिखें।
उत्तर देखें

अर्थ: z = r(cos θ + i sin θ), जहां r = |z| दूरी और θ दिशा का कोण है।

चरण: r = √(1 + 3) = 2। दोनों निर्देशांक धनात्मक हैं, इसलिए पहला चतुर्थांश लें। cos θ = 1/2 और sin θ = √3/2 से θ = π/3।

उत्तर: 2(cos(π/3) + i sin(π/3))। जांच: प्रसार से 1 + i√3 मिलता है। कोण रेडियन में हैं। किसी पूर्णांक k के लिए 2kπ जोड़ने पर भी वही संख्या मिलेगी।

Q10 1/i को a + ib रूप में लिखें।
उत्तर देखें

नियम: i² = −1 और i ≠ 0 है। अंश और हर दोनों को −i से गुणा करें।

चरण: 1/i = (−i)/(−i²) = (−i)/1।

उत्तर: −i = 0 + (−1)i। जांच: i × (−i) = 1।

Q1 Find i^47.
Show answer

Rule: i² = −1 and i⁴ = 1, so integer powers repeat every four.

Step: 47 = 4 × 11 + 3. Thus i^47 = (i⁴)^11 × i³ = 1 × (−i).

Answer: −i. Check: multiplying by i gives i^48 = 1.

Q2 Multiply (2 + 3i)(1 − i).
Show answer

Rule: expand as usual, then replace i² by −1.

Step: 2 − 2i + 3i − 3i² = 2 + i + 3.

Answer: 5 + i. Check: the real part is 2 × 1 − 3 × (−1) = 5; the imaginary part is 2 × (−1) + 3 × 1 = 1.

Q3 For z = 3 + 4i, find its modulus |z| and conjugate z̄.
Show answer

Meaning: the modulus is distance from the origin; the conjugate reverses the imaginary part’s sign.

Step: |z| = √(3² + 4²) = √25 = 5; z̄ = 3 − 4i.

Answer: 5 and 3 − 4i. Check: z z̄ = 9 + 16 = 25 = |z|².

Q4 Simplify (1 + i)/(1 − i).
Show answer

Condition: the denominator 1 − i is not zero. Multiply top and bottom by its conjugate 1 + i.

Step: (1 + i)²/[(1 − i)(1 + i)] = (1 + 2i + i²)/(1 − i²) = 2i/2.

Answer: i. Check: i(1 − i) = i − i² = 1 + i, recovering the numerator.

Q5 Solve x² − 4x + 13 = 0.
Show answer

Rule: for ax² + bx + c = 0, x = (−b ± √D)/(2a), where D = b² − 4ac and a ≠ 0.

Step: D = 16 − 52 = −36, so x = (4 ± 6i)/2.

Answer: x = 2 ± 3i. Check: the roots add to 4 and multiply to 4 + 9 = 13.

Q6 Form a quadratic equation with roots 3 + 2i and 3 − 2i.
Show answer

Rule: if the roots have sum S and product P, one equation is x² − Sx + P = 0.

Step: S = 6; P = (3 + 2i)(3 − 2i) = 9 + 4 = 13.

Answer: x² − 6x + 13 = 0. Check: (x − 3)² + 4 = 0 gives x = 3 ± 2i. Any nonzero multiple gives an equivalent equation.

Q7 A quadratic with real coefficients has root 1 + i. Find the other root.
Show answer

Condition: the coefficients are real and the leading coefficient is nonzero. Non-real roots then occur in conjugate pairs.

Step: change the imaginary part’s sign in 1 + i.

Answer: 1 − i. Check: their sum is 2 and product is 2, giving the real-coefficient equation x² − 2x + 2 = 0.

Q8 Find 1 + ω + ω² when ω³ = 1 and ω ≠ 1.
Show answer

Meaning: ω is a non-real cube root of unity. The condition ω ≠ 1 matters.

Step: ω³ − 1 = (ω − 1)(ω² + ω + 1) = 0. Divide by ω − 1, which is nonzero.

Answer: 0. Check: ω = (−1 + i√3)/2 and ω² = (−1 − i√3)/2 sum to −1. If ω were 1, the requested sum would be 3.

Q9 Write z = 1 + i√3 in polar form.
Show answer

Meaning: z = r(cos θ + i sin θ), where r = |z| and θ gives its direction.

Step: r = √(1 + 3) = 2. Both coordinates are positive, so θ is in quadrant I; cos θ = 1/2 and sin θ = √3/2 give θ = π/3.

Answer: 2(cos(π/3) + i sin(π/3)). Check: expanding gives 1 + i√3. Angles are in radians; adding 2kπ, for any integer k, gives the same number.

Q10 Write 1/i in a + ib form.
Show answer

Rule: i² = −1 and i ≠ 0. Multiply numerator and denominator by −i.

Step: 1/i = (−i)/(−i²) = (−i)/1.

Answer: −i = 0 + (−1)i. Check: i × (−i) = 1.
