Conic Sections Ka Visual Walkthrough

5 animated scenes - cone kaato, eccentricity ghumao, focus-directrix ka balance dekho, ellipse ki string khicho, hyperbola ke asymptote chase karo.

1. Cone Kaato - Ek Cone, Chaar Curves

Double cone ko plane se kaatne se hi saare conics bante hain! Plane ki tilt decide karti hai kaunsa curve milega. Button dabao, plane ghoomta dekho!

Yaad rakho: plane axis ke PERPENDICULAR → circle. Thoda tilt → ellipse. Slant line (generator) ke PARALLEL → parabola. Aur zyada steep → dono nappes kaat ke hyperbola!

2. Eccentricity Morph - Ek Number, Poori Family

Har conic = focus se doori / directrix se doori = e wale points. Slider ghumao: e = 0 circle, e < 1 ellipse, e = 1 parabola, e > 1 hyperbola. Curve AANKHON ke saamne morph hota hai!

eccentricity e0.50
Polar form: focus ko origin maano, to curve r = l/(1 + e·cosθ) hai. e badhao to curve khulta jaata hai - ellipse band hota hai, parabola/hyperbola infinity tak jaate hain!

3. Parabola Lab - Barabar Distance Ka Game

Parabola: focus (a, 0) aur directrix x = -a se BARABAR doori wale points. a badlo, point slide karo - dono distances hamesha EQUAL aayengi. Latus rectum (focus se guzarne wala chord) = 4a.

a (focus kitna door)a = 0.80
Standard forms (4): y² = 4ax (right), y² = -4ax (left), x² = 4ay (up), x² = -4ay (down). Sign direction batata hai, 4a hamesha latus rectum!

4. Ellipse Lab - String Property

Ellipse: do foci se dooriyon ka SUM hamesha 2a - isiliye dhaga (string) bandh kar pencil ghumao to ellipse banta hai! a aur b badlo, foci aur shape dono dekho. c = √(a² - b²), e = c/a.

a (semi-major)a = 2.40
b (semi-minor)b = 1.50
Standard: x²/a² + y²/b² = 1 (a > b). Foci (±c, 0), latus rectum = 2b²/a. b jitna a ke paas, utna GOL; b chhota, utna CHAPTA!

5. Hyperbola Lab - Difference Ka Curve

Hyperbola: foci se dooriyon ka DIFFERENCE hamesha 2a (mod me). Do branches, do asymptotes y = ±(b/a)x - curve unke CLOSE jaata hai par TOUCH nahi karta. c = √(a² + b²), e = c/a > 1.

aa = 1.20
bb = 1.10
Standard: x²/a² - y²/b² = 1. Foci (±c, 0), latus rectum = 2b²/a. Asymptote ke SAATH-SAATH bhaagta hai par kabhi mil nahi paata!

Formula Pack - Screenshot Le Lo

Eccentricity

e = 0 → circle | e < 1 → ellipse | e = 1 → parabola | e > 1 → hyperbola

Parabola

y² = 4ax → focus (a,0), directrix x = -a, latus rectum = 4a | PF = P(directrix) hamesha

Ellipse

x²/a² + y²/b² = 1 → c = √(a²-b²), foci (±c,0), e = c/a < 1, PF₁+PF₂ = 2a, LR = 2b²/a

Hyperbola

x²/a² - y²/b² = 1 → c = √(a²+b²), foci (±c,0), e = c/a > 1, |PF₁-PF₂| = 2a, LR = 2b²/a, asymptotes y = ±(b/a)x

Circle

x² + y² + 2gx + 2fy + c = 0 → centre (-g,-f), r = √(g²+f²-c) | ellipse ka special case (e = 0)
