Set Basics ⭐

set = WELL-DEFINED collection (rule clear!) | a ∈ A, b ∉ A | roster: V = {a,e,i,o,u} | set-builder: V = {x : x vowel hai} | order/repetition matter nahi | N (1,2,3...), W (0,1,2...), Z (integers), Q (p/q), R (number line)

Types + Equal vs Equivalent

φ = empty (sirf EK hi empty set!) | finite vs infinite | singleton = 1 element | EQUAL = same elements {1,2,3}={3,2,1} | EQUIVALENT = sirf same count {1,2,3} ~ {a,b,c} | n(φ) = 0 | U = universal (context ka sabse bada)

Subsets + Power Set ⭐

A ⊆ B: A ke saare elements B me | har set apna subset, φ HAR set ka subset | proper ⊂: A ≠ B | P(A) = saare subsets ka set → n(P(A)) = 2ⁿ | proper subsets: 2ⁿ − 1 | non-empty proper: 2ⁿ − 2 | 2ⁿ kyun? har element: aao ya na aao = 2 choice

Operations + Counting ⭐

A∪B = OR (kisi me bhi) | A∩B = AND (dono me) | A−B = A me jo B me nahi | A′ = U − A (NOT) | disjoint: A∩B = φ | n(A∪B) = n(A) + n(B) − n(A∩B) | 3 sets: +singles −pairs +triple

Laws + De Morgan ⭐⭐

commutative/associative/distributive - algebra jaisa | DE MORGAN: (A∪B)′ = A′∩B′ aur (A∩B)′ = A′∪B′ - complement andar jaake ∪↔∩ FLIP! | identity: A∪φ=A, A∩U=A, A∪U=U, A∩φ=φ | idempotent: A∪A=A∩A=A
