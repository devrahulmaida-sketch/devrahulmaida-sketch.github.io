Selected foundations

Calculation se pehle domain, symbols aur assumptions padho.

Notes language:

1. Set ka membership rule clear ho

  • Arth: Set ek well-defined collection hai. Diye rule se clear hona chahiye ki object member hai ya nahi.
  • Symbols: x ∈ A matlab x member hai; x ∉ A matlab member nahi. Braces set batate hain, sequence nahi.
  • Example: 2 se 5 tak integers ka set {2, 3, 4, 5} hai. Bina test ke "good players" clear rule nahi.
  • Hamari jaanch: Preference se chuni gayi fixed named list bhi set hai. List ya rule do; "good" ka matlab khud se mat maano.

2. Roster, condition aur domain

  • Roster: Har alag member ek baar likho. {1, 2, 2, 3} = {3, 1, 2}; order aur repeats se set nahi badalta.
  • Set-builder: {x ∈ Z : x² = 9} mein x integer hai aur condition satisfy karta hai. Colon ka matlab "aisa ki".
  • Domain zaroori: Z mein answer {−3, 3}, N mein {3}. Yahan NCERT ki tarah N = {1, 2, 3, ...} liya hai.
  • Hamari jaanch: Pehle domain padho, phir condition solve karo, phir har member check karo. Shuru ke kuch terms se infinite pattern unique zaroori nahi.

3. Empty, singleton, finite aur infinite

  • Empty: ∅ = {} mein koi member nahi. Yeh finite hai aur n(∅) = 0.
  • Singleton: {0} ka member 0 hai. {∅} ka member ∅ hai. Dono mein ek member, par dono sets alag hain.
  • Finite ya infinite: Finite set mein distinct members ki sankhya koi nonnegative integer hoti hai. N infinite hai; last natural number nahi.
  • Hamari jaanch: Braces dekho: ∅, {∅} aur {{∅}} alag objects hain. Sabse bahar ke braces ke seedhe andar wale objects gino.

4. Equality, subset aur membership alag

  • Equality: A = B tab jab members bilkul same hon. Do finite sets ka count same hote hue members alag ho sakte hain.
  • Subset: A ⊆ B matlab A ka har member B mein hai. Equality allowed hai; A ⊆ A aur ∅ ⊆ A.
  • Notation: Yahan A ⊊ B proper subset hai, equality nahi. NCERT mein ⊂ equality-allowed subset hai; OpenStax aksar ise proper subset ke liye leta hai. Convention padho.
  • Hamari jaanch: A = {1, 2} ke liye 1 ∈ A aur {1} ⊆ A, lekin {1} ∉ A. ∈ aur ⊆ ko interchange mat karo.

5. Intervals real numbers ke sets hain

  • Endpoints: a < b par (a, b) dono ends ko nahi leta; [a, b] dono leta hai. Square bracket us endpoint ko include karta hai.
  • Mixed interval: (−2, 3] = {x ∈ R : −2 < x ≤ 3}. 3 included, −2 excluded; beech ke fractions bhi included.
  • Infinity: [0, ∞) sab nonnegative real numbers hain. Infinity real endpoint nahi, isliye wahan round bracket.
  • Hamari jaanch: Positive-length interval mein infinitely many reals hain, chahe integers kam hon. Domain integer na kahe to sirf integers mat likho.

6. Power set aur empty-set exception

  • Arth: P(A) mein A ke saare subsets aate hain. A = {a, b} par P(A) = {∅, {a}, {b}, {a, b}}.
  • Finite count: n distinct members ki har include/exclude choice independent hai: n(P(A)) = 2^n. ∅ aur A dono counted hain.
  • Restrictions: Proper subsets: 2^n − 1. Nonempty proper: 2^n − 2 sirf n ≥ 1 par. n = 0 par nonempty proper subsets zero hain, −1 nahi.
  • Hamari jaanch: P(∅) = {∅}, count 1. Ek specified member zaroor chahiye aur n ≥ 1 ho to baaki n−1 free choices se 2^(n−1) subsets milte hain.

7. Union, intersection aur disjoint

  • Union: A ∪ B mein A ya B ya dono ke members hain. OR inclusive hai, "exactly one" nahi.
  • Intersection: A ∩ B mein common members hain. A = {1, 2, 3}, B = {3, 4} par union {1, 2, 3, 4}, intersection {3}.
  • Disjoint: A ∩ B = ∅ yani koi common member nahi. Alag sets zaroori nahi disjoint hon.
  • Hamari jaanch: A ⊆ B ho to A ∪ B = B aur A ∩ B = A. Venn regions relation dikhate hain; unka area automatically count ke proportional nahi.

8. Difference aur complement ka direction

  • Difference: A − B mein A ke woh members bachte hain jo B mein nahi. Yeh set sizes ka numerical subtraction nahi.
  • Example: A = {1, 2, 3}, B = {3, 4}: A − B = {1, 2}, lekin B − A = {4}. Order matter karta hai.
  • Complement: A ⊆ U par A′ = U − A. U badlega to complement badal sakta hai. Ek calculation mein same U rakho.
  • Hamari jaanch: U ke andar A − B = A ∩ B′. A ∩ A′ = ∅, A ∪ A′ = U, aur (A′)′ = A bhi check karo.

9. Law padho, sirf sign flip nahi

  • Basic laws: Union aur intersection commutative aur associative hain. A ∪ ∅ = A; A ∩ U = A.
  • Distributive laws: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C). Aur A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C).
  • De Morgan: Same U mein (A ∪ B)′ = A′ ∩ B′; (A ∩ B)′ = A′ ∪ B′. Operation badalne ke saath dono operands ka complement bhi lo.
  • Hamari jaanch: Union ke bahar yani dono ke bahar. Intersection ke bahar yani kam se kam ek set mein nahi; zaroori nahi dono se bahar ho.

10. Finite counting mein survey ko union mat maano

  • Do sets: Finite A, B ke liye n(A ∪ B) = n(A) + n(B) − n(A ∩ B). Common part do baar juda tha, isliye ek baar ghatao.
  • Neither: Finite U aur A, B ⊆ U par neither = n(U) − n(A ∪ B). Survey total automatically union nahi.
  • Teen-set extension: Teen singles jodo, teen pairwise intersections ghatao, triple ek baar jodo. "Only" na ho to pairwise count mein triple included hai.
  • Hamari jaanch: Finite A, B ⊆ U par overlap max(0, n(A)+n(B)−n(U)) se min(n(A),n(B)) tak hai. Har region count nonnegative integer hona chahiye.

1. समुच्चय का सदस्यता नियम स्पष्ट हो

  • अर्थ: समुच्चय वस्तुओं का सुपरिभाषित संग्रह है। दिए नियम से सदस्यता स्पष्ट होनी चाहिए।
  • चिह्न: x ∈ A का अर्थ x सदस्य है; x ∉ A का अर्थ सदस्य नहीं है। मंझले कोष्ठक समुच्चय बताते हैं, अनुक्रम नहीं।
  • उदाहरण: 2 से 5 तक पूर्णांकों का समुच्चय {2, 3, 4, 5} है। बिना कसौटी के "अच्छे खिलाड़ी" स्पष्ट नियम नहीं है।
  • हमारी जांच: पसंद के आधार पर चुनी गई निश्चित नाम-सूची भी समुच्चय है। सूची या नियम दें; "अच्छा" का अर्थ स्वयं न मानें।

2. सूची, शर्त और संख्या-क्षेत्र

  • सूची रूप: हर अलग सदस्य एक बार लिखें। {1, 2, 2, 3} = {3, 1, 2}; क्रम और दोहराव से समुच्चय नहीं बदलता।
  • समुच्चय-निर्माण रूप: {x ∈ Z : x² = 9} में x पूर्णांक है और शर्त पूरी करता है। कोलन का अर्थ "ऐसा कि" है।
  • क्षेत्र का महत्व: Z में उत्तर {−3, 3}, N में {3} है। यहां NCERT की तरह N = {1, 2, 3, ...} लिया है।
  • हमारी जांच: पहले संख्या-क्षेत्र पढ़ें, फिर शर्त हल करें और हर सदस्य जांचें। कुछ शुरुआती पदों से अनंत सूची का एकमात्र नियम तय नहीं होता।

3. रिक्त, एकल, परिमित और अपरिमित

  • रिक्त: ∅ = {} में कोई सदस्य नहीं। यह परिमित है और n(∅) = 0 है।
  • एकल: {0} का सदस्य 0 है। {∅} का सदस्य ∅ है। दोनों में एक सदस्य है, पर दोनों अलग समुच्चय हैं।
  • परिमित या अपरिमित: परिमित समुच्चय में अलग सदस्यों की संख्या कोई ऋणेतर पूर्णांक होती है। N अपरिमित है; अंतिम प्राकृतिक संख्या नहीं है।
  • हमारी जांच: ∅, {∅} और {{∅}} अलग वस्तुएं हैं। सबसे बाहरी कोष्ठकों के सीधे अंदर की वस्तुएं गिनें।

4. समानता, उपसमुच्चय और सदस्यता अलग

  • समानता: A = B का अर्थ सदस्य बिल्कुल समान हैं। दो परिमित समुच्चयों की संख्या समान होने पर भी सदस्य अलग हो सकते हैं।
  • उपसमुच्चय: A ⊆ B का अर्थ A का हर सदस्य B में है। समानता मान्य है; A ⊆ A और ∅ ⊆ A हैं।
  • संकेत-परंपरा: यहां A ⊊ B उचित उपसमुच्चय है, समानता नहीं। NCERT में ⊂ समानता सहित उपसमुच्चय है; OpenStax अक्सर इसे उचित उपसमुच्चय मानता है। परंपरा पढ़ें।
  • हमारी जांच: A = {1, 2} के लिए 1 ∈ A और {1} ⊆ A हैं, पर {1} ∉ A है। ∈ को ⊆ से न बदलें।

5. अंतराल वास्तविक संख्याओं के समुच्चय हैं

  • अंत बिंदु: a < b पर (a, b) दोनों अंत बिंदु छोड़ता है; [a, b] दोनों लेता है। वर्ग कोष्ठक उस अंत बिंदु को शामिल करता है।
  • मिश्रित अंतराल: (−2, 3] = {x ∈ R : −2 < x ≤ 3}। इसमें 3 है, −2 नहीं; बीच की भिन्न संख्याएं भी हैं।
  • अनंत: [0, ∞) सभी ऋणेतर वास्तविक संख्याएं हैं। अनंत कोई वास्तविक अंत बिंदु नहीं, इसलिए वहां गोल कोष्ठक लगता है।
  • हमारी जांच: धनात्मक लंबाई के अंतराल में अनंत वास्तविक संख्याएं होती हैं, भले पूर्णांक कम हों। क्षेत्र पूर्णांक न कहे तो केवल पूर्णांक न लिखें।

6. घात समुच्चय और रिक्त समुच्चय का अपवाद

  • अर्थ: P(A) में A के सभी उपसमुच्चय आते हैं। A = {a, b} पर P(A) = {∅, {a}, {b}, {a, b}} है।
  • परिमित गणना: n अलग सदस्यों में प्रत्येक को लेने या छोड़ने के स्वतंत्र विकल्प हैं: n(P(A)) = 2^n। ∅ और A दोनों गिने हैं।
  • प्रतिबंध: उचित उपसमुच्चय: 2^n − 1। अरिक्त उचित उपसमुच्चय: 2^n − 2 केवल n ≥ 1 पर। n = 0 पर इनकी संख्या शून्य है, −1 नहीं।
  • हमारी जांच: P(∅) = {∅}, इसलिए संख्या 1 है। कोई निर्दिष्ट सदस्य अवश्य चाहिए और n ≥ 1 हो तो शेष n−1 विकल्पों से 2^(n−1) उपसमुच्चय मिलते हैं।

7. संघ, सर्वनिष्ठ और असंयुक्त समुच्चय

  • संघ: A ∪ B में A या B या दोनों के सदस्य हैं। यहां "या" में दोनों शामिल हैं, केवल एक नहीं।
  • सर्वनिष्ठ: A ∩ B में दोनों के साझा सदस्य हैं। A = {1, 2, 3}, B = {3, 4} पर संघ {1, 2, 3, 4} और सर्वनिष्ठ {3} है।
  • असंयुक्त: A ∩ B = ∅ का अर्थ कोई साझा सदस्य नहीं। अलग समुच्चय जरूरी नहीं असंयुक्त हों।
  • हमारी जांच: A ⊆ B हो तो A ∪ B = B और A ∩ B = A। वेन क्षेत्र संबंध बताते हैं; चित्र का क्षेत्रफल अपने-आप संख्या के अनुपात में नहीं होता।

8. अंतर और पूरक में दिशा देखें

  • अंतर: A − B में A के वे सदस्य बचते हैं जो B में नहीं हैं। यह सदस्य-संख्याओं का साधारण घटाव नहीं है।
  • उदाहरण: A = {1, 2, 3}, B = {3, 4} पर A − B = {1, 2}, पर B − A = {4} है। क्रम महत्वपूर्ण है।
  • पूरक: A ⊆ U पर A′ = U − A। U बदलने पर पूरक बदल सकता है। एक गणना में वही U रखें।
  • हमारी जांच: U के भीतर A − B = A ∩ B′। साथ ही A ∩ A′ = ∅, A ∪ A′ = U, और (A′)′ = A हैं।

9. नियम पढ़ें, केवल चिह्न न पलटें

  • मूल नियम: संघ और सर्वनिष्ठ क्रमविनिमेय तथा साहचर्य हैं। A ∪ ∅ = A; A ∩ U = A।
  • वितरण नियम: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)। और A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)।
  • डी मॉर्गन: उसी U में (A ∪ B)′ = A′ ∩ B′; (A ∩ B)′ = A′ ∪ B′। संक्रिया बदलने के साथ दोनों समुच्चयों के पूरक भी लें।
  • हमारी जांच: संघ के बाहर यानी दोनों के बाहर। सर्वनिष्ठ के बाहर यानी कम से कम एक में नहीं; दोनों से बाहर होना जरूरी नहीं।

10. परिमित गणना में सर्वेक्षण को संघ न मानें

  • दो समुच्चय: परिमित A, B के लिए n(A ∪ B) = n(A) + n(B) − n(A ∩ B)। साझा भाग दो बार जुड़ा था, इसलिए एक बार घटाएं।
  • दोनों में नहीं: परिमित U और A, B ⊆ U पर दोनों में नहीं = n(U) − n(A ∪ B)। सर्वेक्षण की कुल संख्या अपने-आप संघ नहीं है।
  • तीन समुच्चयों का विस्तार: तीनों अलग समुच्चयों की संख्याएं जोड़ें, तीन जोड़ी-सर्वनिष्ठ घटाएं, फिर तिहरा सर्वनिष्ठ जोड़ें। "केवल" न लिखा हो तो जोड़ी की संख्या में तिहरा भाग भी है।
  • हमारी जांच: परिमित A, B ⊆ U पर साझा संख्या max(0, n(A)+n(B)−n(U)) से min(n(A),n(B)) तक है। हर क्षेत्र की संख्या ऋणेतर पूर्णांक होनी चाहिए।
चुनी हुई बुनियादें और हमारे मौलिक प्रश्न, पूरे या क्रमांकित NCERT हल नहीं। Sets PDF पुनर्मुद्रण2026-27 जांचा। घात-समुच्चय संकेत/गणना, परिमित सर्वेक्षण सूत्र और साझा संख्या की सीमाएं सहायक विस्तार हैं, इस संस्करण के हर विषय का दावा नहीं। पूरे अभ्यास, सभी वेन चित्र/प्रमाण, इतिहास और उन्नत अनंत गणनीयता सिद्धांत नहीं लिए हैं। मूल अध्याय भी पढ़ें।

1. A set has a clear membership rule

  • Meaning: A set is a well-defined collection. For a stated rule, membership must be unambiguous.
  • Symbols: x ∈ A means x is a member; x ∉ A means it is not. Braces describe a set, not a sequence.
  • Example: The integers from 2 to 5 give {2, 3, 4, 5}. "Good players" without a stated test is not well-defined.
  • Our check: A fixed named list is a set even if someone originally chose it by preference. Specify the list or rule; do not guess what "good" means.

2. Roster, rule and domain

  • Roster: List each distinct member once. {1, 2, 2, 3} = {3, 1, 2}; order and repeats do not change the set.
  • Set-builder: {x ∈ Z : x² = 9} says x is an integer and satisfies the condition. The colon means "such that".
  • Domain matters: x² = 9 gives {−3, 3} over Z, but {3} over N. Here N = {1, 2, 3, ...}, as in NCERT.
  • Our check: Read the domain, solve the condition, then test every listed member. A short initial list alone need not determine a unique infinite pattern.

3. Empty, singleton, finite and infinite

  • Empty: ∅ = {} has no members. It is a finite set with n(∅) = 0.
  • Singleton: {0} has the member 0. {∅} has the member ∅. Both have one member, but they are different sets.
  • Finite or infinite: A finite set has some nonnegative integer number of distinct members. N is infinite; no last natural number exists.
  • Our check: Braces matter: ∅, {∅} and {{∅}} are different objects. Count the objects directly inside the outer braces.

4. Equality, subset and membership differ

  • Equality: A = B means exactly the same members. Two finite sets can have the same count but different members.
  • Subset: A ⊆ B means every member of A belongs to B. Equality is allowed; A ⊆ A and ∅ ⊆ A.
  • Notation: Here A ⊊ B means subset but not equal. NCERT uses ⊂ for subset with equality allowed; OpenStax often uses it for proper subset. Read the stated convention.
  • Our check: For A = {1, 2}, 1 ∈ A and {1} ⊆ A, but {1} ∉ A. Do not replace ∈ by ⊆.

5. Intervals are sets of real numbers

  • Endpoints: For a < b, (a, b) excludes both endpoints; [a, b] includes both. A square bracket includes that endpoint.
  • Mixed interval: (−2, 3] = {x ∈ R : −2 < x ≤ 3}. It includes 3, excludes −2, and includes fractions between them.
  • Infinity: [0, ∞) means all nonnegative real numbers. Infinity is not a real endpoint to include, so use a round bracket there.
  • Our check: An interval of positive length contains infinitely many reals, even if only a few integers lie inside. Do not list only integers unless the domain says so.

6. Power sets and the empty-set exception

  • Meaning: P(A) is the set of all subsets of A. For A = {a, b}, P(A) = {∅, {a}, {b}, {a, b}}.
  • Finite count: If A has n distinct members, each is included or excluded independently: n(P(A)) = 2^n. This counts both ∅ and A.
  • Restrictions: Proper subsets: 2^n − 1. Nonempty proper subsets: 2^n − 2 only for n ≥ 1. For n = 0, there are zero nonempty proper subsets, not −1.
  • Our check: P(∅) = {∅}, so its count is 1. If a specified member must be included and n ≥ 1, the remaining n−1 choices give 2^(n−1) subsets.

7. Union, intersection and disjoint sets

  • Union: A ∪ B means in A or B or both. It is inclusive OR, not "exactly one".
  • Intersection: A ∩ B means in both. For A = {1, 2, 3}, B = {3, 4}, the union is {1, 2, 3, 4} and intersection is {3}.
  • Disjoint: A ∩ B = ∅ means no common member. Different sets are not necessarily disjoint.
  • Our check: If A ⊆ B, then A ∪ B = B and A ∩ B = A. Venn regions show relationships, not automatically proportional counts.

8. Difference and complement need a direction

  • Difference: A − B keeps members in A but not in B. It is not numerical subtraction of the set sizes.
  • Example: For A = {1, 2, 3}, B = {3, 4}, A − B = {1, 2}, while B − A = {4}. Order matters.
  • Complement: With A ⊆ U, A′ = U − A. Change U and the complement may change. Keep one U throughout a calculation.
  • Our check: A − B = A ∩ B′ for sets inside U. Also A ∩ A′ = ∅, A ∪ A′ = U, and (A′)′ = A.

9. Read each set law, not just a flip trick

  • Basic laws: Union and intersection are commutative and associative. A ∪ ∅ = A; A ∩ U = A.
  • Distributive laws: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C). Also A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C).
  • De Morgan: In the same U: (A ∪ B)′ = A′ ∩ B′; (A ∩ B)′ = A′ ∪ B′. Complement each operand as well as changing the operation.
  • Our check: Outside the union means outside both. Outside the intersection means missing at least one set, not necessarily missing both.

10. Count finite regions without assuming everyone is in

  • Two sets: For finite A and B, n(A ∪ B) = n(A) + n(B) − n(A ∩ B). Subtract the common part once because it was added twice.
  • Neither: If A, B ⊆ U and U is finite: neither = n(U) − n(A ∪ B). The survey total is not automatically the union.
  • Three-set extension: Add the three single-set counts, subtract the three pairwise-intersection counts, then add the triple count. Pairwise intersections include the triple unless "only" is stated.
  • Our check: For finite A, B ⊆ U, overlap lies from max(0, n(A)+n(B)−n(U)) to min(n(A),n(B)). All region counts must be nonnegative integers.

Q1 Write {x ∈ Z : x² = 9} in roster form.
Show answer

Rule: Solve within the stated domain.

Steps: 1. Factor x²−9 = (x−3)(x+3). 2. Get x = 3 or −3. 3. Check both are integers and square to 9.

Answer/check: {−3, 3}. Listing order does not matter.

Q2 Is "five good cricket players" a well-defined set as written?
Show answer

Rule: Membership needs an unambiguous criterion.

Steps: 1. Identify the word good. 2. Look for a fixed test or named list. 3. Note that neither is supplied.

Answer/check: No, not as written. A fixed list of five named players would define a set.

Q3 A has four distinct members. How many members does P(A) have?
Show answer

Rule: Each member has two independent include/exclude choices.

Steps: 1. Read n = 4. 2. Calculate 2^4. 3. Count both ∅ and A among the subsets.

Answer/check: 16. By subset size, 1+4+6+4+1 = 16.

Q4 Is ∅ a subset of every set? Does this also mean it is a member of every set?
Show answer

Rule: Subset and membership are different tests.

Steps: 1. A subset must have no member outside the other set. 2. ∅ has no member that can violate this. 3. Test membership in {1, 2}, which does not list ∅.

Answer/check: ∅ ⊆ A always, but ∅ ∈ A need not hold.

Q5 For finite sets, n(A)=15, n(B)=12 and n(A∩B)=5. Find n(A∪B).
Show answer

Rule: Add the counts and subtract the common part once.

Steps: 1. Add 15+12 = 27. 2. Subtract 5. 3. Check separate regions: 10 only A, 5 both, 7 only B.

Answer/check: 22; 10+5+7 = 22.

Q6 A={1,2,3}, B={3,4,5}. Find A−B and B−A.
Show answer

Rule: Keep members of the first set that are absent from the second.

Steps: 1. Identify the common member 3. 2. Remove it from A to get {1,2}. 3. Remove it from B to get {4,5}.

Answer/check: A−B={1,2}; B−A={4,5}. Difference is not generally commutative.

Q7 Verify the complement-of-union law for U={1,2,3,4}, A={1,2}, B={2,3}.
Show answer

Rule: Use (A∪B)′ = A′∩B′, relative to the same U.

Steps: 1. A∪B={1,2,3}, so its complement is {4}. 2. A′={3,4}, B′={1,4}. 3. Intersect them to obtain {4}.

Answer/check: Both sides are {4}. Both operands, not only the operation, must change.

Q8 U={1,2,...,10}, A={1,3,5,7,9}. Find A′.
Show answer

Rule: A′ keeps members of U that are not in A.

Steps: 1. Start with the ten members of U. 2. Remove the five listed odd members. 3. Check the remaining members are in U and not A.

Answer/check: A′={2,4,6,8,10}; A∩A′=∅ and A∪A′=U.

Q9 Are A={1,2} and B={2,3} disjoint?
Show answer

Rule: Disjoint means the intersection is empty.

Steps: 1. Compare the member lists. 2. Find the common member 2. 3. Write A∩B={2}, which is not ∅.

Answer/check: No. Unequal sets may still overlap.

Q10 Of 50 students, 30 play cricket, 25 football and 10 both. How many play neither?
Show answer

Rule: Union counts at least one activity; neither is the remainder of U.

Steps: 1. Compute the union: 30+25−10 = 45. 2. Subtract from 50: 50−45 = 5. 3. Check 20 cricket-only + 10 both + 15 football-only + 5 neither.

Answer/check: 5 students. The four separate groups total 50.

उत्तर/जांच: 5 विद्यार्थी। चारों अलग समूहों का कुल 50 है।
