Formula Recap - Screenshot Le Lo!

Counting Principles ⭐

AND (stages saath) → MULTIPLY: m × n × p | OR (cases alag) → ADD: m + n | repetition allowed → har stage pe same choices (n^r) | repeat NAHI → choices ghat-ti hain (n × (n−1) × ...)

Factorial ⭐

n! = n × (n−1) × ... × 2 × 1 | 0! = 1 | cancel trick: 8!/5! = 8×7×6 = 336 | yaad rakho: 1!,2!,6,24,120,720,5040 (1! se 7!)

Permutation (ORDER matters) ⭐⭐

ⁿP_r = n!/(n−r)! | full line: n! | repetition: n^r | repeating objects: n!/(p!q!) - ALLAHABAD = 10!/(4!2!) = 75600 | circle: (n−1)! | code words: arrange, rank, signals, numbers

Combination (sirf SELECTION) ⭐⭐

ⁿC_r = n!/(r!(n−r)!) | ⁿP_r = ⁿC_r × r! | ⁿC_r = ⁿC_(n−r) | ⁿC_0 = ⁿC_n = 1 | Pascal: ⁿC_r + ⁿC_(r−1) = ⁿ⁺¹C_r | subsets total = 2ⁿ | code words: team, committee, group, hand

Restriction Patterns ⭐

saath rakhna? → BUNDLE (ek object banao, andar arrange alag) | kabhi saath nahi? → GAP method (baaki pehle, gaps me daalo) ya total − saath | "at least"? → cases bana ke ADD, ya complement (total − none)
