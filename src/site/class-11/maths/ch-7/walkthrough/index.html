Formula Recap - Screenshot Le Lo!

Theorem ⭐

(a+b)ⁿ = Σ C(n,r) aⁿ⁻ʳ bʳ (r = 0 se n) | terms = n+1 | har term me powers ka sum = n | coefficients = Pascal row n

General Term ⭐

T(r+1) = C(n,r) aⁿ⁻ʳ bʳ | TRAP: T₅ ke liye r = 4 (r = term − 1!) | constant term: x ki power = 0 wala term | end se k-th term = start se (n−k+2)-th

Middle Term ⭐

n EVEN → 1 middle: T(n/2 + 1) | n ODD → 2 middle: T((n+1)/2) aur T((n+3)/2) | middle term(s) = GREATEST coefficient

Coefficient Properties ⭐

Σ coefficients = 2ⁿ (a=b=1 rakho) | alternating sum C₀−C₁+C₂−... = 0 | odd-position sum = even-position sum = 2ⁿ⁻¹

Tricks ⭐

remainder: base ko multiple ± 1 likho (jaise 49 = 49, 8 = 7+1) | Pascal triangle = coefficients | (1+x)ⁿ ≈ 1 + nx jab x chhota
