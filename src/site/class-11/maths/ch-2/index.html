Notes language:

1️⃣ Cartesian Product — Ordered Pairs Ki Duniya

  • Ordered pair (a, b): order MATTER karta hai — (a, b) ≠ (b, a) jab tak a = b na ho. (Sets se yahi farak — {a,b} = {b,a} par (a,b) ≠ (b,a)!)
  • Cartesian product ⭐: A × B = {(a, b) : a ∈ A, b ∈ B} — A ke har element ko B ke har element se jodo. Coordinates ka origin yahi hai!
  • Counting: n(A × B) = n(A) × n(B). A me 3, B me 4 → 12 ordered pairs.
  • Cartesian product generally commutative nahi. Dono sets non-empty hon to A × B = B × A tabhi jab A = B. Koi ek empty ho to dono products empty hain.
  • Real plane: R × R = R² — poora coordinate plane! Har point (x, y) ek ordered pair hai.

💡 Feel: A = {shirts}, B = {pants} — A × B = saare possible outfits! Order matter karta hai: (shirt, pant) outfit hai, (pant, shirt) ulta likhna.

2️⃣ Relations — Connections Ka Set ⭐

  • Relation ⭐: A × B ka koi bhi SUBSET — yani A se B ke beech connections ka collection. R ⊆ A × B.
  • Domain: relation me involved A ke saare elements (first components). Range: involved B ke elements (second components). Codomain: poora B (range ⊆ codomain!). ⭐
  • Total relations possible: A × B ke subsets = 2^(n(A)×n(B)).
  • Example: A = {students}, B = {subjects}, R = {(student, subject) : student passes subject} — real life relation!
  • Arrow diagrams aur roster form se relation likhte hain; set-builder bhi: R = {(x, y) : y = x + 1, x ∈ A}.

🎯 Range vs codomain confusion pakka aata hai: codomain = pura target set B; range = jo actually hit hua (chhota ya barabar).

3️⃣ Functions — Har Input Ka Ek Hi Output ⭐

  • Function ⭐: aisa relation jisme A ka HAR element ka B me EXACTLY EK image ho. Do conditions: (1) koi element chhoota nahi, (2) kisi ke do images nahi.
  • Notation: f : A → B, f(x) = image. A = domain, B = codomain.
  • Check karna: arrow diagram me har input se EXACTLY ek arrow — do arrows ya zero arrow = function NAHI!
  • Examples: f(x) = x² (har x ka ek square ✓); x² + y² = 25 se y alone function nahi (ek x ke do y — ±!). ⭐
  • Vertical line test (graphs pe): koi bhi vertical line graph ko ek se zyada jagah kaate to function nahi.
  • Identity function: f(x) = x. Constant function: f(x) = c (sabka same image).

💡 Feel: function = vending machine — har button (input) pe exactly ek item (output). Ek button pe do items ya koi button dead → machine kharab (function nahi)!

5️⃣ Algebra of Functions — Jod, Ghata, Guna, Bhag

  • Addition: (f + g)(x) = f(x) + g(x) — same domain pe pointwise jodo.
  • Subtraction: (f − g)(x) = f(x) − g(x).
  • Multiplication: (fg)(x) = f(x)·g(x).
  • Division ⭐: (f/g)(x) = f(x)/g(x) — jahan g(x) ≠ 0 (domain se woh points nikal do!).
  • Scalar multiple: (αf)(x) = α·f(x).
  • Domains: sum/difference/product ka domain = dono domains ka INTERSECTION; quotient ka = intersection minus g ke zeros. ⭐
  • Example: f(x) = √x (domain x ≥ 0), g(x) = 1/x (domain x ≠ 0) → (f+g) ka domain = (0, ∞).

💡 Functions ka algebra easy hai — bas yaad rakho domain intersection hota hai, aur divide karte time denominator ke zeros hatao!

1️⃣ कार्तीय गुणन — क्रमित युग्मों की दुनिया

  • क्रमित युग्म (a, b): क्रम महत्वपूर्ण — (a, b) ≠ (b, a) जब तक a = b न हो।
  • कार्तीय गुणन ⭐: A × B = {(a, b) : a ∈ A, b ∈ B} — A के प्रत्येक अवयव को B के प्रत्येक से जोड़ो।
  • गिनती: n(A × B) = n(A) × n(B)।
  • कार्तीय गुणन सामान्यतः क्रमविनिमेय नहीं है। A और B दोनों अरिक्त हों तो A × B = B × A तभी जब A = B। कोई एक रिक्त हो तो दोनों गुणन रिक्त हैं।
  • वास्तविक तल: R × R = R² — पूरा निर्देशांक तल!

💡 A = {शर्ट}, B = {पैंट} — A × B = सभी संभव पोशाकें!

2️⃣ संबंध — संपर्कों का समुच्चय ⭐

  • संबंध ⭐: A × B का कोई भी उपसमुच्चय। R ⊆ A × B।
  • प्रांत (domain): संबंध में प्रयुक्त A के अवयव। परिसर (range): प्रयुक्त B के अवयव। सहप्रांत (codomain): पूरा B (परिसर ⊆ सहप्रांत!)। ⭐
  • कुल संबंध: 2^(n(A)×n(B))।
  • उदाहरण: R = {(x, y) : y = x + 1, x ∈ A}।

🎯 परिसर बनाम सहप्रांत: सहप्रांत = पूरा लक्ष्य समुच्चय; परिसर = जो वास्तव में प्राप्त हुआ।

3️⃣ फलन — हर इनपुट का एक ही आउटपुट ⭐

  • फलन ⭐: ऐसा संबंध जिसमें A का प्रत्येक अवयव का B में ठीक एक प्रतिबिंब हो।
  • संकेत: f : A → B, f(x) = प्रतिबिंब।
  • जांच: हर इनपुट से ठीक एक तीर — दो तीर या शून्य = फलन नहीं!
  • उदाहरण: f(x) = x² ✓; x² + y² = 25 से y फलन नहीं (एक x के दो y — ±!)। ⭐
  • ऊर्ध्व रेखा परीक्षण: कोई ऊर्ध्व रेखा आलेख को एक से अधिक बार काटे तो फलन नहीं।
  • तत्समक फलन: f(x) = x। अचर फलन: f(x) = c।

💡 फलन = वेंडिंग मशीन — हर बटन पर ठीक एक आइटम!

5️⃣ फलनों की बीजगणित — जोड़, घटाव, गुणा, भाग

  • योग: (f + g)(x) = f(x) + g(x)।
  • अंतर: (f − g)(x) = f(x) − g(x)।
  • गुणन: (fg)(x) = f(x)·g(x)।
  • भाग ⭐: (f/g)(x) = f(x)/g(x) — जहां g(x) ≠ 0!
  • प्रांत: योग/अंतर/गुणन का प्रांत = दोनों प्रांतों का सर्वनिष्ठ; भाग का = सर्वनिष्ठ ऋण g के शून्य। ⭐
  • उदाहरण: f(x) = √x (x ≥ 0), g(x) = 1/x (x ≠ 0) → (f+g) का प्रांत = (0, ∞)।

💡 प्रांत सर्वनिष्ठ होता है, और भाग में हर के शून्य हटाओ!

1️⃣ Cartesian Product — The World of Ordered Pairs

  • Ordered pair (a, b): order MATTERS — (a, b) ≠ (b, a) unless a = b. (This is exactly how pairs differ from sets — {a,b} = {b,a} but (a,b) ≠ (b,a)!)
  • Cartesian product ⭐: A × B = {(a, b) : a ∈ A, b ∈ B} — pair every element of A with every element of B. This is the origin of coordinates!
  • Counting: n(A × B) = n(A) × n(B). 3 in A, 4 in B → 12 ordered pairs.
  • Cartesian product is not commutative in general. If A and B are non-empty, A × B = B × A exactly when A = B. If either set is empty, both products are empty.
  • The real plane: R × R = R² — the whole coordinate plane! Every point (x, y) is an ordered pair.

💡 Feel: A = {shirts}, B = {pants} — A × B = every possible outfit! Order matters: (shirt, pant) is an outfit; (pant, shirt) is writing it backwards.

2️⃣ Relations — A Set of Connections ⭐

  • Relation ⭐: ANY subset of A × B — a collection of connections from A to B. R ⊆ A × B.
  • Domain: all elements of A involved in the relation (first components). Range: the involved elements of B (second components). Codomain: the whole of B (range ⊆ codomain!). ⭐
  • Total possible relations: subsets of A × B = 2^(n(A)×n(B)).
  • Example: A = {students}, B = {subjects}, R = {(student, subject) : student passed the subject} — a real-life relation!
  • Write relations with arrow diagrams, rosters, or set-builder form: R = {(x, y) : y = x + 1, x ∈ A}.

🎯 The range-vs-codomain confusion is guaranteed in exams: codomain = the full target set B; range = what actually gets hit (smaller or equal).

3️⃣ Functions — Exactly One Output per Input ⭐

  • Function ⭐: a relation where EVERY element of A has EXACTLY ONE image in B. Two conditions: (1) no element left out, (2) no element has two images.
  • Notation: f : A → B, f(x) = the image. A = domain, B = codomain.
  • Checking: in an arrow diagram every input must have EXACTLY one arrow — two arrows or none means NOT a function!
  • Examples: f(x) = x² (every x has one square ✓); from x² + y² = 25, y alone is not a function (one x gives two y's — ±!). ⭐
  • Vertical line test: if any vertical line cuts the graph more than once, it is not a function.
  • Identity function: f(x) = x. Constant function: f(x) = c (same image for all).

💡 Feel: a function is a vending machine — every button (input) gives exactly one item (output). Two items from one button or a dead button means the machine is broken (not a function)!

5️⃣ Algebra of Functions — Add, Subtract, Multiply, Divide

  • Addition: (f + g)(x) = f(x) + g(x) — pointwise on the same domain.
  • Subtraction: (f − g)(x) = f(x) − g(x).
  • Multiplication: (fg)(x) = f(x)·g(x).
  • Division ⭐: (f/g)(x) = f(x)/g(x) — wherever g(x) ≠ 0 (remove those points from the domain!).
  • Scalar multiple: (αf)(x) = α·f(x).
  • Domains: the domain of a sum/difference/product = the INTERSECTION of the two domains; for a quotient = intersection minus the zeros of g. ⭐
  • Example: f(x) = √x (domain x ≥ 0), g(x) = 1/x (domain x ≠ 0) → domain of (f+g) = (0, ∞).

💡 The algebra of functions is easy — just remember the domain is an intersection, and when dividing, drop the denominator's zeros!

Q1 A = {1, 2}, B = {a, b, c}. n(A × B)?
Answer dekho

n(A×B) = 2×3 = 6.

Q2 (a, b) = (3, 5) hai to a aur b?
Answer dekho

Ordered pair me components match: a = 3, b = 5.

Q3 R = {(1,2), (2,4), (3,6)} ka domain aur range?
Answer dekho

Domain = {1, 2, 3}, Range = {2, 4, 6}.

Q4 Range aur codomain me kya farak?
Answer dekho

Codomain = poora target set; range = jo actually images banaye (range ⊆ codomain).

Q5 R = {(1,2), (1,3), (2,4)} function hai?
Answer dekho

Nahi — 1 ke do images (2 aur 3). Har input ka exactly ek output chahiye.

Q6 f(x) = x² + 1. f(3) aur f(−3)?
Answer dekho

Dono 10 — square sign khaa jaata hai. Do inputs ka same image allowed hai!

Q7 [−3.7] (greatest integer) kya hoga?
Answer dekho

−4 — floor hamesha neeche (left) jaata hai, −3 nahi!

Q8 f(x) = 1/(x − 2). Domain?
Answer dekho

Denominator zero nahi hona chahiye → x ≠ 2 → domain = R − {2}.

Q9 f(x) = √x, g(x) = x². (f+g)(4)?
Answer dekho

f(4) = 2, g(4) = 16 → (f+g)(4) = 18.

Q10 Signum function ka range?
Answer dekho

{−1, 0, 1} — negative pe −1, zero pe 0, positive pe 1.

Q1 A = {1, 2}, B = {a, b, c} हैं। n(A × B) निकालें।
उत्तर देखें

A × B में क्रमित युग्म होते हैं: पहला अवयव A से और दूसरा B से। A के हर चयन के लिए B के 3 चयन हैं। उत्तर: 2 × 3 = 6। जांच: (1,a), (1,b), (1,c), (2,a), (2,b), (2,c), कुल 6 युग्म।

Q2 (a, b) = (3, 5) है। a और b निकालें।
उत्तर देखें

समान क्रमित युग्मों के संगत अवयव समान होते हैं। पहले से पहला मिलाएं: a = 3। दूसरे से दूसरा मिलाएं: b = 5। उत्तर: a = 3, b = 5। जांच: रखने पर दोनों ओर (3,5) मिलता है। क्रम महत्वपूर्ण है।

Q3 R = {(1,2), (2,4), (3,6)} का प्रांत और परिसर निकालें।
उत्तर देखें

प्रांत में सभी पहले अवयव और परिसर में सभी दूसरे अवयव लेते हैं। उत्तर: प्रांत = {1,2,3}, परिसर = {2,4,6}। जांच: हर युग्म का इनपुट और आउटपुट इन सूचियों में है। केवल इन युग्मों से कोई बड़ा सहप्रांत तय नहीं कर सकते।

Q4 परिसर और सहप्रांत में क्या अंतर है?
उत्तर देखें

f : A → B में सहप्रांत घोषित लक्ष्य समुच्चय B है। परिसर वे आउटपुट हैं जो वास्तव में मिलते हैं। उत्तर: परिसर ⊆ B; दोनों समान होना जरूरी नहीं। जांच: f : {1,2} → {1,2,3}, f(x) = x में परिसर {1,2} है, लेकिन सहप्रांत {1,2,3} है।

Q5 क्या R = {(1,2), (1,3), (2,4)} एक फलन है?
उत्तर देखें

फलन में हर इनपुट का ठीक एक आउटपुट होता है। यहां इनपुट 1 के दो आउटपुट 2 और 3 हैं। उत्तर: नहीं। जांच: एक ही इनपुट के दो आउटपुट मिलना नियम को गलत सिद्ध करने के लिए काफी है। इनपुट 2 का आउटपुट 4 होने से यह कमी नहीं मिटती।

Q6 f(x) = x² + 1 के लिए f(3) और f(−3) निकालें।
उत्तर देखें

पूरा इनपुट रखें: f(3) = 3² + 1 = 10; f(−3) = (−3)² + 1 = 10। उत्तर: दोनों 10 हैं। जांच: हर इनपुट का एक ही आउटपुट है। अलग इनपुट का समान आउटपुट हो सकता है, इसलिए यह फिर भी फलन है।

Q7 [−3.7] निकालें, जहां [x] का अर्थ x से छोटा या बराबर महत्तम पूर्णांक है।
उत्तर देखें

ऐसा सबसे बड़ा पूर्णांक चाहिए जो इनपुट से बड़ा न हो। −4 ≤ −3.7 < −3 है। उत्तर: −4। जांच: −3, इनपुट −3.7 से बड़ा है, इसलिए मान्य नहीं। यह निकटतम पूर्णांक तक सन्निकटन या दशमलव हटाना नहीं है।

Q8 f(x) = 1/(x − 2) का अधिकतम वास्तविक प्रांत निकालें।
उत्तर देखें

हर शून्य नहीं हो सकता। x − 2 = 0 से x = 2 मिलता है, इसलिए इसे हटाएं। उत्तर: R − {2}, जहां R वास्तविक संख्याओं का समुच्चय है। जांच: x = 3 पर मान 1 और x = 1 पर −1 है; x = 2 पर शून्य से भाग करना पड़ेगा।

Q9 f(x) = √x, g(x) = x² हैं। (f + g)(4) निकालें।
उत्तर देखें

फलनों के योग में एक ही इनपुट पर मान जोड़ते हैं, एक फलन को दूसरे के अंदर नहीं रखते। f(4) = 2 और g(4) = 16। उत्तर: 2 + 16 = 18। जांच: 4 दोनों वास्तविक प्रांतों में है। योग का वास्तविक प्रांत [0,∞) है।

Q10 R पर परिभाषित चिह्न फलन (signum) का परिसर क्या है?
उत्तर देखें

यह इनपुट का चिह्न बताता है: x < 0 पर −1, x = 0 पर 0, x > 0 पर 1। उत्तर: {−1,0,1}। जांच: इनपुट −2, 0, 2 से तीनों मान मिलते हैं। x/|x| केवल x ≠ 0 पर सही है; शून्य पर मान अलग से 0 परिभाषित करते हैं।

Q1 A = {1, 2}, B = {a, b, c}. Find n(A × B).
Show answer

A × B contains ordered pairs, first from A and second from B. Each of 2 choices has 3 partners: 2 × 3 = 6. Answer: 6. Check: (1,a), (1,b), (1,c), (2,a), (2,b), (2,c).

Q2 (a, b) = (3, 5). Find a and b.
Show answer

Equal ordered pairs have equal corresponding components. Match first with first: a = 3. Match second with second: b = 5. Answer: a = 3, b = 5. Check: substitution gives (3,5) on both sides. Order matters.

Q3 Find the domain and range of R = {(1,2), (2,4), (3,6)}.
Show answer

The domain collects first components; the range collects second components. Answer: domain = {1,2,3}, range = {2,4,6}. Check: every listed pair uses these inputs and outputs. A larger codomain cannot be recovered from these pairs alone.

Q4 What is the difference between range and codomain?
Show answer

For f : A → B, the codomain is the declared target B. The range is the set of outputs actually reached. Answer: range ⊆ B, but equality is not required. Check: f : {1,2} → {1,2,3}, f(x) = x has range {1,2} and codomain {1,2,3}.

Q5 Is R = {(1,2), (1,3), (2,4)} a function?
Show answer

A function gives every input exactly one output. Here input 1 has outputs 2 and 3. Answer: no. Check: finding just this one input with two outputs disproves the function rule; output 4 for input 2 does not repair it.

Q6 For f(x) = x² + 1, find f(3) and f(−3).
Show answer

Substitute each complete input: f(3) = 3² + 1 = 10; f(−3) = (−3)² + 1 = 10. Answer: both are 10. Check: each input has one output. Different inputs may share an output, so this is still a function.

Q7 Find [−3.7], where [x] means the greatest integer not exceeding x.
Show answer

The floor is the greatest integer ≤ the input. Here −4 ≤ −3.7 < −3. Answer: −4. Check: −3 is greater than −3.7, so it is not allowed. This is not rounding to the nearest integer or cutting off the decimal.

Q8 Find the largest real domain of f(x) = 1/(x − 2).
Show answer

A denominator cannot be zero. Solve x − 2 = 0 to exclude x = 2. Answer: R − {2}, where R is the set of real numbers. Check: x = 3 gives 1 and x = 1 gives −1; x = 2 would require division by zero.

Q9 For f(x) = √x and g(x) = x², find (f + g)(4).
Show answer

Function addition means adding values at the same input, not composition. f(4) = 2 and g(4) = 16. Answer: (f + g)(4) = 2 + 16 = 18. Check: 4 is in both real domains. The sum has real domain [0,∞).

Q10 What is the range of the signum function on R?
Show answer

Signum records the sign: −1 for x < 0, 0 for x = 0, and 1 for x > 0. Answer: {−1,0,1}. Check: inputs −2, 0 and 2 attain all three values. The formula x/|x| works only for x ≠ 0; define the value at zero separately.
