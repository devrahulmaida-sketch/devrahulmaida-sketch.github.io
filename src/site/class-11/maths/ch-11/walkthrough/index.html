Formula Recap - Screenshot Le Lo!

Setup

point = (x, y, z) | axes teeno perpendicular, origin (0,0,0) | planes: XY (z=0), YZ (x=0), ZX (y=0) | axis pe point: x-axis (a,0,0), XY plane (a,b,0) - ek coordinate ZERO

Octants ⭐

8 octants, sirf SIGNS ka game | Octant I = (+,+,+) | "(−2,4,7) kahan?" → (−,+,+) bas dekho | values matter NAHI karti

Distance ⭐

d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²] | origin se: √(x²+y²+z²) | 2D + ek z-term bas | collinearity: AB + BC = AC

Section Formula ⭐

internal m:n → ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)) | TRAP: m cross B ke saath | midpoint = ((x₁+x₂)/2, ...) | external: m−n | centroid = ((x₁+x₂+x₃)/3, ...)

Shape Identification ⭐

equilateral: 3 sides same | isosceles: 2 same | right: Pythagoras a²+b²=c² | collinear: AB+BC=AC | square: 4 sides + 2 diagonals same | chapter = sirf 2 formulas (distance + section), dono 2D ke twins!
