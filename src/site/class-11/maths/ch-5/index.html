Long Notes — Full Explanation

Concept pakka karne ke liye — aaram se padho

Notes language:

1️⃣ Inequalities Kya Hain — Balance Nahi, Comparison

  • Equation (=): exact balance — 2x = 6 → x = 3 (ek answer). Inequality (<, >, ≤, ≥): comparison — 2x < 6 → x < 3 (poora RANGE of answers!).
  • Symbols: < chhota, > bada, ≤ chhota-ya-barabar, ≥ bada-ya-barabar.
  • Solution set: diye hue domain ke saare values jo inequality ko true banayein. Pehle batao values real, integer ya whole numbers hain. System ka koi solution na bhi ho sakta hai; common region assume mat karo.
  • Real life: "exam me kam se kam 40 marks chahiye" → x ≥ 40. "lift me max 10 log" → x ≤ 10. Inequalities har jagah!
  • Ek variable mein linear inequality: ax + b < 0, ya >, ≤, ≥ wala form, jahan a, b real aur a ≠ 0 hain. Variable sirf first power mein aata hai.

💡 Feel: equation = exact address ("house no. 3"), inequality = poora area code ("sector 3 ke andar kahin bhi")!

2️⃣ Rules of the Game — Kab Sign Flip Hota Hai ⭐

  • Rule 1: dono taraf SAME number add/subtract karo → sign SAME rehta hai. (x − 3 < 5 → x < 8 ✓)
  • Rule 2: dono taraf POSITIVE number se multiply/divide → sign SAME. (2x < 6 → x < 3 ✓)
  • Rule 3 ⭐⭐: NEGATIVE number se multiply/divide → sign FLIP! (−2x < 6 → x > −3 — sign palat gaya!) Sabse zyada galti yahi hoti hai!
  • Kyun flip?: number line pe negative se multiply = mirror image! 2 < 3 hai, par −2 > −3 (mirror me ulta!).
  • Reciprocal: nonzero real a < b ka sign same ho to 1/a > 1/b. Zero ke aar-paar rule mat lagao: −2 < 3 lekin −1/2 < 1/3 hai. Unknown sign ho to pehle cases banao.
  • Safe trick: variable ko LEFT pe laao positive coefficient ke saath — flip mistakes bachte hain.

🎯 Golden rule: minus se multiply/divide = sign palto. Har baar, bina exception. Isi ek rule pe aadhe questions atakte hain!

3️⃣ Number Line Solutions — Ek Variable ⭐

  • Solve karke number line pe dikhao: x < 3 → open circle (○) at 3, LEFT side shade. x ≥ 3 → filled/closed circle (●) at 3, RIGHT shade.
  • Open vs closed ⭐: < ya > = open circle (point INCLUDED nahi); ≤ ya ≥ = closed circle (point included).
  • Interval notation: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞). Bracket ka matlab wahi — round = open, square = closed. ∞ ke saath hamesha round!
  • Combined (AND) inequalities ⭐: −2 ≤ x < 5 → [−2, 5) — dono conditions EK SAATH satisfy honi chahiye. Solve: −3 ≤ 2x − 1 < 7 → sab parts me same operation → −1 ≤ x < 4.
  • OR inequalities: x < −1 ya x > 3 → do alag shade regions, union (−∞, −1) ∪ (3, ∞).

💡 Circle ka funda: sign me barabar hai (≤, ≥) to circle bhara hua (mil gaya membership), nahi to khokhla circle (bahar raha woh point).

4️⃣ Graphical Solutions — Do Variables ⭐

  • Linear inequality in x, y: ax + by < c, real coefficients aur a, b dono ek saath zero nahi. Solution half-plane hai. System ka common set empty, unbounded ya bina corners ka bhi ho sakta hai.
  • Graph steps: ax + by = c draw karo. < ya > par dashed, ≤ ya ≥ par solid line. Test point boundary line par NAHI hona chahiye. (0, 0) tabhi lo jab line par na ho; x + y = 0 ke liye (1, 0) lo. Inequality true ho to uski side, warna opposite side shade karo.
  • Example: x + y < 4 → line x + y = 4 dashed; origin (0+0 < 4 ✓) → origin wali side shade.
  • System of inequalities ⭐: do-teen inequalities ka COMMON region — sabki shading jo overlap kare wahi solution. (LPP ka foundation — 12th me Linear Programming isi pe!)
  • Feasible region: common solution set. Empty, unbounded ya bina corners ka bhi ho sakta hai. Vertices hon to suitable optimization problems mein kaam aate hain.

💡 Feel: line plane ka border hai. Test point = spy jo check karta hai border ke kaunse side solution ka territory hai!

5️⃣ Word Problems — Real Life Inequalities

  • Translation key ⭐: "kam se kam/at least" = ≥; "zyada se zyada/at most" = ≤; "se zyada/more than" = >; "se kam/less than" = <.
  • Example 1, spending limit: book ₹30 ki hai aur total spending ₹120 se kam rakhni hai. Paise kaafi available hon to 30x < 120 aur x non-negative integer se x ∈ {0, 1, 2, 3}; max 3 books. Sirf paise ₹120 se kam kehne se 3 books afford karna guaranteed nahi hai.
  • Example 2 (marks): 3 tests ka average ≥ 60 chahiye, do tests me 55, 70 aaye. (55 + 70 + x)/3 ≥ 60 → 125 + x ≥ 180 → x ≥ 55.
  • Example 3 (temperature conversion): Celsius-Fahrenheit range problems — C ko F me convert karke inequality solve karo.
  • Domain wale questions ⭐: √(x − 3) real kab? → x − 3 ≥ 0 → x ≥ 3. 1/(x − 2) defined kab? → x ≠ 2.
  • Answer check: word problems me final answer CONTEXT me socho — books 3.9 nahi, 3 hi ho sakti hain!

🎯 At least = minimum guarantee = ≥. At most = maximum limit = ≤. Ye do phrases rat lo, word problems aadhe wahi ban jaate hain!

1️⃣ असमिकाएं क्या हैं — संतुलन नहीं, तुलना

  • समीकरण (=): सटीक संतुलन — 2x = 6 → x = 3 (एक उत्तर)। असमिका (<, >, ≤, ≥): तुलना — 2x < 6 → x < 3 (उत्तरों की पूरी श्रेणी!)।
  • प्रतीक: < छोटा, > बड़ा, ≤ छोटा-या-बराबर, ≥ बड़ा-या-बराबर।
  • हल समुच्चय: दिए गए प्रांत के वे सभी मान जो असमिका को सही बनाते हैं। पहले बताएं कि मान वास्तविक, पूर्णांक या पूर्ण संख्याएं हैं। निकाय का कोई हल न भी हो सकता है; उभयनिष्ठ क्षेत्र मानकर न चलें।
  • वास्तविक जीवन: "कम से कम 40 अंक" → x ≥ 40। "अधिकतम 10 लोग" → x ≤ 10।
  • एक चर में रैखिक असमिका: ax + b < 0, या >, ≤, ≥ वाला रूप, जहां a, b वास्तविक और a ≠ 0 हैं। चर केवल पहली घात में आता है।

💡 समीकरण = सटीक पता, असमिका = पूरा क्षेत्र!

2️⃣ खेल के नियम — चिह्न कब पलटता है ⭐

  • नियम 1: दोनों ओर समान संख्या जोड़ो/घटाओ → चिह्न समान।
  • नियम 2: धनात्मक से गुणा/भाग → चिह्न समान।
  • नियम 3 ⭐⭐: ऋणात्मक से गुणा/भाग → चिह्न पलटता है! (−2x < 6 → x > −3!) सबसे अधिक गलती यहीं!
  • क्यों?: संख्या रेखा पर ऋण से गुणा = दर्पण प्रतिबिंब! 2 < 3, परंतु −2 > −3।
  • व्युत्क्रम: समान चिह्न वाली अशून्य वास्तविक संख्याओं a < b के लिए 1/a > 1/b है। शून्य के आर-पार यह नियम न लगाएं: −2 < 3 लेकिन −1/2 < 1/3 है। अज्ञात चिह्न हो तो अलग मामले बनाएं।
  • सुरक्षित युक्ति: चर को बाएं लाओ धन गुणांक के साथ।

🎯 स्वर्ण नियम: ऋण से गुणा/भाग = चिह्न पलटो। हर बार, बिना अपवाद!

3️⃣ संख्या रेखा हल — एक चर ⭐

  • संख्या रेखा पर: x < 3 → 3 पर खुला वृत्त (○), बाईं ओर छाया। x ≥ 3 → भरा वृत्त (●), दाईं ओर।
  • खुला बनाम बंद ⭐: < या > = खुला वृत्त (बिंदु शामिल नहीं); ≤ या ≥ = बंद (शामिल)।
  • अंतराल संकेत: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞)। गोल = खुला, वर्ग = बंद। ∞ के साथ सदैव गोल!
  • संयुक्त (AND) असमिकाएं ⭐: −2 ≤ x < 5 → [−2, 5)। हल: −3 ≤ 2x − 1 < 7 → सभी भागों में समान संक्रिया → −1 ≤ x < 4।
  • OR असमिकाएं: x < −1 या x > 3 → दो क्षेत्र, संघ।

💡 चिह्न में बराबर है (≤, ≥) तो वृत्त भरा, नहीं तो खोखला।

4️⃣ आलेखीय हल — दो चर ⭐

  • दो चर में रैखिक असमिका: ax + by < c, जहां गुणांक वास्तविक और a, b दोनों एक साथ शून्य नहीं हैं। हल एक अर्धतल है। निकाय का उभयनिष्ठ हल खाली, असीमित या बिना शीर्षों वाला भी हो सकता है।
  • आलेख के चरण: ax + by = c बनाएं। < या > के लिए बिंदुरेखा और ≤ या ≥ के लिए ठोस रेखा लें। परीक्षण बिंदु सीमा रेखा पर नहीं होना चाहिए। (0, 0) तभी लें जब वह रेखा पर न हो; x + y = 0 के लिए (1, 0) लें। असमिका सही हो तो उस ओर, नहीं तो दूसरी ओर छाया करें।
  • उदाहरण: x + y < 4 → रेखा x + y = 4 dashed; मूलबिंदु संतुष्ट ✓ → मूलबिंदु वाली ओर छाया।
  • असमिकाओं का निकाय ⭐: उभयनिष्ठ क्षेत्र — सभी छायाओं का अतिव्यापन। (LPP की नींव — 12वीं में काम आएगा!)
  • सुसंगत क्षेत्र: उभयनिष्ठ हल समुच्चय। वह खाली, असीमित या बिना शीर्षों वाला हो सकता है। शीर्ष मौजूद हों तो उपयुक्त इष्टतमीकरण समस्याओं में काम आते हैं।

💡 रेखा सीमा है। परीक्षण बिंदु = जासूस जो बताता है किस ओर हल का क्षेत्र है!

5️⃣ शब्द समस्याएं — वास्तविक जीवन असमिकाएं

  • अनुवाद कुंजी ⭐: "कम से कम" = ≥; "अधिक से अधिक" = ≤; "से अधिक" = >; "से कम" = <।
  • उदाहरण 1, खर्च की सीमा: पुस्तक ₹30 की है और कुल खर्च ₹120 से कम रखना है। पर्याप्त पैसे उपलब्ध हों तो 30x < 120 तथा x ऋणेत्तर पूर्णांक होने से x ∈ {0, 1, 2, 3}, अर्थात अधिकतम 3 पुस्तकें। केवल इतना कहना कि पैसे ₹120 से कम हैं, 3 पुस्तकें खरीद पाने की गारंटी नहीं है।
  • उदाहरण 2 (अंक): 3 परीक्षाओं का औसत ≥ 60, दो में 55, 70। (55 + 70 + x)/3 ≥ 60 → x ≥ 55।
  • प्रांत प्रश्न ⭐: √(x − 3) वास्तविक कब? → x ≥ 3। 1/(x − 2) परिभाषित कब? → x ≠ 2।
  • जांच: उत्तर संदर्भ में सोचो — पुस्तकें 3.9 नहीं, 3 ही!

🎯 कम से कम = ≥, अधिक से अधिक = ≤। ये दो वाक्यांश रट लो!

1️⃣ What Inequalities Are — Not Balance, but Comparison

  • Equation (=): an exact balance — 2x = 6 → x = 3 (one answer). Inequality (<, >, ≤, ≥): a comparison — 2x < 6 → x < 3 (a whole RANGE of answers!).
  • Symbols: < less than, > greater than, ≤ less than or equal, ≥ greater than or equal.
  • Solution set: all values in the stated domain that make the inequality true. State whether values are real, integer or whole numbers. A system may have no solution; do not assume the common region exists.
  • Real life: "need at least 40 marks" → x ≥ 40. "lift holds at most 10 people" → x ≤ 10. Inequalities are everywhere!
  • Linear inequality in one variable: ax + b < 0, or the corresponding >, ≤, ≥ form, with real a, b and a ≠ 0. The variable occurs only to the first power.

💡 Feel: an equation is an exact address ("house no. 3"); an inequality is a whole area code ("anywhere in sector 3")!

2️⃣ Rules of the Game — When the Sign Flips ⭐

  • Rule 1: add/subtract the SAME number on both sides → sign stays. (x − 3 < 5 → x < 8 ✓)
  • Rule 2: multiply/divide by a POSITIVE number → sign stays. (2x < 6 → x < 3 ✓)
  • Rule 3 ⭐⭐: multiply/divide by a NEGATIVE number → the sign FLIPS! (−2x < 6 → x > −3 — flipped!) This is where most mistakes happen!
  • Why the flip?: multiplying by a negative is a mirror image on the number line! 2 < 3, but −2 > −3 (the mirror reverses it!).
  • Reciprocals: for nonzero real numbers a < b with the same sign, 1/a > 1/b. Do not use this rule across zero: −2 < 3 but −1/2 < 1/3. For an unknown sign, split into cases first.
  • Safe trick: bring the variable to the LEFT with a positive coefficient — flip mistakes disappear.

🎯 Golden rule: multiply/divide by a negative = flip the sign. Every time, no exceptions. Half the questions in this chapter hinge on this one rule!

3️⃣ Number Line Solutions — One Variable ⭐

  • Solve and show on a number line: x < 3 → an open circle (○) at 3, shaded LEFT. x ≥ 3 → a closed circle (●) at 3, shaded RIGHT.
  • Open vs closed ⭐: < or > = open circle (point NOT included); ≤ or ≥ = closed circle (included).
  • Interval notation: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞). Round bracket = open, square = closed. Always round with ∞!
  • Combined (AND) inequalities ⭐: −2 ≤ x < 5 → [−2, 5) — both conditions must hold TOGETHER. Solve: −3 ≤ 2x − 1 < 7 → same operation on all parts → −1 ≤ x < 4.
  • OR inequalities: x < −1 or x > 3 → two separate shaded regions, the union (−∞, −1) ∪ (3, ∞).

💡 Circle logic: if the sign includes "equal" (≤, ≥), the circle is filled (membership granted); otherwise it is hollow (that point stays out).

4️⃣ Graphical Solutions — Two Variables ⭐

  • Linear inequality in x, y: ax + by < c, with real coefficients and a, b not both zero. Its solution is a half-plane. For a system, the common set may be empty, unbounded, or have no corners.
  • Graph steps: draw ax + by = c. Use a dashed line for < or > and a solid line for ≤ or ≥. Choose a test point NOT on the boundary. Use (0, 0) only if it is off the line; for x + y = 0, use (1, 0) instead. Shade its side if it satisfies the inequality, otherwise the opposite side.
  • Example: x + y < 4 → draw x + y = 4 dashed; the origin works (0+0 < 4 ✓) → shade the origin's side.
  • System of inequalities ⭐: the COMMON region of two or three inequalities — wherever all the shadings overlap. (The foundation of Linear Programming in Class 12!)
  • Feasible region: the common solution set. It need not have corners and may be empty or unbounded. If vertices exist, they matter in suitable optimization problems.

💡 Feel: the line is a border. The test point is a spy checking which side of the border holds the solution territory!

5️⃣ Word Problems — Real-Life Inequalities

  • Translation key ⭐: "at least" = ≥; "at most" = ≤; "more than" = >; "less than" = <.
  • Example 1, spending limit: books cost ₹30 each and total spending must be less than ₹120. With enough money available, 30x < 120 and x a non-negative integer give x ∈ {0, 1, 2, 3}; at most 3 books. Having an unspecified amount below ₹120 alone does not guarantee you can afford 3.
  • Example 2 (marks): needs an average ≥ 60 across 3 tests; scored 55 and 70 in two. (55 + 70 + x)/3 ≥ 60 → 125 + x ≥ 180 → x ≥ 55.
  • Example 3 (temperature): Celsius-Fahrenheit range problems — convert and solve the inequality.
  • Domain questions ⭐: when is √(x − 3) real? → x − 3 ≥ 0 → x ≥ 3. When is 1/(x − 2) defined? → x ≠ 2.
  • Check the answer: in word problems think about CONTEXT — books can be 3, not 3.9!

🎯 At least = a minimum guarantee = ≥. At most = a maximum limit = ≤. Learn these two phrases and half the word problems are done!

Answer dekho

3x < 15 → x < 5 = (−∞, 5).

Q2 Solve: −2x ≥ 10.
Answer dekho

Negative se divide → sign FLIP: x ≤ −5.

Q3 −4 < 3x − 1 ≤ 8 solve karo.
Answer dekho

Sab parts me +1: −3 < 3x ≤ 9 → ÷3: −1 < x ≤ 3 = (−1, 3].

Q4 x < 2 ko number line pe kaise dikhayenge?
Answer dekho

Open circle (○) at 2, left side shade — 2 included nahi.

Q5 [3, 7) interval me 7 included hai?
Answer dekho

Nahi — round bracket = open. 3 included, 7 nahi.

Q6 x + y ≤ 6 ke graph me line kaisi hogi?
Answer dekho

Solid (kyunki ≤ me barabar hai — line included), phir test point (0,0) wali side shade.

Q7 System of inequalities ka solution kya hota hai?
Answer dekho

Saari inequalities ki shading ka common (overlapping) region — feasible region.

Q8 'Kam se kam 50 marks chahiye' — inequality?
Answer dekho

x ≥ 50 ('kam se kam' = at least).

Q9 √(2x − 6) real kab hoga?
Answer dekho

Andar wala ≥ 0 → 2x − 6 ≥ 0 → x ≥ 3.

Q10 Do numbers ka sum 30 se zyada, pehla number 12 hai. Dusre ke liye inequality?
Answer dekho

12 + y > 30 → y > 18.

Q1 वास्तविक x के लिए 3x − 7 < 8 हल करें।
उत्तर देखें

नियम: दोनों ओर समान संख्या जोड़ने से असमिका का चिह्न नहीं बदलता।

चरण: दोनों ओर 7 जोड़ें: 3x < 15। धनात्मक 3 से भाग दें: x < 5।

उत्तर: (−∞, 5)। जांच: x = 4 पर 5 < 8 सही है, लेकिन x = 5 पर 8 < 8 गलत है।

Q2 वास्तविक x के लिए −2x ≥ 10 हल करें।
उत्तर देखें

नियम: ऋणात्मक संख्या से भाग देने पर असमिका का चिह्न पलटता है।

चरण: दोनों ओर −2 से भाग दें। ≥ की जगह ≤ आएगा।

उत्तर: x ≤ −5, अर्थात (−∞, −5]। जांच: x = −5 पर 10 ≥ 10 और x = −6 पर 12 ≥ 10 सही हैं।

Q3 वास्तविक x के लिए −4 < 3x − 1 ≤ 8 हल करें।
उत्तर देखें

अर्थ: दोनों असमिकाएं एक साथ सही होनी चाहिए।

चरण: तीनों भागों में 1 जोड़ें: −3 < 3x ≤ 9। धनात्मक 3 से भाग दें: −1 < x ≤ 3।

उत्तर: (−1, 3]। जांच: −1 पर −4 < −4 गलत है, इसलिए वह शामिल नहीं। 3 पर −4 < 8 ≤ 8 सही है, इसलिए वह शामिल है।

Q4 x < 2 को संख्या रेखा पर कैसे दिखाएंगे?
उत्तर देखें

अर्थ: 2 से छोटी सभी वास्तविक संख्याएं हल हैं, लेकिन 2 स्वयं हल नहीं है।

चरण: 2 पर खुला वृत्त बनाएं और बाईं ओर की किरण पर छाया करें।

उत्तर: 2 पर खुला वृत्त, बाईं ओर छाया; अंतराल (−∞, 2)। जांच: 1 हल है, लेकिन 2 और 3 नहीं।

Q5 क्या अंतराल [3, 7) में 7 शामिल है?
उत्तर देखें

नियम: वर्ग कोष्ठक में सिरा शामिल होता है; गोल कोष्ठक में नहीं।

चरण: [3, 7) का अर्थ 3 ≤ x < 7 है।

उत्तर: नहीं। 3 शामिल है, 7 नहीं। जांच: 6 भीतर है, लेकिन 7 के लिए x < 7 गलत है।

Q6 x + y ≤ 6 के आलेख में सीमा रेखा और छाया कैसी होगी?
उत्तर देखें

नियम: ≤ में बराबरी शामिल है, इसलिए सीमा रेखा के बिंदु भी हल हैं।

चरण: (6, 0) और (0, 6) से गुजरती ठोस रेखा x + y = 6 बनाएं। परीक्षण बिंदु (0, 0) रेखा पर नहीं है और 0 ≤ 6 को सही बनाता है।

उत्तर: ठोस सीमा रेखा और मूलबिंदु वाला अर्धतल छायांकित करें। जांच: (3, 3) शामिल सीमा पर है; (4, 4) हल नहीं है।

Q7 असमिकाओं के निकाय का हल क्या होता है?
उत्तर देखें

अर्थ: निकाय की सभी असमिकाएं एक साथ सही होनी चाहिए।

चरण: हर असमिका हल करें, फिर केवल उभयनिष्ठ भाग, अर्थात प्रतिच्छेद लें।

उत्तर: सभी का उभयनिष्ठ हल समुच्चय। आलेख में इसे सुसंगत क्षेत्र भी कहते हैं। जांच: x ≥ 1 और x < 3 से [1, 3) मिलता है; x < 0 और x ≥ 1 का कोई उभयनिष्ठ हल नहीं है।

Q8 कम से कम 50 अंक चाहिए, इसकी असमिका लिखें।
उत्तर देखें

अर्थ: प्राप्त अंकों को x मानें। कम से कम का अर्थ 50 या उससे अधिक है।

चरण: ठीक 50 अंक भी स्वीकार हैं, इसलिए बराबरी शामिल करें।

उत्तर: x ≥ 50। जांच: 50 और 51 शर्त पूरी करते हैं, 49 नहीं। अधिकतम अंक या पूर्णांक की शर्त वास्तविक परीक्षा से मिलेगी।

Q9 √(2x − 6) कब वास्तविक होगा?
उत्तर देखें

नियम: वास्तविक वर्गमूल के लिए भीतर का व्यंजक शून्य या धनात्मक होना चाहिए।

चरण: 2x − 6 ≥ 0 ⇒ 2x ≥ 6 ⇒ x ≥ 3।

उत्तर: [3, ∞)। जांच: x = 3 पर √0 = 0 है। x = 2 पर √(−2) चाहिए, जो वास्तविक नहीं है।

Q10 दो संख्याओं का योग 30 से अधिक है। पहली 12 है। दूसरी संख्या y के लिए क्या शर्त होगी?
उत्तर देखें

अर्थ: से अधिक में बराबरी शामिल नहीं है।

चरण: 12 + y > 30। दोनों ओर 12 घटाएं।

उत्तर: y > 18। जांच: y = 19 पर 31 > 30 सही है। y = 18 पर 30 > 30 गलत है।

Q1 Solve 3x − 7 < 8 for real x.
Show answer

Rule: adding the same number on both sides keeps the inequality direction.

Steps: add 7 to get 3x < 15. Divide by positive 3 to get x < 5.

Answer: (−∞, 5). Check: x = 4 gives 5 < 8, but x = 5 gives 8 < 8, which is false.

Q2 Solve −2x ≥ 10 for real x.
Show answer

Rule: dividing by a negative number reverses the inequality.

Steps: divide both sides by −2; ≥ changes to ≤.

Answer: x ≤ −5, or (−∞, −5]. Check: x = −5 gives 10 ≥ 10; x = −6 gives 12 ≥ 10.

Q3 Solve −4 < 3x − 1 ≤ 8 for real x.
Show answer

Meaning: both inequalities must hold at the same time.

Steps: add 1 to all three parts: −3 < 3x ≤ 9. Divide all parts by positive 3: −1 < x ≤ 3.

Answer: (−1, 3]. Check: −1 is excluded because it gives −4 < −4; 3 is included because it gives −4 < 8 ≤ 8.

Q4 How do you show x < 2 on a number line?
Show answer

Meaning: all real numbers smaller than 2 are solutions; 2 itself is not.

Steps: mark 2 with an open circle. Shade the ray to the left.

Answer: open at 2, shade left; interval (−∞, 2). Check: 1 is a solution, while 2 and 3 are not.

Q5 Does the interval [3, 7) include 7?
Show answer

Rule: a square bracket includes an endpoint; a round bracket excludes it.

Steps: read [3, 7) as 3 ≤ x < 7.

Answer: no. It includes 3 but not 7. Check: 6 lies inside; 7 fails x < 7.

Q6 What boundary line and shading represent x + y ≤ 6?
Show answer

Rule: ≤ includes equality, so points on the boundary belong to the solution.

Steps: draw the solid line x + y = 6 through (6, 0) and (0, 6). The test point (0, 0) is off the line and satisfies 0 ≤ 6.

Answer: solid boundary, shade the half-plane containing the origin. Check: (3, 3) is on the included boundary; (4, 4) is outside.

Q7 What is the solution of a system of inequalities?
Show answer

Meaning: a system requires all its inequalities to hold together.

Steps: solve each one, then keep only their common part, the intersection.

Answer: the common solution set, also called the feasible region in a graph. Check: x ≥ 1 and x < 3 give [1, 3); x < 0 and x ≥ 1 have no common solution.

Q8 Write an inequality for needing at least 50 marks.
Show answer

Meaning: let x be the marks obtained. At least means 50 or more.

Steps: include equality because exactly 50 is allowed.

Answer: x ≥ 50. Check: 50 and 51 meet this condition; 49 does not. Any maximum or whole-mark restriction comes from the actual test.

Q9 When is √(2x − 6) real?
Show answer

Rule: for a real square root, the expression inside must be non-negative.

Steps: 2x − 6 ≥ 0 ⇒ 2x ≥ 6 ⇒ x ≥ 3.

Answer: [3, ∞). Check: x = 3 gives √0 = 0; x = 2 would require √(−2), which is not real.

Q10 Two numbers have sum greater than 30. If the first is 12, what can the second number y be?
Show answer

Meaning: greater than is strict, so equality is not allowed.

Steps: 12 + y > 30. Subtract 12 from both sides.

Answer: y > 18. Check: y = 19 gives 31 > 30, while y = 18 gives 30 > 30, which is false.
