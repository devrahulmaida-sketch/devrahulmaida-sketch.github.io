Symbols + Rules

< chhota, > bada, ≤ / ≥ barabar included | add/subtract SAME number → sign same | ×÷ POSITIVE → sign same | ×÷ NEGATIVE → SIGN FLIP (minus = mirror!) ⭐ | safe trick: variable ko LEFT pe positive coefficient ke saath laao

Number Line + Intervals ⭐

< , > → OPEN circle (○) | ≤ , ≥ → CLOSED (●) | x < 3 = (−∞, 3) | x ≥ 3 = [3, ∞) | round = open, square = closed | ∞ ke saath HAMESHA round bracket

AND vs OR ⭐

AND (dono ek saath): −2 ≤ x < 5 → [−2, 5) - overlap | OR (koi ek): x < −1 ya x > 3 → (−∞,−1) ∪ (3,∞) - do alag regions | "between" = AND, "outside" = OR

2D Region Steps ⭐

(1) inequality → equation, line draw karo | (2) </> = DASHED line, ≤/≥ = SOLID | (3) test point (origin easiest!) - satisfy kare to us side, nahi to doosri side shade

System + Word Problems

common region = sabki shading ka overlap = feasible region (LPP foundation) | corners (vertices) important | "kam se kam" = ≥ | "max/zyada se zyada" = ≤ | "se kam nahi" = ≥
