Formula / Fact Recap - Ek Nazar Mein

BasicsEndocrine = ductless, hormone seedha blood me. Peptide, steroid, amino-acid types. Negative feedback common. Hypothalamus links neural + chemical.
PituitaryAnterior: GH, TSH, ACTH, LH, FSH, PRL, MSH. Posterior: oxytocin + ADH. GH: gigantism, acromegaly, dwarfism.
Thyroid + CaT3/T4 need iodine, set BMR. Goitre, cretinism, Graves'. TCT Ca↓, PTH Ca↑. Thymus = T-cells. Pineal = melatonin.
AdrenalCortex: cortisol, aldosterone (Na⁺ + water), androgens. Medulla: adrenaline + noradrenaline = fight or flight.
PancreasAlpha = glucagon (sugar ↑). Beta = insulin (sugar ↓). Diabetes mellitus = insulin problem, glycosuria.
Gonads + actionTestosterone (Leydig), estrogen (follicle), progesterone (corpus luteum). Peptide: membrane + 2nd messenger. Steroid: nuclear + DNA.
