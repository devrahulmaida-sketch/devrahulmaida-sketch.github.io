Formula / Fact Recap - Ek Nazar Mein

GlycolysisCytoplasm, glucose → 2 pyruvate. 4 ATP bane, 2 use: NET 2 ATP + 2 NADH. Hexokinase, PFK (rate-limiting), pyruvate kinase. No O₂.
FermentationYeast: ethanol + CO₂ (bread, beer). Muscle/Lactobacillus: lactic acid. Sirf 2 ATP. Yeast dies at 13% alcohol.
KrebsLink: pyruvate → acetyl CoA + CO₂ + NADH. Matrix. Acetyl CoA + OAA → citrate. Per glucose: 6 NADH + 2 FADH₂ + 2 ATP. Amphibolic.
ETCCristae. NADH → I → Q → III → cyt c → IV → O₂. FADH₂ via II. ATP synthase. 1 NADH = 3 ATP, 1 FADH₂ = 2 ATP.
Total ATP2 + 2 + (10 NADH × 3) + (2 FADH₂ × 2) = 38 ATP (NCERT). Efficiency ~40%.
RQCO₂ / O₂. Carb = 1, protein ~0.9, fat ~0.7. Plants respire 24×7, photosynthesis only in light.
