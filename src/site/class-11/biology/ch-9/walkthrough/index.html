Formula / Fact Recap - Ek Nazar Mein

CompositionWater 70-90%, proteins 10-15%, nucleic acids 5-7%, carbs 3%, lipids 2%, ions 1%. Acid-soluble = micro; acid-insoluble = macro. Lipids: not polymers.
CarbsC:H:O = 1:2:1. Starch (plant), glycogen (animal), cellulose (wall), chitin. Sucrose = non-reducing. Starch + iodine = blue.
ProteinsNH₂ + COOH + H + R on α-C. Peptide bond. 4 levels. Collagen #1 in animals, RuBisCO #1 in biosphere.
Lipids + NATriglyceride = glycerol + 3 FA. Phospholipid bilayer = membrane. Nucleotide = base + pentose + phosphate. A=T (2), G≡C (3). RNA has uracil.
EnzymesLower activation energy. Apoenzyme + cofactor = holoenzyme. Optimum temp + pH, denaturation. Competitive inhibitor: malonate.
BondsPeptide (protein), glycosidic (carb), phosphodiester (nucleic acid), ester (lipid). Anabolism builds, catabolism breaks.
