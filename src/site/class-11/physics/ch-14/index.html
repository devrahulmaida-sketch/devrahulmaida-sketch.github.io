Selected foundations

Pehle meaning, phir conditions, examples aur checks.

Notes language:

1. Wave disturbance le jaati hai

  • Meaning: Mechanical wave material medium mein chalne wala disturbance hai jo energy le ja sakta hai. Particles equilibrium ke paas oscillate karte hain; poora medium pattern ke saath nahi chalta.
  • Types: Transverse: particle displacement propagation ke perpendicular, jaise stretched string. Longitudinal: parallel, jaise air mein sound.
  • Hamari check: Sound ko medium chahiye. Light electromagnetic hai, vacuum mein bhi chalti hai. Har wave par string-speed formula mat lagao.

2. Travelling sine wave padho

  • Rule: k aur ω positive hon: y = A sin(kx − ωt + φ) +x mein jaati hai; −ωt ki jagah +ωt ho to −x. A amplitude, φ initial phase.
  • Definitions: k = 2π/λ, ω = 2πf, T = 1/f; wave speed v = ω/k = fλ. λ same phase ke neighbouring points ki distance hai.
  • Hamari check: Metre aur second use karo. Sine ka argument dimensionless, radians mein hai. Direction ke liye constant phase follow karo; equation samjhe bina sign mat rato.

3. Particle velocity aur wave speed alag

  • Rule: y = A sin(kx − ωt + φ) mein x fixed: uy = ∂y/∂t = −Aω cos(kx − ωt + φ); ay = −ω²y.
  • Difference: Pattern x mein v = ω/k se chalta hai; string particle transverse move karta hai. Maximum particle speed Aω hai, zaroori nahi v ho.
  • Hamari check: x = 0, t = 0, φ = 0 par y = 0, par uy = −Aω. Zero displacement par particle velocity zero zaroori nahi.

4. Phase difference

  • Rule: Same time par do points ka Δφ = kΔx = 2πΔx/λ. Fixed point par time Δt mein phase change −ωΔt hai.
  • Example: λ/4 separation par π/2; λ/2 par π; λ par 2π, yani equivalent phase.
  • Hamari check: Same time ya same place clearly bolo. Neighbouring crests ki distance λ; crest se nearest trough λ/2 hai.

5. Ideal stretched string ki speed

  • Model: Uniform flexible string, constant tension F aur small transverse slopes par v = √(F/μ). μ = mass/length, kg m⁻¹ mein.
  • Scaling: F four times to speed double. μ four times to speed half. Driver frequency set karta hai; is model mein medium aur tension speed set karte hain.
  • Hamari check: F,μ same rakhkar frequency double to wavelength half, speed same. F tension hai, period T nahi.

6. Average power: model pehle

  • Rule: Is ideal string par ek sinusoidal travelling wave ki average power Pavg = μω²A²v/2 watts hai. A peak amplitude hai.
  • Scaling: μ,v,frequency same hon aur A double ho to power four times. μ,v,A same hon aur frequency double ho to bhi power four times.
  • Hamari check: Yeh ek travelling wave ka formula hai, ideal standing wave ki net power nahi. Intensity power/area hai, W m⁻² mein; power se alag hai.

7. Superposition aur interference

  • Rule: Linear medium mein overlapping displacements signed add hote hain: y = y1 + y2. Absolute values mat jodo.
  • Same-frequency waves: Same direction ki do sine waves, har amplitude A, constant phase difference δ: R = 2A|cos(δ/2)|. In phase par 2A; opposite phase par zero.
  • Hamari check: Zero cancellation ke liye equal amplitudes aur us point par opposite phase chahiye. Unequal hon to minimum |A1 − A2|. Coherent waves ki intensities seedha mat jodo; interference term bhi hota hai.

8. Standing waves aur fixed string

  • Model: Equal amplitude/frequency ki opposite travelling waves se y = 2A sin(kx) cos(ωt) mil sakta hai. Nodes aur antinodes ki positions fixed hain.
  • Spacing: Is origin ke liye nodes x = nλ/2. Neighbouring nodes λ/2 apart; node se nearest antinode λ/4. Antinode amplitude 2A.
  • Fixed ends: L length string dono ends fixed: λn = 2L/n; fn = nv/(2L), n = 1,2,3... . Fundamental n = 1; first overtone n = 2. Ideal standing wave ka net time-averaged energy transport zero hai.

9. Pipe: displacement aur pressure

  • Boundary: Ideal air column ka closed end displacement node aur pressure antinode hai. Open end approximately displacement antinode aur pressure node hai.
  • Frequencies: End correction ignore: open–open fn = nv/(2L), n = 1,2,3... . Ek end closed: fn = nv/(4L), sirf n = 1,3,5... .
  • Hamari check: Ek-end-closed pipe ka first overtone third harmonic hai, second nahi. Air ka sound speed lo, string speed nahi. Real opening par end correction chahiye.

10. Beats aur do possible answers

  • Meaning: Do close sound frequencies se fixed listener ko periodic loudness changes milte hain. fb = |f1 − f2|; successive loudness maxima ke beech time 1/fb.
  • Example: 256 Hz reference aur 4 beats/s se unknown 252 Hz ya 260 Hz ho sakta hai. Sirf beats se higher/lower nahi pata chalta.
  • Hamari check: Clear slow beats ke liye frequencies close hon; similar amplitudes se contrast strong hota hai. Envelope ke sign-change rate ko beat count mat samjho.

1. तरंग विक्षोभ को आगे ले जाती है

  • अर्थ: यांत्रिक तरंग पदार्थ के माध्यम में आगे बढ़ने वाला विक्षोभ है, जो ऊर्जा ले जा सकता है। कण साम्य के पास दोलन करते हैं; पूरा माध्यम तरंग के साथ नहीं चलता।
  • प्रकार: अनुप्रस्थ: कण का विस्थापन संचरण के लंबवत, जैसे तनी डोरी। अनुदैर्घ्य: संचरण के समांतर, जैसे हवा में ध्वनि।
  • हमारी जांच: ध्वनि को माध्यम चाहिए। प्रकाश विद्युतचुंबकीय है और निर्वात में भी चलता है। हर तरंग पर डोरी की चाल का सूत्र न लगाएं।

2. चलती साइन तरंग पढ़ें

  • नियम: धनात्मक k और ω के लिए y = A sin(kx − ωt + φ) +x दिशा में चलती है; −ωt की जगह +ωt हो तो −x दिशा में। A आयाम, φ आरंभिक कला है।
  • परिभाषाएं: k = 2π/λ, ω = 2πf, T = 1/f और तरंग चाल v = ω/k = fλ. λ समान कला वाले निकटतम बिंदुओं की दूरी है।
  • हमारी जांच: मीटर और सेकंड लें। साइन का कोण विमाहीन है और रेडियन में है। दिशा के लिए स्थिर कला का पीछा करें; समीकरण समझे बिना चिह्न न रटें।

3. कण का वेग तरंग की चाल नहीं

  • नियम: y = A sin(kx − ωt + φ) में x स्थिर रखें: uy = ∂y/∂t = −Aω cos(kx − ωt + φ). कण का त्वरण ay = −ω²y.
  • अंतर: तरंग का रूप x दिशा में v = ω/k से चलता है; डोरी का कण अनुप्रस्थ चलता है। अधिकतम कण चाल Aω है, जरूरी नहीं v हो।
  • हमारी जांच: x = 0, t = 0, φ = 0 पर y = 0 लेकिन uy = −Aω. शून्य विस्थापन का अर्थ शून्य कण वेग नहीं।

4. कलांतर

  • नियम: एक ही समय पर दो बिंदुओं का कलांतर Δφ = kΔx = 2πΔx/λ. स्थिर बिंदु पर Δt समय में कला −ωΔt बदलती है।
  • उदाहरण: λ/4 दूरी पर π/2; λ/2 पर π; λ पर 2π, अर्थात समान कला।
  • हमारी जांच: एक समय या एक स्थान, यह बताएं। निकटतम शिखरों की दूरी λ है; शिखर से निकटतम गर्त की दूरी λ/2 है।

5. आदर्श तनी डोरी की चाल

  • मॉडल: एकसमान लचीली डोरी, स्थिर तनाव F और छोटी अनुप्रस्थ ढाल के लिए v = √(F/μ). μ = द्रव्यमान/लंबाई, इकाई kg m⁻¹.
  • अनुपात: F चार गुना तो चाल दुगुनी। μ चार गुना तो चाल आधी। चालक आवृत्ति तय करता है; इस मॉडल में माध्यम और तनाव चाल तय करते हैं।
  • हमारी जांच: F,μ वही रखकर आवृत्ति दुगुनी करें तो तरंगदैर्घ्य आधा, चाल वही रहती है। F तनाव है, आवर्तकाल T नहीं।

6. औसत शक्ति: पहले मॉडल

  • नियम: इस आदर्श डोरी पर एक चलती साइन तरंग की औसत शक्ति Pavg = μω²A²v/2 वाट है। A शिखर आयाम है।
  • अनुपात: μ,v,आवृत्ति वही हों और A दुगुना तो शक्ति चार गुना। μ,v,A वही हों और आवृत्ति दुगुनी तो भी शक्ति चार गुना।
  • हमारी जांच: यह एक चलती तरंग का सूत्र है, आदर्श अप्रगामी तरंग की कुल शक्ति नहीं। तीव्रता शक्ति/क्षेत्रफल है, इकाई W m⁻²; यह शक्ति से अलग है।

7. अध्यारोपण और व्यतिकरण

  • नियम: रैखिक माध्यम में मिलते विस्थापन चिह्न सहित जुड़ते हैं: y = y1 + y2. केवल परिमाण न जोड़ें।
  • समान आवृत्ति: समान दिशा की दो साइन तरंगों का आयाम A और स्थिर कलांतर δ हो तो परिणामी आयाम R = 2A|cos(δ/2)|. समान कला में 2A; विपरीत कला में शून्य।
  • हमारी जांच: पूरा निरसन तभी जब आयाम समान और उस बिंदु पर कला विपरीत हो। असमान आयाम में न्यूनतम |A1 − A2| है। सुसंगत तरंगों की तीव्रताएं सीधे न जोड़ें; व्यतिकरण पद भी होता है।

8. अप्रगामी तरंग और बंधी डोरी

  • मॉडल: समान आयाम और आवृत्ति की विपरीत चलती तरंगें y = 2A sin(kx) cos(ωt) दे सकती हैं। निस्पंद और प्रस्पंद की जगहें स्थिर हैं।
  • दूरी: इस मूल के लिए निस्पंद x = nλ/2 हैं। पड़ोसी निस्पंद λ/2 दूर; निस्पंद से निकटतम प्रस्पंद λ/4 दूर। प्रस्पंद का आयाम 2A है।
  • बंधे सिरे: L लंबी डोरी के दोनों सिरे बंधे हों: λn = 2L/n; fn = nv/(2L), n = 1,2,3... . मूल n = 1; पहला अधिस्वर n = 2. आदर्श अप्रगामी तरंग में शुद्ध समय-औसत ऊर्जा परिवहन शून्य है।

9. नली: विस्थापन और दाब

  • सीमा: आदर्श वायु स्तंभ का बंद सिरा विस्थापन निस्पंद और दाब प्रस्पंद है। खुला सिरा लगभग विस्थापन प्रस्पंद और दाब निस्पंद है।
  • आवृत्तियां: अंत-संशोधन छोड़कर: दोनों सिरे खुले हों तो fn = nv/(2L), n = 1,2,3... . एक सिरा बंद हो तो fn = nv/(4L), केवल n = 1,3,5... .
  • हमारी जांच: एक सिरा बंद नली का पहला अधिस्वर तीसरा संनादी है, दूसरा नहीं। हवा में ध्वनि चाल लें, डोरी की नहीं। असली खुले सिरों में अंत-संशोधन चाहिए।

10. विस्पंद और दो संभव उत्तर

  • अर्थ: पास-पास की दो ध्वनि आवृत्तियां स्थिर श्रोता को आवर्ती तेज-मंद ध्वनि दे सकती हैं। विस्पंद आवृत्ति fb = |f1 − f2|; लगातार तेज ध्वनि के बीच समय 1/fb.
  • उदाहरण: 256 Hz संदर्भ और प्रति सेकंड 4 विस्पंद हों तो अज्ञात 252 Hz या 260 Hz हो सकता है। केवल विस्पंद से ऊंची-नीची आवृत्ति तय नहीं होती।
  • हमारी जांच: स्पष्ट धीमे विस्पंद के लिए आवृत्तियां पास हों; समान आयाम से तेज-मंद अंतर अधिक मिलता है। आवरण का चिह्न बदलने की दर को विस्पंद गिनती न समझें।
सीमा: चुनी हुई बुनियादें और हमारे मौलिक हल सहित प्रश्न; पूरे NCERT अभ्यास हल या संपूर्ण परीक्षा तैयारी नहीं। विस्तृत तरंग-समीकरण व्युत्पत्ति, ध्वनि चाल का ऊष्मागतिक आधार, डॉप्लर प्रभाव, विस्तृत परावर्तन/संचरण, अंत-संशोधन गणना और असमान आयाम के सामान्य कलांतर की व्युत्पत्ति शामिल नहीं। पुराने वीडियो अलग सामग्री हैं।

1. A wave carries a disturbance

  • Meaning: A mechanical wave is a disturbance that travels through a material medium and can carry energy. The particles oscillate near their equilibrium positions; the whole medium does not travel with the pattern.
  • Types: Transverse: particle displacement is perpendicular to propagation, as in a stretched string. Longitudinal: parallel to propagation, as in sound in air.
  • Our check: Sound needs a medium. Light is electromagnetic and can travel through vacuum. Do not use a string-speed formula for every kind of wave.

2. Read a travelling sine wave

  • Rule: For positive k and ω, y = A sin(kx − ωt + φ) travels along +x; changing −ωt to +ωt gives −x. A is amplitude and φ initial phase.
  • Definitions: k = 2π/λ, ω = 2πf, T = 1/f and wave speed v = ω/k = fλ. Here λ is distance between neighbouring points in the same phase.
  • Our check: Use metres and seconds. The sine argument is dimensionless, in radians. Follow constant phase to find direction rather than memorising the sign without its equation.

3. Particle velocity is not wave speed

  • Rule: For y = A sin(kx − ωt + φ), hold x fixed: particle velocity uy = ∂y/∂t = −Aω cos(kx − ωt + φ). Particle acceleration ay = −ω²y.
  • Difference: The pattern moves along x at v = ω/k; a string particle moves transversely. Maximum particle speed is Aω, not necessarily v.
  • Our check: At x = 0, t = 0, φ = 0, y = 0 but uy = −Aω. Zero displacement does not mean zero particle velocity.

4. Phase difference

  • Rule: At the same time, phase difference between two points is Δφ = kΔx = 2πΔx/λ for the stated wave. At a fixed point, phase changes by −ωΔt.
  • Example: Separation λ/4 gives π/2 phase difference; λ/2 gives π. Separation λ gives 2π, equivalent phase.
  • Our check: State same time or same place. Neighbouring crests are λ apart; a crest and its neighbouring trough are λ/2 apart.

5. Speed on an ideal stretched string

  • Model: For a uniform flexible string under constant tension F with small transverse slopes: v = √(F/μ), where μ = mass/length in kg m⁻¹.
  • Scaling: Four times tension gives twice the speed. Four times μ gives half the speed. The driver fixes frequency; the medium and tension set speed in this model.
  • Our check: If frequency doubles at unchanged F and μ, wavelength halves, while wave speed stays the same. F is tension, not period T.

6. Average power: state the model

  • Rule: One sinusoidal travelling wave on that ideal string carries average power Pavg = μω²A²v/2, in watts. A is peak amplitude.
  • Scaling: At unchanged μ, v and frequency, doubling A makes Pavg four times larger. At unchanged μ, v and A, doubling frequency also makes it four times larger.
  • Our check: This is a single travelling-wave formula, not the net power of an ideal standing wave. Intensity is power per area, in W m⁻²; do not confuse it with power.

7. Superposition and interference

  • Rule: In a linear medium, overlapping displacements add algebraically: y = y1 + y2. Add signed displacements, not their absolute values.
  • Same-frequency waves: Two same-direction sinusoidal waves, each amplitude A and constant phase difference δ, have resultant amplitude R = 2A|cos(δ/2)|. In phase: 2A; opposite phase: zero.
  • Our check: Cancellation to zero needs equal amplitudes and opposite phase at that point. For unequal amplitudes the minimum amplitude is |A1 − A2|. Do not add intensities without interference terms for coherent waves.

8. Standing waves and fixed strings

  • Model: Equal-amplitude, equal-frequency waves travelling oppositely can give y = 2A sin(kx) cos(ωt). The pattern has fixed nodes and antinodes.
  • Spacing: Nodes: x = nλ/2 for this origin. Neighbouring nodes are λ/2 apart; a node and its nearest antinode are λ/4 apart. Antinode amplitude is 2A.
  • Fixed ends: A string of length L fixed at both ends has λn = 2L/n and fn = nv/(2L), n = 1,2,3... . Fundamental n = 1; first overtone n = 2. Ideal standing waves have zero net time-averaged energy transport.

9. Pipes: displacement versus pressure

  • Boundary: For an ideal air column, a closed end is a displacement node and pressure antinode. An open end is approximately a displacement antinode and pressure node.
  • Frequencies: Ignoring end correction: open–open fn = nv/(2L), n = 1,2,3... . One end closed: fn = nv/(4L), n = 1,3,5... only.
  • Our check: For a one-end-closed pipe the first overtone is the third harmonic, not second. Use sound speed in air, not string speed; real openings need end corrections.

10. Beats and an ambiguity

  • Meaning: Two nearby sound frequencies can produce periodic loudness changes at a fixed listener. Beat frequency fb = |f1 − f2|; time between successive loudness maxima is 1/fb.
  • Example: A 256 Hz reference and 4 beats each second allow either 252 Hz or 260 Hz for the unknown. Beats alone do not tell which is higher.
  • Our check: For clear slow beats the frequencies must be close, and similar amplitudes give stronger contrast. Do not mistake the envelope sign-change rate for the beat count.

तरंग का रूप x दिशा में v = ω/k से चलता है; डोरी का कण अनुप्रस्थ चलता है। अधिकतम कण चाल Aω है, जरूरी नहीं v हो।
λ/4 दूरी पर π/2; λ/2 पर π; λ पर 2π, अर्थात समान कला।
F चार गुना तो चाल दुगुनी। μ चार गुना तो चाल आधी। चालक आवृत्ति तय करता है; इस मॉडल में माध्यम और तनाव चाल तय करते हैं।
μ,v,आवृत्ति वही हों और A दुगुना तो शक्ति चार गुना। μ,v,A वही हों और आवृत्ति दुगुनी तो भी शक्ति चार गुना।
समान दिशा की दो साइन तरंगों का आयाम A और स्थिर कलांतर δ हो तो परिणामी आयाम R = 2A|cos(δ/2)|. समान कला में 2A; विपरीत कला में शून्य।
इस मूल के लिए निस्पंद x = nλ/2 हैं। पड़ोसी निस्पंद λ/2 दूर; निस्पंद से निकटतम प्रस्पंद λ/4 दूर। प्रस्पंद का आयाम 2A है।
अंत-संशोधन छोड़कर: दोनों सिरे खुले हों तो fn = nv/(2L), n = 1,2,3... . एक सिरा बंद हो तो fn = nv/(4L), केवल n = 1,3,5... .
256 Hz संदर्भ और प्रति सेकंड 4 विस्पंद हों तो अज्ञात 252 Hz या 260 Hz हो सकता है। केवल विस्पंद से ऊंची-नीची आवृत्ति तय नहीं होती।
Transverse: particle displacement is perpendicular to propagation, as in a stretched string. Longitudinal: parallel to propagation, as in sound in air.
k = 2π/λ, ω = 2πf, T = 1/f and wave speed v = ω/k = fλ. Here λ is distance between neighbouring points in the same phase.
The pattern moves along x at v = ω/k; a string particle moves transversely. Maximum particle speed is Aω, not necessarily v.
Separation λ/4 gives π/2 phase difference; λ/2 gives π. Separation λ gives 2π, equivalent phase.
Four times tension gives twice the speed. Four times μ gives half the speed. The driver fixes frequency; the medium and tension set speed in this model.
At unchanged μ, v and frequency, doubling A makes Pavg four times larger. At unchanged μ, v and A, doubling frequency also makes it four times larger.
Two same-direction sinusoidal waves, each amplitude A and constant phase difference δ, have resultant amplitude R = 2A|cos(δ/2)|. In phase: 2A; opposite phase: zero.
Nodes: x = nλ/2 for this origin. Neighbouring nodes are λ/2 apart; a node and its nearest antinode are λ/4 apart. Antinode amplitude is 2A.
Ignoring end correction: open–open fn = nv/(2L), n = 1,2,3... . One end closed: fn = nv/(4L), n = 1,3,5... only.
A 256 Hz reference and 4 beats each second allow either 252 Hz or 260 Hz for the unknown. Beats alone do not tell which is higher.

Q1 A 50 Hz wave has wavelength 0.80 m. Find period and wave speed.
Show answer

Rule: T = 1/f; v = fλ.

Steps: 1. T = 1/50 = 0.020 s. 2. v = 50 × 0.80 = 40 m s⁻¹.

Answer/check: 0.020 s; 40 m s⁻¹. Frequency × length has speed units.

Q2 y = 0.020 sin(4πx − 80πt), with x,y in m and t in s. Find A,λ,f and direction.
Show answer

Rule: Compare with A sin(kx − ωt); λ = 2π/k; f = ω/(2π).

Steps: 1. A = 0.020 m, k = 4π m⁻¹, ω = 80π rad s⁻¹. 2. λ = 0.50 m, f = 40 Hz; constant phase moves along +x.

Answer/check: 2.0 cm; 0.50 m; 40 Hz; +x. Speed = ω/k = 20 m s⁻¹.

Q3 For that wave, find particle velocity at x = 0,t = 0 and compare with pattern speed.
Show answer

Rule: uy = −Aω cos(kx − ωt); v = ω/k.

Steps: 1. At zero phase, uy = −0.020 × 80π = −1.6π m s⁻¹. 2. v = 20 m s⁻¹ along +x.

Answer/check: uy ≈ −5.03 m s⁻¹ transversely; pattern speed 20 m s⁻¹. These are different quantities.

Q4 λ = 1.2 m. At one instant two points are 0.30 m apart. Phase difference magnitude?
Show answer

Rule: |Δφ| = 2π|Δx|/λ.

Steps: 1. Separation is 0.30/1.2 = 1/4 wavelength. 2. |Δφ| = 2π/4 = π/2 rad.

Answer/check: π/2 rad, not π. Same-time comparison is essential.

Q5 A 2 m uniform string has mass 0.010 kg and tension 50 N. Find wave speed; then quadruple tension.
Show answer

Rule: μ = m/L; v = √(F/μ).

Steps: 1. μ = 0.010/2 = 0.005 kg m⁻¹; v = √(50/0.005) = 100 m s⁻¹. 2. New F = 200 N gives 200 m s⁻¹.

Answer/check: 100 then 200 m s⁻¹. This assumes small transverse slopes and unchanged μ.

Q6 One sinusoidal travelling string wave has μ = 0.010 kg m⁻¹,v = 100 m s⁻¹,A = 0.010 m,ω = 20 rad s⁻¹. Average power?
Show answer

Rule: Pavg = μω²A²v/2.

Steps: 1. Pavg = 0.5 × 0.010 × 400 × 0.0001 × 100 = 0.020 W. 2. Double A with other quantities fixed: new power = 4 × 0.020 = 0.080 W.

Answer/check: 0.020 W; after doubling amplitude, 0.080 W. Not a standing-wave net-power formula.

Q7 Two same-direction sinusoidal waves have the same frequency, amplitude 3 mm each and phase difference 2π/3. Resultant amplitude?
Show answer

Rule: R = 2A|cos(δ/2)|.

Steps: 1. δ/2 = π/3, with cos(π/3) = 1/2. 2. R = 2 × 3 × 1/2 = 3 mm.

Answer/check: 3 mm, not 6 mm. The result lies between 0 and 2A = 6 mm.

Q8 String fixed at both ends: L = 0.80 m,v = 80 m s⁻¹. Find first three frequencies and adjacent-node spacing in n = 3.
Show answer

Rule: fn = nv/(2L); λn = 2L/n; node spacing = λn/2.

Steps: 1. f1 = 80/1.6 = 50 Hz; f2 = 100 Hz; f3 = 150 Hz. 2. For n = 3, spacing = L/3 ≈ 0.267 m.

Answer/check: 50,100,150 Hz; 0.267 m. n = 3 has three loops and four nodes including the ends.

Q9 Take sound speed 340 m s⁻¹,L = 0.85 m. Find fundamental and first overtone for open–open and one-end-closed pipes. Ignore end correction.
Show answer

Rule: Open: f1 = v/(2L), first overtone 2f1. One end closed: f1 = v/(4L), first overtone 3f1.

Steps: 1. Open: f1 = 340/1.70 = 200 Hz; overtone 400 Hz. 2. One end closed: f1 = 340/3.40 = 100 Hz; overtone 300 Hz.

Answer/check: Open:200,400 Hz. One end closed:100,300 Hz. First overtone is not always second harmonic.

Q10 A 256 Hz fork produces four beats per second with an unknown fork. Find possible frequencies and time between loudness maxima.
Show answer

Rule: fb = |fu − 256|; Tbeat = 1/fb.

Steps: 1. |fu − 256| = 4 gives fu = 252 or 260 Hz. 2. Tbeat = 1/4 = 0.25 s.

Answer/check: 252 Hz or 260 Hz; 0.25 s. More information is needed to choose which frequency.
