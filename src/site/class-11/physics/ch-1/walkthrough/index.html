4. Error Propagation - Errors JUDTE Hain!

Measurement kabhi exact nahi hoti. Rules: Z = A ± B → ΔZ = ΔA + ΔB (absolute errors add!) | Z = A×B ya A/B → ΔZ/Z = ΔA/A + ΔB/B (relative errors add!) | Z = Aᵖ → power multiply. Values badlo, % error dekho:

Units + Dimensions ⭐

7 fundamental: m, kg, s, A, K, mol, cd | Dimensions: speed [LT⁻¹], acceleration [LT⁻²], force [MLT⁻²], energy/work [ML²T⁻²], pressure [ML⁻¹T⁻²], power [ML²T⁻³] | uses: formula check (LHS=RHS), formula nikalna, units convert | limitation: dimensionless constants (2π) nahi milte

Significant Figures ⭐

non-zero sab significant | beech ke zeroes YES (2.03→3) | leading zeroes NO (0.0023→2) | trailing zeroes decimal ke baad YES (2.300→4) | multiply/divide: kam sig figs wale ke barabar | add/subtract: decimal places dekho

Errors ⭐

absolute = |measured − true| | relative = Δa/a | percentage = ×100 | Z = A±B → ΔZ = ΔA+ΔB (JUDTE hain!) | Z = AᵖBᵑ → ΔZ/Z = p(ΔA/A) + q(ΔB/B) - powers multiply!

Instruments

Vernier: LC = 1 MSD − 1 VSD = 0.01 cm | Screw gauge: LC = pitch/circular divisions = 0.01 mm | reading = MSR + n×LC (n = coinciding line)

Scale + Prefixes
