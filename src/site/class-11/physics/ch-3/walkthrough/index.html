Motion in a Plane Ka Visual Walkthrough

5 animated scenes - vectors jodo aur todo, projectile udao, nadi paar karo, circular motion ka acceleration dekho.

1. Vector Addition - Angle Ghumao, Resultant Badlo

A aur B ko head-to-tail jodo: resultant R = A + B, magnitude |R| = √(A² + B² + 2AB cosθ). Dono ke beech ka angle θ ghumao - same vectors, alag alag resultant!

vectors ke beech angle θ = 60°

2. Resolution - Vector Ko x aur y Mein Todo

Har 2D vector do shadows ka sum hai: Ax = A cosθ (x-shadow) aur Ay = A sinθ (y-shadow). Angle badlo aur shadows ka badalna dekho - components se addition EASY ho jaata hai!

vector ka angle θ = 35°

3. Projectile - Phenko, Parabola Banao

Sirf gravity ke under free motion: ax = 0, ay = −g. x aur y motions bilkul independent! u aur θ set karo, "Phenko!" dabao - range, height, time of flight sab live:

initial speed u u = 20 m/s
launch angle θ θ = 45°

4. River-Boat - Nadi Paar Karo

Ground velocity = boat ka velocity + river ka velocity (vAB = vA − vB wala relative velocity). Boat seedha opposite bank aim kar rahi hai (shortest TIME wala case) - river kitna drift karayegi?

boat speed (still water) vb = 5.0 m/s
river speed vr = 2.0 m/s

5. Circular Motion - Seedha Nahi, Center Ki Ore!

CONSTANT speed phir bhi ACCELERATED motion - kyunki direction badal rahi hai! Velocity hamesha tangent, acceleration hamesha center ki taraf: a = v²/r. v aur r badlo:

speed v v = 10 m/s
radius r r = 25 m

Formula Pack - Screenshot Le Lo

Vector Addition

|R| = √(A² + B² + 2AB cosθ) | θ = 0° → A+B (max), θ = 180° → |A−B| (min), θ = 90° → √(A²+B²) | tanφ = B sinθ / (A + B cosθ)

Resolution (Components)

Ax = A cosθ | Ay = A sinθ | A = √(Ax² + Ay²) | tanθ = Ay/Ax | resultant ka component = components ka sum

Projectile Motion ⭐

R = u² sin2θ / g (θ = 45° pe MAX) | H = u² sin²θ / 2g | T = 2u sinθ / g | trajectory y = x tanθ − gx²/(2u² cos²θ) | top pe v = u cosθ ≠ 0 (trap!) | θ aur 90°−θ SAME range

Relative Velocity

vAB = vA − vB | river-boat: crossing time = width / vboat (boat seedha aim kare toh), drift = vriver × time | rain-man: umbrella relative velocity ki direction mein

Uniform Circular Motion

a = v²/r = ω²r (CENTER ki taraf) | v = ωr | ω = 2π/T = 2πf | speed constant, VELOCITY nahi (direction badalti hai) | v ⊥ a hamesha
