Class 8 / Maths / Distributive identities

Distributive property and identities

Multiplication distributes over addition: a(b + c) = ab + ac. Area diagrams make this visible and lead to the square and difference identities.

Three ideas about distributing

1. Multiplication distributes over addition

For any three numbers a, b and c, the distributive property says a(b + c) = ab + ac.

Picture a rows of dots with b + c columns: the whole array is a(b + c) dots, and it splits into ab dots and ac dots.

This also gives (a + b)c = ac + bc, and it explains increases: if 27 grows by 1, then 23 x 27 grows by 23, because 23(27 + 1) = 23 x 27 + 23.

Distributive expansions
ExpressionExpansion
a(b + c)ab + ac
(a + b)cac + bc
23 x 2823 x 27 + 23 = 644

Worked example

Use the distributive property to find 23 x 28.

Three steps

  1. Write 28 as 27 + 1.
  2. Then 23 x 28 = 23(27 + 1) = 23 x 27 + 23 = 621 + 23.
  3. So 23 x 28 = 644.

2. A product of two sums

To expand (a + m)(b + n), treat (a + m) as one term and distribute twice.

The product is the sum of each term of the first bracket times each term of the second: (a + m)(b + n) = ab + an + mb + mn.

An area diagram shows the same thing: a rectangle of sides a + m and b + n splits into four regions ab, an, mb and mn. This expansion is an identity: it holds for all values of the letters.

Products of two sums
ProductExpansion
(a + m)(b + n)ab + an + mb + mn
(x + 2)(x + 3)x^2 + 5x + 6

Worked example

Expand (x + 2)(x + 3).

Three steps

  1. Multiply each term of the first bracket by each term of the second: x^2 + 3x + 2x + 6.
  2. Combine the like terms 3x and 2x.
  3. So (x + 2)(x + 3) = x^2 + 5x + 6.

3. Square and difference identities

Splitting a square of side a + b into four regions gives (a + b)^2 = a^2 + 2ab + b^2.

Similarly, (a - b)^2 = a^2 - 2ab + b^2, and (a + b)(a - b) = a^2 - b^2.

These identities make squares easy: 65^2 = (60 + 5)^2 = 3600 + 600 + 25 = 4225, and 55^2 = (60 - 5)^2 = 3600 - 600 + 25 = 3025.

Special identities
IdentityExpansionExample
(a + b)^2a^2 + 2ab + b^265^2 = 4225
(a - b)^2a^2 - 2ab + b^255^2 = 3025
(a + b)(a - b)a^2 - b^265 x 55 = 3575

Worked example

Find 65^2 using the identity for (a + b)^2.

Three steps

  1. Write 65 as 60 + 5.
  2. Apply (a + b)^2 = a^2 + 2ab + b^2: 60^2 + 2 x (60 x 5) + 5^2 = 3600 + 600 + 25.
  3. So 65^2 = 4225.

Try it yourself

Q1. What does a(b + c) expand to?

Show answer and reasoning

Three steps

  1. Multiplication distributes over addition.
  2. The term a multiplies b and c separately.
  3. So a(b + c) = ab + ac.

Q2. Find 55^2 using (60 - 5)^2.

Show answer and reasoning

Three steps

  1. Apply (a - b)^2 = a^2 - 2ab + b^2 with a = 60, b = 5.
  2. That is 3600 - 600 + 25.
  3. So 55^2 = 3025.

Q3. What is (a + b)(a - b), and what is 65 x 55?

Show answer and reasoning

Three steps

  1. Expanding gives a^2 - ab + ab - b^2 = a^2 - b^2.
  2. Write 65 x 55 as (60 + 5)(60 - 5) = 60^2 - 5^2.
  3. So 65 x 55 = 3600 - 25 = 3575.

Q4. What does (a + m)(b + n) expand to?

Show answer and reasoning

Three steps

  1. Treat (a + m) as one term and distribute over (b + n).
  2. Multiply each term of one bracket by each term of the other.
  3. So (a + m)(b + n) = ab + an + mb + mn.

वितरण के तीन विचार

1. गुणन योग पर वितरित होता है

किन्हीं तीन संख्याओं a, b और c के लिए वितरण गुण कहता है a(b + c) = ab + ac।

b + c स्तंभों वाली a पंक्तियों के बिंदुओं की कल्पना करें: पूरी व्यवस्था a(b + c) बिंदु है, और वह ab बिंदुओं और ac बिंदुओं में बँटती है।

इससे (a + b)c = ac + bc भी मिलता है, और यह वृद्धि भी समझाता है: यदि 27 एक बढ़े, तो 23 x 27 में 23 की वृद्धि होती है, क्योंकि 23(27 + 1) = 23 x 27 + 23।

वितरण प्रसार
व्यंजकप्रसार
a(b + c)ab + ac
(a + b)cac + bc
23 x 2823 x 27 + 23 = 644

हल किया हुआ उदाहरण

वितरण गुण से 23 x 28 ज्ञात करें।

तीन चरण

  1. 28 को 27 + 1 लिखें।
  2. तब 23 x 28 = 23(27 + 1) = 23 x 27 + 23 = 621 + 23।
  3. तो 23 x 28 = 644।

2. दो योगों का गुणनफल

(a + m)(b + n) का प्रसार करने के लिए (a + m) को एक पद मानकर दो बार वितरित करें।

गुणनफल पहले कोष्ठक के हर पद और दूसरे कोष्ठक के हर पद के गुणनफलों का योग है: (a + m)(b + n) = ab + an + mb + mn।

क्षेत्र-आरेख भी यही दिखाता है: a + m और b + n भुजाओं वाला आयत चार क्षेत्रों ab, an, mb और mn में बँटता है। यह प्रसार एक सर्वसमिका है: यह अक्षरों के सभी मानों के लिए सत्य है।

दो योगों के गुणनफल
गुणनफलप्रसार
(a + m)(b + n)ab + an + mb + mn
(x + 2)(x + 3)x^2 + 5x + 6

हल किया हुआ उदाहरण

(x + 2)(x + 3) का प्रसार करें।

तीन चरण

  1. पहले कोष्ठक के हर पद को दूसरे कोष्ठक के हर पद से गुणा करें: x^2 + 3x + 2x + 6।
  2. समान पदों 3x और 2x को मिलाएँ।
  3. तो (x + 2)(x + 3) = x^2 + 5x + 6।

3. वर्ग और अंतर की सर्वसमिकाएँ

a + b भुजा के वर्ग को चार क्षेत्रों में बांटने से मिलता है (a + b)^2 = a^2 + 2ab + b^2।

इसी तरह (a - b)^2 = a^2 - 2ab + b^2, और (a + b)(a - b) = a^2 - b^2।

ये सर्वसमिकाएँ वर्ग आसान बनाती हैं: 65^2 = (60 + 5)^2 = 3600 + 600 + 25 = 4225, और 55^2 = (60 - 5)^2 = 3600 - 600 + 25 = 3025।

(a + b)^2 की सर्वसमिका से 65^2 ज्ञात करें।

तीन चरण

  1. 65 को 60 + 5 लिखें।
  2. (a + b)^2 = a^2 + 2ab + b^2 लगाएँ: 60^2 + 2 x (60 x 5) + 5^2 = 3600 + 600 + 25।
  3. तो 65^2 = 4225।

खुद आज़माएँ

Q1. a(b + c) का प्रसार क्या है?

उत्तर और तर्क दिखाएँ

तीन चरण

  1. गुणन योग पर वितरित होता है।
  2. पद a, b और c को अलग-अलग गुणा करता है।
  3. तो a(b + c) = ab + ac।

Q2. (60 - 5)^2 से 55^2 ज्ञात करें।

उत्तर और तर्क दिखाएँ

तीन चरण

  1. a = 60, b = 5 के साथ (a - b)^2 = a^2 - 2ab + b^2 लगाएँ।
  2. यह है 3600 - 600 + 25।
  3. तो 55^2 = 3025।

Q3. (a + b)(a - b) क्या है, और 65 x 55 कितना है?

उत्तर और तर्क दिखाएँ

तीन चरण

  1. प्रसार देता है a^2 - ab + ab - b^2 = a^2 - b^2।
  2. 65 x 55 को (60 + 5)(60 - 5) = 60^2 - 5^2 लिखें।
  3. तो 65 x 55 = 3600 - 25 = 3575।

Q4. (a + m)(b + n) का प्रसार क्या है?

उत्तर और तर्क दिखाएँ

तीन चरण

  1. (a + m) को एक पद मानकर (b + n) पर वितरित करें।
  2. एक कोष्ठक के हर पद को दूसरे के हर पद से गुणा करें।
  3. तो (a + m)(b + n) = ab + an + mb + mn।

Distributive property aur identities

Distribute karne ke teen ideas

1. Multiplication addition par distribute hota hai

Kisi bhi teen numbers a, b aur c ke liye distributive property kehti hai a(b + c) = ab + ac.

b + c columns wali a rows ke dots socho: poori array a(b + c) dots hai, aur wo ab dots aur ac dots mein split hoti hai.

Isse (a + b)c = ac + bc bhi milta hai, aur ye increase bhi samjhata hai: agar 27 ek badhe, to 23 x 27 mein 23 ka increase hota hai, kyunki 23(27 + 1) = 23 x 27 + 23.

Distributive expansions
ExpressionExpansion
a(b + c)ab + ac
(a + b)cac + bc
23 x 2823 x 27 + 23 = 644

Solved example

Distributive property se 23 x 28 nikalo.

Teen steps

  1. 28 ko 27 + 1 likho.
  2. Tab 23 x 28 = 23(27 + 1) = 23 x 27 + 23 = 621 + 23.
  3. To 23 x 28 = 644.

2. Do sums ka product

(a + m)(b + n) expand karne ke liye (a + m) ko ek term maankar do baar distribute karo.

Product first bracket ke har term aur second bracket ke har term ke products ka sum hai: (a + m)(b + n) = ab + an + mb + mn.

Area diagram bhi yehi dikhata hai: a + m aur b + n sides wala rectangle chaar regions ab, an, mb aur mn mein split hota hai. Ye expansion ek identity hai: ye letters ki saari values ke liye true hai.

Do sums ke products
ProductExpansion
(a + m)(b + n)ab + an + mb + mn
(x + 2)(x + 3)x^2 + 5x + 6

Solved example

(x + 2)(x + 3) expand karo.

Teen steps

  1. First bracket ke har term ko second bracket ke har term se multiply karo: x^2 + 3x + 2x + 6.
  2. Like terms 3x aur 2x ko milao.
  3. To (x + 2)(x + 3) = x^2 + 5x + 6.

3. Square aur difference identities

a + b side ke square ko chaar regions mein baantne se milta hai (a + b)^2 = a^2 + 2ab + b^2.

Isi tarah (a - b)^2 = a^2 - 2ab + b^2, aur (a + b)(a - b) = a^2 - b^2.

Ye identities squares easy banati hain: 65^2 = (60 + 5)^2 = 3600 + 600 + 25 = 4225, aur 55^2 = (60 - 5)^2 = 3600 - 600 + 25 = 3025.

Solved example

(a + b)^2 ki identity se 65^2 nikalo.

Teen steps

  1. 65 ko 60 + 5 likho.
  2. (a + b)^2 = a^2 + 2ab + b^2 lagao: 60^2 + 2 x (60 x 5) + 5^2 = 3600 + 600 + 25.
  3. To 65^2 = 4225.

Khud try karo

Q1. a(b + c) ka expansion kya hai?

Answer aur reasoning dikhao

Teen steps

  1. Multiplication addition par distribute hota hai.
  2. Term a, b aur c ko alag-alag multiply karta hai.
  3. To a(b + c) = ab + ac.

Q2. (60 - 5)^2 se 55^2 nikalo.

Answer aur reasoning dikhao

Teen steps

  1. a = 60, b = 5 ke saath (a - b)^2 = a^2 - 2ab + b^2 lagao.

Q3. (a + b)(a - b) kya hai, aur 65 x 55 kitna hai?

Answer aur reasoning dikhao

Teen steps

  1. Expansion deta hai a^2 - ab + ab - b^2 = a^2 - b^2.
  2. 65 x 55 ko (60 + 5)(60 - 5) = 60^2 - 5^2 likho.
  3. To 65 x 55 = 3600 - 25 = 3575.

Q4. (a + m)(b + n) ka expansion kya hai?

Answer aur reasoning dikhao

Teen steps

  2. Ek bracket ke har term ko doosre ke har term se multiply karo.
  3. To (a + m)(b + n) = ab + an + mb + mn.
