1️⃣ Neural System aur Neuron Structure ⭐⭐

  • Neural system ka organisation ⭐: humans me Central Neural System (CNS) — brain + spinal cord (information processing + control!) aur Peripheral Neural System (PNS) — nerves jo CNS ko body se jodte hain. PNS ke 2 hisse: somatic (voluntary — skeletal muscles!) aur autonomic (involuntary — sympathetic + parasympathetic!).
  • Neuron ⭐⭐: neural system ki structural + functional unit — 3 parts: cell body (cyton) — nucleus + cytoplasm + Nissl's granules!; dendrites — short, branched, impulses TOWARDS cell body; axon — lamba, impulses AWAY from cell body, tip pe synaptic knobs (neurotransmitters!).
  • Neuron types ⭐⭐: Multipolar — 1 axon + many dendrites (cerebral cortex — sabse common!); Bipolar — 1 axon + 1 dendrite (retina of eye!); Unipolar — cell body se ek hi process jo dono taraf (embryonic stage!).
  • Axon 2 types ⭐: Myelinated — Schwann cells ka myelin sheath wrap (gaps = Nodes of Ranvier! — impulse FAST, saltatory conduction!); Unmyelinated — Schwann cell but no myelin — impulse SLOW (smooth muscle me!).
  • Neuroglia ⭐: support cells — neurons ka 50%+ volume, protect + support + nourish karte hain.

💡 Dendrite = IN, axon = OUT. Myelinated = fast (Nodes of Ranvier + saltatory!). Multipolar = most common!

2️⃣ Nerve Impulse — Generation aur Conduction ⭐⭐

  • Resting potential ⭐⭐: rest pe axon membrane POLARISED — bahar +ve (Na+ zyada!), andar -ve (K+ + negatively charged proteins!). Na-K pump — 3 Na+ bahar, 2 K+ andar (active transport, ATP!) — resting potential ~-70 mV.
  • Action potential ⭐⭐: stimulus → membrane pe Na+ channels OPEN → Na+ rush IN → DEPOLARISATION (andar +ve, bahar -ve! ~+30 mV!) → yehi action potential/nerve impulse! Phir K+ bahar jaata hai → repolarisation (back to -70 mV!).
  • Conduction ⭐: depolarised point ke agle point pe bhi wahi repeat hota hai — impulse current ki tarah travel karta hai axon ke saath.
  • Saltatory conduction ⭐⭐: MYELINATED axons me impulse Node of Ranvier se node JUMP karta hai (myelin insulator!) — bahut FAST (unmyelinated se ~50x fast!).
  • Refractory period ⭐: action potential ke turant baad membrane thodi der ke liye doosra impulse pass nahi kar sakti (Na+ channels reset!).

🎯 Resting = -70 mV (bahar +, andar -; Na-K pump 3 out, 2 in!). Stimulus → Na+ in → depolarisation (+30) → K+ out → repolarise!

3️⃣ Synapse — Impulse Transmission ⭐⭐

  • Synapse ⭐: ek neuron ke axon-end aur doosre neuron ke dendrite/cell body ke beech ka junction — 2 types: electrical aur chemical.
  • Electrical synapse ⭐⭐: pre-aur post-synaptic membranes bahut PAAS — impulse direct current flow se jaata hai (gap junctions!) — FAST, but RARE (humans me kam!).
  • Chemical synapse ⭐⭐: pre-synaptic neuron + synaptic cleft (gap!) + post-synaptic neuron. Impulse aane pe pre-synaptic membrane pe Ca2+ in → synaptic vesicles membrane se fuse → NEUROTRANSMITTER release (cleft me!) → post-synaptic membrane ke receptors se bind → naye ion channels open → naya potential (excitatory ya inhibitory!).
  • Neurotransmitters ⭐: acetylcholine, dopamine, GABA, serotonin, glutamate — excitatory (depolarise) ya inhibitory (hyperpolarise!).
  • Comparison ⭐: chemical = slow but versatile + ONE-WAY (unidirectional!); electrical = fast, bidirectional ho sakta.

🎯 Chemical synapse = vesicle → neurotransmitter → cleft → receptor → naya signal. One-way transmission! Electrical = fast, rare.

4️⃣ Brain — Forebrain, Midbrain, Hindbrain ⭐⭐

  • Brain ke 3 main parts ⭐⭐: Forebrain + Midbrain + Hindbrain. Brain ~1200-1400 g (adult human!). Skull + 3 meninges (dura mater, arachnoid, pia mater) se protect!
  • Forebrain ⭐⭐: sabse BADA part — cerebrum (2 hemispheres — corpus callosum se jode! — outer grey matter cerebral cortex — sensory, motor, association areas — thinking, memory, willpower! + inner white matter — tracts!) + thalamus (sensory/motor relay to cortex!) + hypothalamus ⭐⭐ (thalamus ke neeche — body temperature, hunger, thirst, emotions, hormone control via pituitary — 'master controller'!) + limbic system (amygdala + hippocampus — emotions, memory!).
  • Midbrain ⭐⭐: forebrain aur hindbrain ke beech — corpora quadrigemina (4 lobes — visual + auditory reflexes!) + cerebral peduncles (tracts!).
  • Hindbrain ⭐⭐: Pons ⭐ (fibre tracts connect different regions — pneumotaxic centre for breathing!) + cerebellum ⭐⭐ (highly convoluted surface — posture + balance + coordination of body movements!) + medulla oblongata ⭐⭐ (cardiovascular + respiratory + gastric reflexes — VITAL centres — 'vital knot'!).
  • Cerebellum vs cerebrum: cerebrum = think/decide; cerebellum = balance/coordinate (drunk person ka chakkar = cerebellum affected!).

🎯 Cerebrum = think; hypothalamus = hunger/temp; cerebellum = balance; medulla = vital centres (heart+breathing); pons = relay+pneumotaxic!

5️⃣ Reflex Action aur Sense Organs ⭐⭐

  • Reflex action ⭐⭐: sudden, involuntary, quick response — reflex arc ⭐ = receptor → sensory (afferent) neuron → CNS (interneuron) → motor (efferent) neuron → effector (muscle/gland). Example: knee-jerk, hand hatna hot surface se! Spinal cord = reflex centre (brain ko baad me pata chalta hai!).
  • Eye structure ⭐⭐: 3 layers — sclera (outer, tough, white — protect! — aage cornea transparent!) + choroid (middle, vascular — aage ciliary body + iris — pupil control — colour!) + retina (inner — photoreceptors: rods (dim light, no colour — rhodopsin!) + cones (bright light + colour vision — red/green/blue!)). Blind spot ⭐ = optic nerve exit (NO photoreceptors!); fovea centralis ⭐ = macula lutea (yellow spot) me — sirf cones, SHARPEST vision!
  • Image formation ⭐: light → cornea → pupil → lens (ciliary muscles focus!) → retina pe inverted real image → rods/cones action potential → optic nerve → brain (visual cortex — image upright process!).
  • Ear structure ⭐⭐: Outer ear — pinna (collect!) + auditory canal → tympanic membrane (eardrum!); Middle ear — 3 ossicles malleus → incus → stapes (amplify!) + Eustachian tube (pressure balance to pharynx!); Inner ear — cochlea (hearing — Organ of Corti — hair cells!) + vestibular apparatus (semicircular canals + utricle + saccule — BALANCE!).
  • Hearing path ⭐: sound → pinna → canal → eardrum vibrate → ossicles amplify → oval window → cochlea fluid waves → hair cells → auditory nerve → brain. Balance = semicircular canals (rotation!) + utricle/saccule (linear/gravity!).

🎯 Reflex arc: receptor→sensory→CNS→motor→effector. Eye: rods = dim, cones = colour; fovea = sharpest; blind spot = no receptors. Ear: cochlea = hear, semicircular = balance!

1️⃣ तंत्रिका-तंत्र और न्यूरॉन ⭐⭐

  • संगठन ⭐: CNS — मस्तिष्क + मेरुरज्जु (प्रसंस्करण + नियंत्रण!) और PNS — तंत्रिकाएँ जो CNS को शरीर से जोड़तीं। PNS: कायिक (ऐच्छिक!) + स्वायत्त (अनैच्छिक — सहानुभूतिक + परासहानुभूतिक!)।
  • न्यूरॉन ⭐⭐: संरचनात्मक + कार्यात्मक इकाई — 3 भाग: कोशिका-काय (cyton) — केंद्रक + निस्ल-कण!; द्रुमिकाएँ (dendrites) — लघु, शाखित, आवेग कोशिका-काय की ओर; तंत्रिकाक्ष (axon) — लंबा, आवेग दूर, सिरे पर सिनैप्टिक-घुमाव!
  • प्रकार ⭐⭐: बहुध्रुवीय — 1 तंत्रिकाक्ष + अनेक द्रुमिकाएँ (सबसे सामान्य!); द्विध्रुवीय — 1+1 (रेटिना!); एकध्रुवीय — एक प्रक्रिया (भ्रूणीय!)।
  • तंत्रिकाक्ष ⭐: मायेलिनी — मायेलिन-आच्छदन (रिक्तियाँ = रैंवियर-संधि! — आवेग तीव्र, लवणगमन!); अमायेलिनी — धीमा।
  • न्यूरोग्लिया ⭐: सहायक कोशिकाएँ — न्यूरॉन की रक्षा + पोषण।

💡 द्रुमिका = अंदर, तंत्रिकाक्ष = बाहर। मायेलिनी = तीव्र (रैंवियर-संधि + लवणगमन)!

2️⃣ तंत्रिका-आवेग — उत्पादन और संचरण ⭐⭐

  • विश्राम-विभव ⭐⭐: विश्राम पर झिल्ली ध्रुवीकृत — बाहर +ve (Na+ अधिक!), अंदर -ve। Na-K पंप — 3 Na+ बाहर, 2 K+ अंदर (सक्रिय परिवहन!) — ~-70 mV।
  • क्रिया-विभव ⭐⭐: उद्दीपन → Na+ चैनल खुले → Na+ अंदर → विध्रुवीकरण (~+30 mV!) = क्रिया-विभव/आवेग! फिर K+ बाहर → पुनर्ध्रुवीकरण।
  • संचरण ⭐: विध्रुवीकृत बिंदु से अगले बिंदु पर दोहराव — आवेग अग्रसर।
  • लवणगमन-संचरण ⭐⭐: मायेलिनी में आवेग रैंवियर-संधि से संधि तक कूदता — बहुत तीव्र!

🎯 विश्राम = -70 mV (Na-K पंप 3 बाहर, 2 अंदर!)। उद्दीपन → Na+ अंदर → विध्रुवीकरण → K+ बाहर!

3️⃣ सिनैप्स — आवेग-संचरण ⭐⭐

  • सिनैप्स ⭐: एक न्यूरॉन के तंत्रिकाक्ष और दूसरे के द्रुमिका के बीच संधि — 2 प्रकार: विद्युत और रासायनिक।
  • विद्युत सिनैप्स ⭐⭐: झिल्लियाँ बहुत पास — आवेग सीधा धारा से (अंतराल-संधि!) — तीव्र, दुर्लभ।
  • रासायनिक सिनैप्स ⭐⭐: आवेग → Ca2+ अंदर → पुटक झिल्ली से संलयित → न्यूरोट्रांसमीटर मुक्त (सिनैप्टिक-विवर में!) → ग्राही से बंधे → नया विभव (उत्तेजक/अवरोधक!)।
  • न्यूरोट्रांसमीटर ⭐: एसीटिलकोलीन, डोपामिन, GABA, सेरोटोनिन।
  • तुलना ⭐: रासायनिक = धीमा पर एकदिशीय; विद्युत = तीव्र, द्विदिशीय संभव।

🎯 रासायनिक = पुटक → न्यूरोट्रांसमीटर → विवर → ग्राही → नया संकेत। एकदिशीय!

4️⃣ मस्तिष्क — अग्र, मध्य, पश्च ⭐⭐

  • 3 मुख्य भाग ⭐⭐: अग्रमस्तिष्क + मध्यमस्तिष्क + पश्चमस्तिष्क। ~1200-1400 g। 3 मेनिंजेस से सुरक्षित!
  • अग्रमस्तिष्क ⭐⭐: सबसे बड़ा — सेरिब्रम (2 गोलार्ध — कॉर्पस-कैलोसम से जुड़े! — बाहरी प्रकाश-वर्ण सेरिब्रल-कॉर्टेक्स — संवेदन, चिंतन, स्मृति! + आंतरिक श्वेत-वर्ण!) + थैलेमस (संवेदी-रिले!) + हाइपोथैलेमस ⭐⭐ (ताप, भूख, प्यास, भावनाएँ, पीयूषिका-नियंत्रण — 'मास्टर-नियंत्रक'!) + लिंबिक-तंत्र।
  • मध्यमस्तिष्क ⭐⭐: चतुष्कोटि-पिंड (corpora quadrigemina) — दृश्य + श्रवण-प्रतिवर्त!
  • पश्चमस्तिष्क ⭐⭐: पोंस ⭐ (क्षेत्र-संयोजन + श्वसन-केंद्र!) + अनुमस्तिष्क (cerebellum) ⭐⭐ (अत्यधिक-वलित — मुद्रा + संतुलन + समन्वय!) + मेडुला ⭐⭐ (हृदय + श्वसन + पाचन-प्रतिवर्त — प्राण-केंद्र!)।
  • अंतर: सेरिब्रम = सोच; अनुमस्तिष्क = संतुलन (नशे में चक्कर = अनुमस्तिष्क प्रभावित!)।

🎯 सेरिब्रम = चिंतन; हाइपोथैलेमस = भूख/ताप; अनुमस्तिष्क = संतुलन; मेडुला = प्राण-केंद्र!

5️⃣ प्रतिवर्ती-क्रिया और ज्ञानेन्द्रियाँ ⭐⭐

  • प्रतिवर्ती-क्रिया ⭐⭐: अकस्मात्, अनैच्छिक, त्वरित-प्रतिक्रिया — प्रतिवर्ती-चाप ⭐ = ग्राही → संवेदी-तंत्रिका → CNS → गमन-तंत्रिका → अनुक्रियक। उदा: घुटना-झटका, गर्म-सतह से हाथ हटना!
  • नेत्र-संरचना ⭐⭐: 3 भित्तियाँ — स्क्लेरा (बाहरी, दृढ़ — आगे स्वच्छमंडल!) + कोरॉइड (मध्य, वाहिकामय — आगे परितारिका (iris) — पुतली-नियंत्रण!) + दृष्टिपटल (retina) — शलाकाएँ (rods — मंद-प्रकाश!) + शंकु (cones — रंग-दृष्टि!)। अंध-बिंदु ⭐ = दृक्-तंत्रिका-निर्गम (कोई ग्राही नहीं!); केंद्रीय-गर्तिका (fovea) ⭐ = पीत-बिंदु में — केवल शंकु, सुस्पष्ट दृष्टि!
  • प्रतिबिंब ⭐: प्रकाश → स्वच्छमंडल → पुतली → लेंस → दृष्टिपटल पर उल्टा प्रतिबिंब → दृक्-तंत्रिका → मस्तिष्क।
  • कर्ण-संरचना ⭐⭐: बाह्य — कर्ण-पल्लव + नाल → कर्ण-पटह (eardrum); मध्य — 3 अस्थिकाएँ मैलियस → इन्कस → स्टेपीज़ + यूस्टेशियन-नलिका (दाब-संतुलन!); आंतरिक — कर्णावर्त (cochlea — श्रवण!) + देहली-यंत्र (अर्धवृत्त-नालिकाएँ — संतुलन!)।
  • श्रवण-मार्ग ⭐: ध्वनि → पल्लव → पटह → अस्थिकाएँ → कर्णावर्त-तरंग → रोम-कोशिकाएँ → श्रवण-तंत्रिका → मस्तिष्क। संतुलन = अर्धवृत्त-नालिकाएँ!

🎯 प्रतिवर्ती-चाप: ग्राही→संवेदी→CNS→गमन→अनुक्रियक। शलाका = मंद, शंकु = रंग; कर्णावर्त = श्रवण!

1️⃣ Neural System and the Neuron ⭐⭐

  • Organisation ⭐: the Central Neural System (CNS) — brain + spinal cord — and the Peripheral Neural System (PNS) — nerves connecting the CNS to the body. PNS: somatic (voluntary) + autonomic (involuntary — sympathetic + parasympathetic!).
  • Neuron ⭐⭐: the structural + functional unit — three parts: cell body (cyton) — nucleus + Nissl's granules!; dendrites — short, branched, carry impulses TOWARDS the body; axon — long, carries impulses AWAY, ending in synaptic knobs.
  • Types ⭐⭐: Multipolar — 1 axon + many dendrites (most common!); Bipolar — 1 + 1 (retina!); Unipolar — single process (embryonic!).
  • Axons ⭐: Myelinated — myelin sheath (gaps = Nodes of Ranvier — FAST, saltatory!); Unmyelinated — slow.
  • Neuroglia ⭐: support cells — protect + nourish neurons.

💡 Dendrite = IN, axon = OUT. Myelinated = fast (Nodes of Ranvier + saltatory)!

2️⃣ Nerve Impulse — Generation and Conduction ⭐⭐

  • Resting potential ⭐⭐: at rest the membrane is POLARISED — outside +ve (more Na+!), inside -ve. The Na-K pump pushes 3 Na+ out and 2 K+ in (active transport!) — about -70 mV.
  • Action potential ⭐⭐: a stimulus opens Na+ channels → Na+ rushes in → DEPOLARISATION (~+30 mV!) = the action potential! Then K+ flows out → repolarisation.
  • Conduction ⭐: the depolarised point triggers the next — the impulse travels along the axon.
  • Saltatory conduction ⭐⭐: in myelinated axons the impulse JUMPS from node to node — much FASTER!

🎯 Resting = -70 mV (Na-K pump 3 out, 2 in!). Stimulus → Na+ in → depolarisation → K+ out!

3️⃣ Synapse — Impulse Transmission ⭐⭐

  • Synapse ⭐: the junction between one neuron's axon and the next neuron's dendrite — two types: electrical and chemical.
  • Electrical synapse ⭐⭐: membranes are very CLOSE — the impulse flows directly as current (gap junctions!) — FAST but rare.
  • Chemical synapse ⭐⭐: an impulse arrives → Ca2+ enters → vesicles fuse → NEUROTRANSMITTER released into the synaptic cleft → binds receptors on the next neuron → a new potential (excitatory or inhibitory!).
  • Neurotransmitters ⭐: acetylcholine, dopamine, GABA, serotonin.
  • Comparison ⭐: chemical = slower but ONE-WAY; electrical = fast, can be two-way.

🎯 Chemical synapse = vesicle → neurotransmitter → cleft → receptor → new signal. One-way!

4️⃣ Brain — Forebrain, Midbrain, Hindbrain ⭐⭐

  • Three main parts ⭐⭐: forebrain + midbrain + hindbrain. Brain ~1200-1400 g, protected by 3 meninges!
  • Forebrain ⭐⭐: the largest — cerebrum (2 hemispheres joined by the corpus callosum! — outer grey matter cerebral cortex — sensory, motor, association areas — thinking, memory!) + thalamus (sensory relay!) + hypothalamus ⭐⭐ (body temperature, hunger, thirst, emotions — the 'master controller'!) + limbic system.
  • Midbrain ⭐⭐: the corpora quadrigemina — visual + auditory reflexes!
  • Hindbrain ⭐⭐: Pons ⭐ (connects regions + breathing centre!) + cerebellum ⭐⭐ (highly folded — posture + balance + coordination!) + medulla oblongata ⭐⭐ (cardiovascular + respiratory + gastric reflexes — the VITAL centres!).
  • Key contrast: cerebrum = think; cerebellum = balance (a drunk person's stagger = cerebellum affected!).

🎯 Cerebrum = think; hypothalamus = hunger/temp; cerebellum = balance; medulla = vital centres!

5️⃣ Reflex Action and Sense Organs ⭐⭐

  • Reflex action ⭐⭐: a sudden, involuntary, quick response — the reflex arc ⭐ = receptor → sensory neuron → CNS → motor neuron → effector. Example: knee-jerk, pulling your hand off a hot surface!
  • Eye structure ⭐⭐: three layers — sclera (outer, tough — cornea in front!) + choroid (middle, vascular — iris controls the pupil!) + retina (inner — rods (dim light!) + cones (colour!)). Blind spot ⭐ = optic nerve exit (no photoreceptors!); fovea centralis ⭐ = only cones, the SHARPEST vision!
  • Image formation ⭐: light → cornea → pupil → lens → an inverted image on the retina → optic nerve → brain.
  • Ear structure ⭐⭐: Outer ear — pinna + canal → eardrum; middle ear — 3 ossicles malleus → incus → stapes + Eustachian tube; inner ear — the cochlea (hearing!) + vestibular apparatus (semicircular canals — BALANCE!).
  • Hearing path ⭐: sound → pinna → eardrum → ossicles → cochlear waves → hair cells → auditory nerve → brain. Balance = semicircular canals!

🎯 Reflex arc: receptor→sensory→CNS→motor→effector. Rods = dim, cones = colour; cochlea = hearing, semicircular = balance!

  • रासायनिक: पुटक→न्यूरोट्रांसमीटर→ग्राही
  • एकदिशीय संचरण
  • विद्युत: तीव्र, दुर्लभ

मस्तिष्क ⭐⭐

  • सेरिब्रम = चिंतन; हाइपोथैलेमस = भूख/ताप
  • अनुमस्तिष्क = संतुलन; मेडुला = प्राण
  • पोंस = श्वसन-केंद्र

नेत्र/कर्ण ⭐⭐

  • शलाका = मंद, शंकु = रंग; गर्तिका = स्पष्ट
  • प्रतिवर्ती: ग्राही→संवेदी→CNS→गमन→अनुक्रियक
  • कर्णावर्त = श्रवण; अर्धवृत्त = संतुलन

Neuron ⭐⭐

  • Dendrite = IN; axon = OUT
  • Myelinated = fast (Nodes of Ranvier)
  • Multipolar = most common

Impulse ⭐⭐

  • Resting -70 mV (Na-K pump 3 out, 2 in)
  • Na+ in → depolarisation
  • K+ out → repolarisation

Synapse ⭐⭐

  • Chemical: vesicle→neurotransmitter→receptor
  • One-way transmission
  • Electrical: fast, rare (gap junctions)

Brain ⭐⭐

  • Cerebrum = think; hypothalamus = hunger/temp
  • Cerebellum = balance; medulla = vital
  • Pons = pneumotaxic

Eye/Ear ⭐⭐

  • Rods = dim, cones = colour; fovea = sharp
  • Reflex: receptor→sensory→CNS→motor→effector
  • Cochlea = hear; semicircular = balance

🏆 NEET Practice — 10 Questions

Pehle khud solve karo, phir answer dekho.

Q1. Dendrite aur axon me farak batao.
Answer dekho

Dendrites = chhote, branched, impulses cell body KI TARAF laate hain; axon = lamba, impulses cell body se DOOR le jaata hai (tip pe synaptic knobs!).

Q2. Resting potential kya hai aur kaise banta hai?
Answer dekho

Rest pe axon membrane ~ -70 mV — bahar +ve (zyada Na+!), andar -ve. Na-K pump 3 Na+ bahar aur 2 K+ andar pump karta hai (active transport, ATP!).

Q3. Action potential kaise generate hota hai?
Answer dekho

Stimulus → membrane pe Na+ channels OPEN → Na+ andar rush → DEPOLARISATION (~+30 mV — andar +ve!) = action potential. Phir K+ bahar → repolarisation.

Q4. Saltatory conduction kya hai?
Answer dekho

MYELINATED axons me impulse Node of Ranvier se agle node tak JUMP karta hai (myelin insulator hai!) — bahut fast conduction!

Q5. Chemical synapse me impulse kaise transmit hota hai?
Answer dekho

Pre-synaptic pe impulse → Ca2+ andar → synaptic vesicles membrane se fuse → neurotransmitter cleft me release → post-synaptic receptors se bind → naya potential. One-way!

Q6. Cerebellum ka main function kya hai?
Answer dekho

Body posture, balance aur movement ka COORDINATION — highly folded surface. Drunk person ka chakkar/chalna = cerebellum affected!

Q7. Medulla oblongata kyun 'vital' hai?
Answer dekho

Kyunki yahan cardiovascular (heart), respiratory (breathing), gastric reflexes ke VITAL centres hain — ye band ho jaayein to jaan khatre me!

Q8. Rods aur cones me farak batao.
Answer dekho

Rods = dim light vision (rhodopsin pigment!), colour nahi; cones = bright light + COLOUR vision (red/green/blue!). Fovea me sirf cones (sharpest vision!).

Q9. Reflex arc ke 5 components batao.
Answer dekho

Receptor → sensory (afferent) neuron → CNS (interneuron) → motor (efferent) neuron → effector (muscle/gland). Example: hot surface se haath hatna!

Q10. Cochlea aur semicircular canals me farak kya hai?
Answer dekho

Cochlea = HEARING (Organ of Corti — hair cells se sound signals!); semicircular canals = BALANCE/equilibrium (body position/rotation sense!).
