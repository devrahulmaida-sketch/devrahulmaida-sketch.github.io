📖 Full Explanation (Long Notes)

Concept pakka karne ke liye — aaram se padho

🌐 Notes language:

1️⃣ Inequalities Kya Hain — Balance Nahi, Comparison

  • Equation (=): exact balance — 2x = 6 → x = 3 (ek answer). Inequality (<, >, ≤, ≥): comparison — 2x < 6 → x < 3 (poora RANGE of answers!).
  • Symbols: < chhota, > bada, ≤ chhota-ya-barabar, ≥ bada-ya-barabar.
  • Solution set: inequality ko TRUE banane wale saare values — infinite answers ko interval/graph se likhte hain.
  • Real life: "exam me kam se kam 40 marks chahiye" → x ≥ 40. "lift me max 10 log" → x ≤ 10. Inequalities har jagah!
  • Linear inequality: variable ki power 1 — ax + b < 0, 3x − 5 ≥ 7 jaisi. (Is chapter me yahi padhenge.)

💡 Feel: equation = exact address ("house no. 3"), inequality = poora area code ("sector 3 ke andar kahin bhi")!

2️⃣ Rules of the Game — Kab Sign Flip Hota Hai ⭐

  • Rule 1: dono taraf SAME number add/subtract karo → sign SAME rehta hai. (x − 3 < 5 → x < 8 ✓)
  • Rule 2: dono taraf POSITIVE number se multiply/divide → sign SAME. (2x < 6 → x < 3 ✓)
  • Rule 3 ⭐⭐: NEGATIVE number se multiply/divide → sign FLIP! (−2x < 6 → x > −3 — sign palat gaya!) Sabse zyada galti yahi hoti hai!
  • Kyun flip?: number line pe negative se multiply = mirror image! 2 < 3 hai, par −2 > −3 (mirror me ulta!).
  • Reciprocal: dono taraf same sign ke numbers hon to reciprocal lene pe sign flip (2 < 3 → 1/2 > 1/3).
  • Safe trick: variable ko LEFT pe laao positive coefficient ke saath — flip mistakes bachte hain.

🎯 Golden rule: minus se multiply/divide = sign palto. Har baar, bina exception. Isi ek rule pe aadhe questions atakte hain!

3️⃣ Number Line Solutions — Ek Variable ⭐

  • Solve karke number line pe dikhao: x < 3 → open circle (○) at 3, LEFT side shade. x ≥ 3 → filled/closed circle (●) at 3, RIGHT shade.
  • Open vs closed ⭐: < ya > = open circle (point INCLUDED nahi); ≤ ya ≥ = closed circle (point included).
  • Interval notation: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞). Bracket ka matlab wahi — round = open, square = closed. ∞ ke saath hamesha round!
  • Combined (AND) inequalities ⭐: −2 ≤ x < 5 → [−2, 5) — dono conditions EK SAATH satisfy honi chahiye. Solve: −3 ≤ 2x − 1 < 7 → sab parts me same operation → −1 ≤ x < 4.
  • OR inequalities: x < −1 ya x > 3 → do alag shade regions, union (−∞, −1) ∪ (3, ∞).

💡 Circle ka funda: sign me barabar hai (≤, ≥) to circle bhara hua (mil gaya membership), nahi to khokhla circle (bahar raha woh point).

4️⃣ Graphical Solutions — Do Variables ⭐

  • Linear inequality in x, y: ax + by < c jaisi — solution ek REGION hota hai plane me, ek line nahi!
  • Steps ⭐: (1) Inequality ko equation banao (ax + by = c) — LINE draw karo. (2) < ya > ho to DASHED line (line excluded), ≤ ya ≥ ho to SOLID (included). (3) Test point daalo (origin (0,0) easiest!) — satisfy kare to us side shade, nahi to doosri side.
  • Example: x + y < 4 → line x + y = 4 dashed; origin (0+0 < 4 ✓) → origin wali side shade.
  • System of inequalities ⭐: do-teen inequalities ka COMMON region — sabki shading jo overlap kare wahi solution. (LPP ka foundation — 12th me Linear Programming isi pe!)
  • Feasible region: common shaded area — corners (vertices) important hote hain optimization ke liye.

💡 Feel: line plane ka border hai. Test point = spy jo check karta hai border ke kaunse side solution ka territory hai!

5️⃣ Word Problems — Real Life Inequalities

  • Translation key ⭐: "kam se kam/at least" = ≥; "zyada se zyada/at most" = ≤; "se zyada/more than" = >; "se kam/less than" = <.
  • Example 1: Ravi ke paas ₹120 se kam paise hain, book ₹30 ki hai. x books: 30x < 120 → x < 4 → max 3 books (whole number!).
  • Example 2 (marks): 3 tests ka average ≥ 60 chahiye, do tests me 55, 70 aaye. (55 + 70 + x)/3 ≥ 60 → 125 + x ≥ 180 → x ≥ 55.
  • Example 3 (temperature conversion): Celsius-Fahrenheit range problems — C ko F me convert karke inequality solve karo.
  • Domain wale questions ⭐: √(x − 3) real kab? → x − 3 ≥ 0 → x ≥ 3. 1/(x − 2) defined kab? → x ≠ 2.
  • Answer check: word problems me final answer CONTEXT me socho — books 3.9 nahi, 3 hi ho sakti hain!

🎯 At least = minimum guarantee = ≥. At most = maximum limit = ≤. Ye do phrases rat lo, word problems aadhe wahi ban jaate hain!

1️⃣ असमिकाएं क्या हैं — संतुलन नहीं, तुलना

  • समीकरण (=): सटीक संतुलन — 2x = 6 → x = 3 (एक उत्तर)। असमिका (<, >, ≤, ≥): तुलना — 2x < 6 → x < 3 (उत्तरों की पूरी श्रेणी!)।
  • प्रतीक: < छोटा, > बड़ा, ≤ छोटा-या-बराबर, ≥ बड़ा-या-बराबर।
  • हल समुच्चय: असमिका को सत्य बनाने वाले सभी मान — अनंत उत्तर अंतराल/आलेख से लिखते हैं।
  • वास्तविक जीवन: "कम से कम 40 अंक" → x ≥ 40। "अधिकतम 10 लोग" → x ≤ 10।
  • रैखिक असमिका: चर की घात 1 — ax + b < 0, 3x − 5 ≥ 7 जैसी।

💡 समीकरण = सटीक पता, असमिका = पूरा क्षेत्र!

2️⃣ खेल के नियम — चिह्न कब पलटता है ⭐

  • नियम 1: दोनों ओर समान संख्या जोड़ो/घटाओ → चिह्न समान।
  • नियम 2: धनात्मक से गुणा/भाग → चिह्न समान।
  • नियम 3 ⭐⭐: ऋणात्मक से गुणा/भाग → चिह्न पलटता है! (−2x < 6 → x > −3!) सबसे अधिक गलती यहीं!
  • क्यों?: संख्या रेखा पर ऋण से गुणा = दर्पण प्रतिबिंब! 2 < 3, परंतु −2 > −3।
  • व्युत्क्रम: समान चिह्न की संख्याओं के व्युत्क्रम पर चिह्न पलटता है (2 < 3 → 1/2 > 1/3)।
  • सुरक्षित युक्ति: चर को बाएं लाओ धन गुणांक के साथ।

🎯 स्वर्ण नियम: ऋण से गुणा/भाग = चिह्न पलटो। हर बार, बिना अपवाद!

3️⃣ संख्या रेखा हल — एक चर ⭐

  • संख्या रेखा पर: x < 3 → 3 पर खुला वृत्त (○), बाईं ओर छाया। x ≥ 3 → भरा वृत्त (●), दाईं ओर।
  • खुला बनाम बंद ⭐: < या > = खुला वृत्त (बिंदु शामिल नहीं); ≤ या ≥ = बंद (शामिल)।
  • अंतराल संकेत: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞)। गोल = खुला, वर्ग = बंद। ∞ के साथ सदैव गोल!
  • संयुक्त (AND) असमिकाएं ⭐: −2 ≤ x < 5 → [−2, 5)। हल: −3 ≤ 2x − 1 < 7 → सभी भागों में समान संक्रिया → −1 ≤ x < 4।
  • OR असमिकाएं: x < −1 या x > 3 → दो क्षेत्र, संघ।

💡 चिह्न में बराबर है (≤, ≥) तो वृत्त भरा, नहीं तो खोखला।

4️⃣ आलेखीय हल — दो चर ⭐

  • दो चरों में रैखिक असमिका: ax + by < c — हल तल में एक क्षेत्र होता है!
  • चरण ⭐: (1) असमिका को समीकरण बनाओ — रेखा खींचो। (2) < या > → बिंदुरेखा (dashed), ≤ या ≥ → ठोस (solid)। (3) परीक्षण बिंदु (0,0) डालो — संतुष्ट करे तो उस ओर छाया, नहीं तो दूसरी ओर।
  • उदाहरण: x + y < 4 → रेखा x + y = 4 dashed; मूलबिंदु संतुष्ट ✓ → मूलबिंदु वाली ओर छाया।
  • असमिकाओं का निकाय ⭐: उभयनिष्ठ क्षेत्र — सभी छायाओं का अतिव्यापन। (LPP की नींव — 12वीं में काम आएगा!)
  • सुसंगत क्षेत्र (feasible region): उभयनिष्ठ छायांकित क्षेत्र — शीर्ष (vertices) महत्वपूर्ण।

💡 रेखा सीमा है। परीक्षण बिंदु = जासूस जो बताता है किस ओर हल का क्षेत्र है!

5️⃣ शब्द समस्याएं — वास्तविक जीवन असमिकाएं

  • अनुवाद कुंजी ⭐: "कम से कम" = ≥; "अधिक से अधिक" = ≤; "से अधिक" = >; "से कम" = <।
  • उदाहरण 1: रवि के पास ₹120 से कम, पुस्तक ₹30 की। 30x < 120 → x < 4 → अधिकतम 3 पुस्तकें!
  • उदाहरण 2 (अंक): 3 परीक्षाओं का औसत ≥ 60, दो में 55, 70। (55 + 70 + x)/3 ≥ 60 → x ≥ 55।
  • प्रांत प्रश्न ⭐: √(x − 3) वास्तविक कब? → x ≥ 3। 1/(x − 2) परिभाषित कब? → x ≠ 2।
  • जांच: उत्तर संदर्भ में सोचो — पुस्तकें 3.9 नहीं, 3 ही!

🎯 कम से कम = ≥, अधिक से अधिक = ≤। ये दो वाक्यांश रट लो!

1️⃣ What Inequalities Are — Not Balance, but Comparison

  • Equation (=): an exact balance — 2x = 6 → x = 3 (one answer). Inequality (<, >, ≤, ≥): a comparison — 2x < 6 → x < 3 (a whole RANGE of answers!).
  • Symbols: < less than, > greater than, ≤ less than or equal, ≥ greater than or equal.
  • Solution set: all the values that make the inequality TRUE — written as intervals or graphs.
  • Real life: "need at least 40 marks" → x ≥ 40. "lift holds at most 10 people" → x ≤ 10. Inequalities are everywhere!
  • Linear inequality: the variable has power 1 — like ax + b < 0, 3x − 5 ≥ 7. (This chapter's focus.)

💡 Feel: an equation is an exact address ("house no. 3"); an inequality is a whole area code ("anywhere in sector 3")!

2️⃣ Rules of the Game — When the Sign Flips ⭐

  • Rule 1: add/subtract the SAME number on both sides → sign stays. (x − 3 < 5 → x < 8 ✓)
  • Rule 2: multiply/divide by a POSITIVE number → sign stays. (2x < 6 → x < 3 ✓)
  • Rule 3 ⭐⭐: multiply/divide by a NEGATIVE number → the sign FLIPS! (−2x < 6 → x > −3 — flipped!) This is where most mistakes happen!
  • Why the flip?: multiplying by a negative is a mirror image on the number line! 2 < 3, but −2 > −3 (the mirror reverses it!).
  • Reciprocals: taking reciprocals of same-signed numbers flips the sign (2 < 3 → 1/2 > 1/3).
  • Safe trick: bring the variable to the LEFT with a positive coefficient — flip mistakes disappear.

🎯 Golden rule: multiply/divide by a negative = flip the sign. Every time, no exceptions. Half the questions in this chapter hinge on this one rule!

3️⃣ Number Line Solutions — One Variable ⭐

  • Solve and show on a number line: x < 3 → an open circle (○) at 3, shaded LEFT. x ≥ 3 → a closed circle (●) at 3, shaded RIGHT.
  • Open vs closed ⭐: < or > = open circle (point NOT included); ≤ or ≥ = closed circle (included).
  • Interval notation: x < 3 = (−∞, 3); x ≥ 3 = [3, ∞). Round bracket = open, square = closed. Always round with ∞!
  • Combined (AND) inequalities ⭐: −2 ≤ x < 5 → [−2, 5) — both conditions must hold TOGETHER. Solve: −3 ≤ 2x − 1 < 7 → same operation on all parts → −1 ≤ x < 4.
  • OR inequalities: x < −1 or x > 3 → two separate shaded regions, the union (−∞, −1) ∪ (3, ∞).

💡 Circle logic: if the sign includes "equal" (≤, ≥), the circle is filled (membership granted); otherwise it is hollow (that point stays out).

4️⃣ Graphical Solutions — Two Variables ⭐

  • Linear inequality in x, y: like ax + by < c — the solution is a whole REGION of the plane, not a line!
  • Steps ⭐: (1) Turn the inequality into an equation (ax + by = c) — draw the LINE. (2) < or > → DASHED line (line excluded); ≤ or ≥ → SOLID (included). (3) Plug in a test point (the origin (0,0) is easiest!) — if it satisfies the inequality, shade its side; otherwise the other side.
  • Example: x + y < 4 → draw x + y = 4 dashed; the origin works (0+0 < 4 ✓) → shade the origin's side.
  • System of inequalities ⭐: the COMMON region of two or three inequalities — wherever all the shadings overlap. (The foundation of Linear Programming in Class 12!)
  • Feasible region: the common shaded area — its corners (vertices) matter for optimization.

💡 Feel: the line is a border. The test point is a spy checking which side of the border holds the solution territory!

5️⃣ Word Problems — Real-Life Inequalities

  • Translation key ⭐: "at least" = ≥; "at most" = ≤; "more than" = >; "less than" = <.
  • Example 1: Ravi has less than ₹120; a book costs ₹30. 30x < 120 → x < 4 → at most 3 books (whole numbers only!).
  • Example 2 (marks): needs an average ≥ 60 across 3 tests; scored 55 and 70 in two. (55 + 70 + x)/3 ≥ 60 → 125 + x ≥ 180 → x ≥ 55.
  • Example 3 (temperature): Celsius-Fahrenheit range problems — convert and solve the inequality.
  • Domain questions ⭐: when is √(x − 3) real? → x − 3 ≥ 0 → x ≥ 3. When is 1/(x − 2) defined? → x ≠ 2.
  • Check the answer: in word problems think about CONTEXT — books can be 3, not 3.9!

🎯 At least = a minimum guarantee = ≥. At most = a maximum limit = ≤. Learn these two phrases and half the word problems are done!

🏆 JEE Practice — 10 Questions

Pehle khud solve karo, phir answer dekho.

Q1. Solve: 3x − 7 < 8.
Answer dekho

3x < 15 → x < 5 = (−∞, 5).

Q2. Solve: −2x ≥ 10.
Answer dekho

Negative se divide → sign FLIP: x ≤ −5.

Q3. −4 < 3x − 1 ≤ 8 solve karo.
Answer dekho

Sab parts me +1: −3 < 3x ≤ 9 → ÷3: −1 < x ≤ 3 = (−1, 3].

Q4. x < 2 ko number line pe kaise dikhayenge?
Answer dekho

Open circle (○) at 2, left side shade — 2 included nahi.

Q5. [3, 7) interval me 7 included hai?
Answer dekho

Nahi — round bracket = open. 3 included, 7 nahi.

Q6. x + y ≤ 6 ke graph me line kaisi hogi?
Answer dekho

Solid (kyunki ≤ me barabar hai — line included), phir test point (0,0) wali side shade.

Q7. System of inequalities ka solution kya hota hai?
Answer dekho

Saari inequalities ki shading ka common (overlapping) region — feasible region.

Q8. 'Kam se kam 50 marks chahiye' — inequality?
Answer dekho

x ≥ 50 ('kam se kam' = at least).

Q9. √(2x − 6) real kab hoga?
Answer dekho

Andar wala ≥ 0 → 2x − 6 ≥ 0 → x ≥ 3.

Q10. Do numbers ka sum 30 se zyada, pehla number 12 hai. Dusre ke liye inequality?
Answer dekho

12 + y > 30 → y > 18.
